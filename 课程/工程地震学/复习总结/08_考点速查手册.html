一、必背定义（名词解释题库）

名词定义（精简版）
工程地震学从工程抗震应用角度出发，研究与减轻地震灾害有关的地震问题的一门学科，主要以地震所产生的强烈地震动及其效应为研究目标
工程地震学的研究目的对工程场地可能遭受的地震破坏作用做出定量的预测，为建筑物及各类工程结构设施的抗震设计提供科学基础和依据
地震地下岩石突然断裂、地壳沿断裂突然滑移，使缓慢积累的能量突然释放而引起的地球表层振动
弹性回跳说Reid（1911）提出：断层两侧岩体长期积累弹性应变，应力超过摩擦强度时突然滑动并释放应变能，岩体回弹到未变形状态
震级表示地震本身大小的标度，由地震仪记录的振幅（或地震矩）计算，一次地震只有一个震级
地震烈度地震发生时在某一地区引起的地震动强度及其所产生的影响、造成破坏的强烈程度
震害指数房屋震害程度的定量指标，以 0.00 到 1.00 之间的数字表示由轻到重的震害程度
等震线把烈度相同的点连接起来的封闭曲线（烈度等值线）
仪器烈度用地震动参数（PGA、PGV 等）定量表征的烈度
海啸由海底地震、火山喷发、泥石流、滑坡等海底地形突然变化引发的、具有长波长和周期的大洋行波
爬高（run-up）海水涌上陆地所到达的最远处高于正常海平面的高度
砂土液化将任何物质转变为液化态的作用或过程；在无粘性土中，是因孔隙水压增加和有效应力减少所导致的从固态到液态的变化
滑坡斜坡上的岩体或土体，在重力作用下沿一定的软弱面或带整体或分散顺坡向下滑动的自然现象
崩塌陡崖、陡坎、陡坡上的岩体、土体及其碎屑物在重力作用下突然脱离山体崩落、滚动，堆积在坡脚的地质现象
泥石流沙石、泥土、岩屑、石块等松散固体物质和水的混合体，在地震动或暴雨、冰雪融水激发下，沿坡面或沟床做突然流动的现象
堰塞湖地震引发的滑坡、崩塌或泥石流的堆积体堵塞河流后，上游水位壅高而形成的天然湖泊
地震地质学研究地震孕育、发生和发展的地质过程和条件的科学
新构造运动从新第三纪（中新世开始）以来发生的地壳运动
活动断层GB 17741—2005：晚第四纪以来（距今约 12.6 万年）有活动的断层；活动指地表或近地表有地质地貌证据
发震断层可能发生破坏性地震的断层
断裂分段一条大的活动断裂带可分为若干大段落，每一段落都可作为独立震源发生地震破裂，且不受相邻段制约而有自己独特的活动历史
级联破裂活动断裂上空间可变破裂模式：两个或多个相连接的基本破裂单元在一次地震中同时破裂
古地震学研究史前地震的位置、时间和大小的一门学科
本底地震地震带内已划定的潜在震源区外的地震，表示在地震带内随机发生
震级上限 M_uz地震带内震级-频度关系中累积频度趋于零的上限震级值；不具有时间含义
超越概率某场地遭遇大于或等于给定的地震动参数值的概率
面波频散面波的传播速度（相速度）随频率（周期）而变化
首波当 V₂ > V₁ 且入射角达临界角时，透射波沿界面以 V₂ 滑行并向第一介质辐射能量，以临界角返回地表被接收的波

二、必背公式（写在草稿纸上的”公式卡”）

内容公式
P 波速度V_P = √((λ+2μ)/ρ)
S 波速度V_S = √(μ/ρ)
速度比V_P/V_S = √((λ+2μ)/μ) = √(2(1−σ)/(1−2σ))；σ = 0.25 时 ≈ 1.73
斯涅耳定律sinθ₁/V₁ = sinθ₂/V₂ = p
临界角sinθ_c = V₁/V₂
直达波走时（震源在地表）t_d = x/V₁
反射波走时（震源在地表）t_r = √(x²+4h₁²)/V₁
首波走时（震源在地表）t_h = x/V₂ + 2h₁√(V₂²−V₁²)/(V₁V₂)
交叉距离（震源在地表）x_c = 2h₁√((V₂+V₁)/(V₂−V₁))
直达波走时（震源在深度 H）t_d = √(x²+H²)/V₁
反射波走时（震源在深度 H）t_r = √(x²+(2h₁−H)²)/V₁
首波走时（震源在深度 H）t_h = x/V₂ + (2h₁−H)√(V₂²−V₁²)/(V₁V₂)
交叉距离（震源在深度 H）x_c = (2h₁−H)√((V₂+V₁)/(V₂−V₁))
瑞利波速度c_R ≈ 0.92 V_S
里氏震级M_L = lg A − lg A₀(Δ)；零级：Δ = 100 km、A₀ = 1 μm
面波震级M_s = lg(A/T) + 1.66 lgΔ + 3.3
体波震级m_b = lg(A/T) + Q(Δ, h)
地震矩M₀ = μ A D（N·m）
矩震级M_w = (2/3)(lg M₀ − 9.1)，M₀ 单位 N·m
震级-能量lg E = 11.8 + 1.5M（erg）；lg E = 1.5M + 4.8（J）
能量倍数震级相差 1 级 → 能量约差 31.6 倍（10^1.5）
仪器烈度（I<IX）MMI = 3.66 lg PGA − 1.66（PGA 单位 g）；MMI = 3.47 lg PGV + 2.35（PGV 单位 cm/s）
海啸波速v = √(gH)
海啸等级m = log₂H
级联破裂方案数m = n(n+1)/2
G-R 关系lg N(m) = a − bm；b 通常为 1 ± 0.3；β = b·ln10

五、易混概念对照表（选择题最爱）

对比AB
工程地震 vs 工程抗震给出设防标准（要抗多大的震）结构反应分析与抗震设计（怎样抗住）
地震预测 vs 地震预报科学行为，对三要素的科学判断政府行为，按法定程序向社会发布
震级 vs 烈度地震本身大小，一次地震一个值某地受影响程度，随地点变化
断裂 vs 节理 vs 断层岩石破裂形成断裂构造两侧无明显位移
活动断层 vs 发震断层晚第四纪以来有活动（地貌证据）可能发生破坏性地震；蠕滑断层属活动但非发震
潜源 vs 本底地震已划定的潜在震源区内潜源区外、带内随机发生
震级上限 vs 震级下限累积频度趋于零，无时间含义可能有影响的最小震级，一般取 4.0
构造地貌法 vs GPS几万~几十万年尺度几年~几十年尺度（古地震填补其间空挡）
首波 vs 折射波折射波的特例（临界角滑行后返回地表）进入第二介质继续传播的波
瑞利波 vs 勒夫波P-SV 型、铅垂面椭圆运动、≈0.92V_SSH 型、水平横向振动、需低速层+高速半空间，更快
砂土液化 vs 淤泥软化无粘性饱和砂土孔隙水压升高、有效应力减小淤泥类软土的强度软化（同属场地地质灾害）
滑坡 vs 崩塌整体沿滑面下滑，水平运动为主，很少完全脱离母体崩落翻滚，垂直运动为主，完全脱离母体
PSHA vs CPSHA三个假定：源内空间均匀、G-R 分布、泊松分布增加地震区带划分与空间分布函数，解决空间不均匀问题

六、论述题万能框架（背这几个”骨架”）

6.1 论”某类地震灾害”的框架

定义 → 成因/机制 → 发生条件 → 典型震例（数据）→ 工程影响 → 防治措施

例（海啸）：定义 → 逆冲型海底地震使海水抬升 → 三要素 → 2004 苏门答腊/2011 日本 → 沿海工程设防、避让 → 评估 + 预警 + 减轻三途径。

6.2 论”活动断层与工程”的框架

断层活动性（时限标准）→ 活动断层的表征与分类 → 分段与级联（最大潜在地震）→ 定量参数（速率、同震位移、复发间隔）→ 工程对策（避让 / 抗断设计）

6.3 论”地震危险性分析”的框架

为什么概率方法（认识局限 + 工程风险差异）→ Cornell 框架与三假定 → 四步骤 → 中国方案（地震区带 + 潜源 + 空间分布函数）→ 结果与不确定性

6.4 论”工程地震学与相邻学科关系”的框架

定义与目的 → 学科链条（地质学 → 地震学 → 工程地震学 → 地震工程学）→ 各学科分工与相互促进 → 结论（桥梁作用）
