模块一：卷积神经网络基础

1.1 为什么用卷积（而不是全连接）

全连接把图像展平为向量 → 参数爆炸（224×224×3 ≈ 15 万维），且丢失空间结构。卷积带来三大好处：

  1. 参数共享（Parameter Sharing）：同一过滤器在整张图上滑动复用 → 平移不变性（在左上角学到的边缘检测器也能用于右下角）。
  2. 稀疏连接（Sparsity）：输出每个像素只连输入局部区域 → 比全连接参数少几个数量级。
  3. 平移等变：输入平移，输出相应平移。

1.2 卷积运算

边缘检测（直觉起点）：垂直边缘检测核（卷积核 / filter / kernel）：

​111​000​−1−1−1​​

与图像做互相关（深度学习框架常称”卷积”实为互相关），亮→暗跳变处产生亮带 → 检测垂直边缘。水平、45° 等同理。CNN 的威力在于过滤器权重本身由反向传播学习，而非手工指定。

维度公式：输入 n×n，过滤器 f×f，无填充、步长 1 → 输出 (n−f+1)×(n−f+1)。

1.3 Padding 与 Stride

  • Padding：边缘像素被卷积计算次数少 → 信息流失、尺寸缩小。补 0 解决。
    • valid：不填充，输出缩小；
    • same：填充使输出尺寸 = 输入，填充量 p=⌊(f−1)/2⌋（f 通常奇数）。
  • Stride（步长 s）：过滤器每次滑动的步幅。输出尺寸：
⌊sn+2p−f​+1⌋×⌊sn+2p−f​+1⌋

1.4 三维与多通道卷积

  • 彩色图输入 n×n×3，过滤器 f×f×3（深度必须等于输入通道数）；
  • 多个过滤器 → 每个过滤器产生一张特征图，堆叠成输出体积 n′×n′×c′；
  • 输出通道数 = 过滤器个数 = 想学到的特征种类数。

1.5 池化层（Pooling）

  • 最大池化：取局部窗口最大值（最常用，保留纹理/边缘强度）；
  • 平均池化：取均值；
  • 特点：无可学习参数，仅做下采样（减小尺寸、控制过拟合、扩大感受野）；
  • 现代大网络（ResNet 等）常靠 stride 卷积代替池化下采样。

1.6 经典网络演进（必背谱系）

网络年份关键贡献深度备注
LeNet-51998最早实用 CNN（手写数字）7 层卷积+池化+全连接
AlexNet2012引爆深度学习（ImageNet）8 层ReLU + Dropout + GPU
VGG-16/192014用小 3×3 卷积堆叠16/19结构简单、参数大
Inception/GoogLeNet2014多尺度并行 + 1×1 bottleneck221×1 卷积降维
ResNet2015残差连接解决退化达 152残差块 + 跳跃连接

残差块（ResNet 核心）：

a[l+2]=g(W[l+2]a[l+1]+a[l])

跳跃连接（skip connection）让恒等映射易学，使网络可加深而不退化——训练误差随深度下降。

Inception 模块：并行用 1×1、3×3、5×5 卷积与池化，再拼接；1×1 卷积做”瓶颈”降维，控制计算量。

1×1 卷积（Network in Network） 三大作用：① 降维/升维控计算量；② 引入非线性；③ 跨通道信息混合。

模块二：深度卷积网络实例探究

2.1 迁移学习（Transfer Learning）—— 工程最实用技巧

预训练大模型（在 ImageNet 等大数据集学到的表征）作为 backbone：

  • 数据集小：只替换并训练最后几层/分类头，冻结前面；
  • 数据集中等：解冻后几块微调；
  • 数据集大：可用预训练权重初始化后整体训练，或从头训练（但仍用其结构）。

2.2 数据增强（Data Augmentation）

缓解数据不足、提升泛化：

  • 镜像翻转、随机裁剪（crop）、色彩抖动（color shifting）、旋转、缩放；
  • 常用技巧：在 RGB 通道上加 PCA 噪声（AlexNet）；用专门线程实时生成增强样本。

2.3 其他高效设计

  • 1×1 卷积降维（见 1.6）；
  • 深度可分离卷积（MobileNet）：逐通道 + 1×1 点卷积，大幅减参，适合移动端；
  • 瓶颈结构（bottleneck）：1×1 先降维、3×3 计算、1×1 升维。

模块三：目标检测与分割

3.1 目标定位（Classification + Localization）

输出向量：y^​=[pc​, bx​, by​, bh​, bw​, c1​, c2​, …]。

  • pc​：是否含目标；
  • (bx​,by​)：边界框中心（相对格点，0~1）；(bh​,bw​)：宽高；
  • ci​：类别 one-hot。

损失：含目标时用定位误差 + 分类误差；不含目标时只惩罚 pc​。

3.2 关键点 / Landmark 检测

输出一组坐标 (xi​,yi​)，如人脸 64 个关键点、姿态关节点。本质是坐标回归，标签需一致（同一关键点编号）。

3.3 滑动窗口 → 卷积化

  • 原始滑窗：多位置裁剪 + 多次前向 → 慢；
  • 卷积化滑窗：全卷积网络一次前向，输出网格上每格对应一个窗口的预测 → 实时。

3.4 YOLO（You Only Look Once）

将图像分成 S×S 网格（如 19×19），每个格点预测：

  • 该格内含目标的置信度；
  • B 个边界框 (bx​,by​,bh​,bw​) + 置信度；
  • C 个类别概率。

优点：单阶段、实时、全局上下文好；编码：中心相对格点、宽高相对整图。

IoU（交并比）：预测框与真实框交集面积 ÷ 并集面积；通常 IoU > 0.5 判为正确检测。

非极大值抑制（NMS）：

  1. 按置信度降序排列所有框；
  2. 取最高置信度框，输出它；
  3. 抑制与它 IoU 超过阈值（如 0.5）的其他框；
  4. 重复至无剩余。 → 确保每个目标只保留一个框。

Anchor Boxes（锚框）：预设若干形状（高瘦/矮宽），每格预测多个 anchor → 解决”一格多目标”。预测的是相对 anchor 的偏移。

3.5 R-CNN 系列（两阶段）

方法思路速度精度
R-CNNSelective Search 提 ~2000 候选框 → 各自过 CNN → SVM 分类慢（每张图数秒）高
Fast R-CNN整图过 CNN 得特征图，RoI Pooling 从特征图取候选区较快高
Faster R-CNN用 RPN（区域候选网络）学习提候选框更快高
Mask R-CNNFaster R-CNN + 并行掩码分支—实例分割
  • RoI Pooling / Align：把任意候选框映射到固定尺寸特征（Align 用双线性插值更准）；
  • RPN：在特征图滑窗，每点预测”是否为前景 + 框偏移”，与 anchor 配合。

3.6 语义分割（Semantic Segmentation）

  • 转置卷积（Transposed Conv / 上采样 / “反卷积”）：把小特征图放大，用于解码器上采样；
  • U-Net：编码器（下采样提取语义） + 解码器（上采样恢复空间） + 跳跃连接把编码器的浅层细节直接拼到解码器 → 兼顾语义与定位，医学图像分割标配；
  • FCN / DeepLab（带空洞卷积 dilated conv 扩大感受野）等。

注：CASIA 课件 cv4-图像分割.pdf 覆盖传统与深度分割方法，可作为本节的扩展阅读。

模块四：人脸验证与神经风格迁移

4.1 人脸验证 vs 辨识

  • 验证（1:1）：“这两张是同一个人吗？” → 阈值判断距离；
  • 辨识（1:N）：“这人是库里谁？” → 比对所有人取最近。

4.2 One-shot 学习

只需一张（或极少）样本即可识别新人——靠**学习”相似度”**而非”分类”。

4.3 Siamese 网络

  • 同一 CNN 编码两张图 → 得到两个嵌入向量 f(x(1)),f(x(2))；
  • 比较距离 d=∥f(x(1))−f(x(2))∥；
  • 同人距离小、异人距离大。

Triplet Loss（三元组损失）：同时输入

  • Anchor（锚点） xA
  • Positive（同人） xP
  • Negative（异人） xN

目标：

∥f(xA)−f(xP)∥2+α<∥f(xA)−f(xN)∥2

即 同人距离 + 间隔 α < 异人距离。训练让嵌入空间把同人聚拢、异人推开。

4.4 神经风格迁移（Neural Style Transfer）

生成图 G 同时像内容图 C 的内容、像风格图 S 的风格。优化目标：

J(G)=αJcontent​(C,G)+βJstyle​(S,G)
  • 内容代价 Jcontent​：在某隐藏层，生成图与内容图激活的均方误差（保留”画了什么”）；
  • 风格代价 Jstyle​：用各层特征图的 Gram 矩阵（通道间相关性的协方差）刻画”纹理/笔触”，生成图与风格图的 Gram 矩阵逐层接近（保留”怎么画的”）；
  • 用梯度下降直接优化像素 G（而非网络权重）。
