一、笔记原文转写

数学分析 → 函数、代数、数值分析、有限元 数值解法 → 差分（离散点） 有限元法 / 边界元法 / 有限体积法 / 谱方法 传热学 → 差分法

热对流扩散方程（傅里叶定律）：

ρc∂t∂T​=∇⋅k∇T+Q

短短几行其实交代了整门课的三件事：问题的来源（数学分析 → 微分方程）、 求解的路线（离散 → 代数方程组）、方法的家族（差分、有限元、边界元、有限体积、谱方法）。

二、逐条解释与补充

2.1 为什么”数学分析 → 数值分析 → 有限元”是一条链

数学分析讨论的是存在且能写出解析表达式的解；一旦区域形状不规则、系数可变、边界条件复杂， 解析解基本写不出来，只能求近似解。近似解有两种典型来源：

  • 把连续的自变量离散成有限个点（差分法）：导数用差商代替，一阶导数的三种差分见 02-一维稳态热传导的有限差分法。
  • 把解限制在有限维函数空间里（有限元、谱方法）：设定 u(x)≈∑Ni​(x)ui​， 要求某个积分意义下的误差为零。这就是有限元的起点。

两条路最后都归结为同一个线性代数问题 [A]{u}={f}，所以《数值分析》里的 直接法（追赶法、LU）、迭代法（Jacobi、SOR、共轭梯度）是这门课的工具箱。

2.2 五种方法的定位

方法离散对象优点缺点本课程位置
有限差分区域上的网格节点构造简单、格式直观不规则区域难处理、边界精度低P1–P3 重点
有限元区域的单元划分 + 基函数几何适应性强、边界条件自然处理、理论完备需要网格与插值、装配过程繁琐P4–P12 重点
边界元只离散边界降一维、适合无限域需要基本解、系数矩阵满阵未展开
有限体积控制体（守恒通量）严格守恒、适合流体高阶精度难达到未展开
谱方法全局光滑基函数光滑解精度极高复杂几何与间断解适应性差未展开

老师笔记里”传热学 → 差分法”的意思是：这一节的物理背景取自传热学（稳态/瞬态导热）， 处理手段暂时用差分法；到了有限元部分，物理背景会换成材料力学/弹性力学。

2.3 热对流扩散方程逐项解释

ρc(∂t∂T​+V⋅∇T)=∇⋅(k∇T)+Q
项名称物理含义
ρc∂T/∂t时间项（非定常项）单位体积内能随时间的变化率
ρcV⋅∇T对流项流体带着热量迁移（V 为流体速度）
∇⋅(k∇T)扩散项傅里叶定律 + 能量守恒得到的净导热
Q源项单位体积、单位时间的内部产热（如核衰变、电阻发热）

笔记 P3 顶部把右端注释为**“单位体积内平均产/燃率”**，即 Q 是体热源密度。

傅里叶定律（本构关系，不是守恒律）：

q=−k∇T

即热流密度与温度梯度成正比、方向相反。把它代入能量守恒 ρc∂T/∂t=−∇⋅q+Q 就得到上面那个方程。这个”守恒律 + 本构关系 → 控制方程”的推导思路后面还会用两次 （力学里换成”平衡 + 胡克定律”，见 P4）。

若 V=0（固体，无流动），对流项消失，退化为热传导方程：

ρc∂t∂T​=∇⋅(k∇T)+Q

若再令 ∂T/∂t=0（或 ρc∂T/∂t=0，笔记 P2 写的就是这一步）， 得到本课程实际要解的第 1 个模型问题：

∇⋅(k∇T)+Q=0​

2.4 物质导数（笔记 P2 上半页会用到）

笔记 P2 出现 dtdT​=∂t∂T​+V⋅∇T， 这是物质导数/全导数：跟随流体质点观察温度变化，由”局部变化 + 迁移变化”两部分组成。 对应两种参考立场：

  • Euler 表述：固定空间点看物理量随时间的变化 → 出现 ∂T/∂t。
  • Lagrange 表述：跟随质点看物理量的变化 → 出现 DT/Dt。

两种表述描述同一物理过程，写出来的方程形式不同（守恒形式 vs 非守恒形式），这一点在第 1 节课 强调”如何描述物理过程”时提到过。

三、PDE 分类（补充，笔记没写但必须知道）

二阶线性 PDE Auxx​+2Buxy​+Cuyy​+Dux​+Euy​+Fu=G 按判别式 Δ=B2−AC 分类：

类型判别式典型方程定解条件
椭圆型Δ<0Laplace uxx​+uyy​=0、Poisson全部边界上给边界条件
抛物型Δ=0热传导 ut​=a2uxx​边界条件 + 初始条件
双曲型Δ>0波动 utt​=a2uxx​边界条件 + 两个初始条件

本课程主线：椭圆型（稳态导热、静力弹性问题，笔记 P2、P3、P8–P12）+ 抛物型（瞬态导热，笔记 P1、P2 的时间项）。双曲型（波动/地震）在后续课程或 《工程地震学》里出现，差分参考书第 7 章专门讲。

四、适定性与误差来源（理解”为什么强调收敛性”）

  • 适定性：解存在、唯一、且连续依赖数据。Hadamard 意义下，椭圆型边值问题在合理条件下是适定的； 反问题（如由地面运动反演震源）往往不适定，需要正则化。
  • 三类误差：
    1. 模型误差（方程本身是近似，如忽略温度对 k 的影响）；
    2. 离散误差（用差分/插值代替连续算子，O(h2) 之类，这门课的理论主线）；
    3. 舍入误差（浮点运算，见 P7 讨论的条件数 Cond(A)=∣λmax​∣/∣λmin​∣）。

记忆点：离散误差靠加密网格/提高阶数减小；舍入误差反而随网格加密而放大（条件数增大）。 这两者的矛盾是数值方法里永恒的张力，笔记 P7 专门写了这一点。

五、复习要点（P1 层面）

  1. 能默写热对流扩散方程并逐项说出物理含义。
  2. 能说清”守恒律 + 傅里叶定律 → 控制方程”的推导顺序。
  3. 能对比五种数值方法的适用场合（至少说出有限元相对差分法的两个优势）。
  4. 能按判别式给 PDE 分类，并说出各自的定解条件格式。

六、预习衔接

下一节开始把所有问题都简化成一维稳态：−dxd​(kdxdT​)=Q， 先看差分解法（P2），再看有限元解法（P4 起）。预习时请把两个工具准备好：

  • Taylor 展开（差分格式的构造与截断误差）；
  • 分部积分 / Gauss-Green 公式（弱形式的核心，P4、P10 各用一次）。
