04 · 有限元法入门：一维杆件例子与变分原理（笔记 P4）

对应原始笔记：原图/笔记-04.jpg （本页含 4 张黑板照片：左上是弹性杆受力图，中部是”离散模型 + 平衡方程 + 矩阵形式 + 边界条件”， 下部两块版书是”内积形式 → 分部积分 → 弱形式”）

这是整门课的转折点：从”用差商代替导数”转到”用变分原理 + 分片插值造方程”。 老师用的引例就是教科书第一章第一节那个**弹性杆（受自重与端部拉力）**的例子。

一、笔记原文转写

主题：有限元方法的第一个例子。

有限元方法=能量/弱形式古典变分原理​​+形函数与单元分片多项式插值​​（两者的"完美结合"）

力学符号：E（弹性模量）、S(x)（横截面积）、ρ（密度）、g（重力加速度）、 P（端部集中力）、u(x)（轴向位移）。

σ=Eε=Edxdu​（胡克定律）,ε=dxdu​（几何方程）

对节点（node）i，它同时属于左侧单元 [xi−1​,xi​] 与右侧单元 [xi​,xi+1​]：

ESdxdu​​xi−​​=ESli​ui​−ui−1​​,ESdxdu​​xi+​​=ESli+1​ui+1​−ui​​

第 i 点的力平衡方程（i=1,⋯,n−1）：

(21​ρgSli​+21​ρgSli+1​)+ESli+1​ui+1​−ui​​−ESli​ui​−ui−1​​=0

两个端点的方程：

21​ρgSl1​+ESl1​u1​−u0​​−R=0(i=0, 第一类 强制边界) 21​ρgSln​−ESln​un​−un−1​​+P=0(i=n, 第二类 自然边界)

平衡方程（强形式）：

⎩⎨⎧​dxd​(ESdxdu​)+ρgS=0,u=0,ESdxdu​=P,​0<x<Lx=0x=L​

变分（能量法）与内积形式：

∫0L​[dxd​(ESdxdu​)+ρgS]uˉdx=0∀uˉ∈C01​([0,L])

笔记写着”Δ 有限元方法 → 内积形式（弱形式）“：先取 [0,L] 上可积的函数， 再取任一检验函数 uˉ(x)；C1[0,L] 表示在 [0,L] 上一阶连续可微。

二、例子完整推导（把笔记跳的物理步骤补齐）

2.1 建模：三类方程

一根竖挂的均质弹性杆，上端固定、下端受拉力 P，同时受自重 ρgS 作用， 求轴向位移 u(x)。标准三套方程：

方程表达式来源
几何方程（应变-位移）ε=dxdu​小变形假设
本构方程（应力-应变）σ=Eε=Edxdu​胡克定律
平衡方程（内力-外力）dxd​(ESdxdu​)+ρgS=0取微元受力平衡

注意：这三个方程的结构和 P1–P3 热传导完全平行： 傅里叶定律 q=−k∇T ↔ 胡克定律 σ=Eε； 能量守恒 ↔ 动量平衡；温度 T ↔ 位移 u。 所以从差分换到有限元，物理背景变了，数学结构没变。

2.2 边界条件的分类（这段是重点）

位置条件类别力学术语有限元里的叫法
x=0u(0)=0第一类位移已知（固定端）强制边界条件 / 本质边界条件（Dirichlet）
x=LESu′(L)=P第二类力已知（自由端受力）自然边界条件（Neumann）
任意边界ESu′+ku=g第三类弹簧支承混合边界条件（Robin/Cauchy）

为什么叫”强制”和”自然”？

  • 强制边界条件必须在试探函数空间里事先满足（即把 u(0)=0 硬塞进解的表达式中）；
  • 自然边界条件不需要预先满足，它会在弱形式的分部积分过程中自动浮现。 P8 会把这句话写给第二、三类边界条件。

2.3 离散模型：把连续杆换成”糖葫芦”

笔记左侧黑板照片上的物理模型是这样的（教材里的说法是”弹簧-糖葫芦串”）：

  1. 把 [0,L] 分成 n 个小段（单元）ei​=[xi−1​,xi​]，端点称为节点；
  2. 每个单元的自重集中到两端节点（各一半）：21​ρgSli​；
  3. 每个单元像一根弹簧，刚度 ki​=li​ES​；
  4. 每个节点处”所有作用力的合力为零”——即节点力平衡。

由此得到笔记里那三行方程（li​=xi​−xi−1​）：

内节点 i=1,…,n−1：

两个单元各分给节点 i 的自重21​ρgSli​+21​ρgSli+1​​​+右侧单元的作用力li+1​ES​(ui+1​−ui​)​​−左侧单元的作用力li​ES​(ui​−ui−1​)​​=0

左端点 i=0（有支座反力 R）：

21​ρgSl1​+l1​ES​(u1​−u0​)−R=0

右端点 i=n（有集中力 P）：

21​ρgSln​−ln​ES​(un​−un−1​)+P=0

写成矩阵就是 [K]{u}={F}，其中 [K] 的每一行之和为零（刚体平移不产生内力）， 这一性质叫刚度矩阵的奇异性，必须靠第一类边界条件消除。P9 会再次遇到”ui​=ui−1​ 时贡献为零”。

2.4 等价性：为什么”节点力平衡”能代表”微分方程”

把上面三行平衡方程按内点整理，用 Δx→0 的极限去看：

li+1​ES​(ui+1​−ui​)−li​ES​(ui​−ui−1​)≈dxd​(ESdxdu​)Δx

即”相邻单元内力之差 = 该点外荷载”。这正是微分方程 dxd​(ESu′)+ρgS=0 的差分近似。 所以离散模型与连续模型在 h→0 时一致（相容性）。这就是笔记上”Δx→0：处处成立”的意思。

三、从强形式到弱形式（笔记的核心戏份）

3.1 强形式（原微分方程形式）

⎩⎨⎧​dxd​(ESdxdu​)+ρgS=0,u=0,ESdxdu​=P,​0<x<Lx=0x=L​

要求解 u∈C2[0,L]（二阶连续可微）——这个要求对后面要用的分片线性插值太苛刻（它只有 C0）。

3.2 内积形式（加权余量）

取任意检验函数 uˉ(x)∈C01​[0,L]（一阶连续可微，且在 x=0 处为零，即 uˉ(0)=0）， 把方程乘上 uˉ 再在 [0,L] 上积分：

∫0L​[dxd​(ESdxdu​)+ρgS]uˉdx=0∀uˉ∈C01​

这一步的合法性：如果 u 是强形式的解，则每个 x 处方括号内为 0，积分当然为 0； 反过来如果对所有 uˉ 积分都为 0，则方括号内必处处为零（变分法基本引理）——所以两者等价。

3.3 分部积分 → 弱形式

对上式第一项分部积分（笔记写的”分部积分”）：

∫0L​dxd​(ESdxdu​)uˉdx=[ESdxdu​uˉ]0L​−∫0L​ESdxdu​dxduˉ​dx

边界项利用 uˉ(0)=0（这就是检验函数为什么必须取 C01​）和自然边界条件 ESu′(L)=P：

[ESu′uˉ]0L​=ESu′(L)uˉ(L)−ESu′(0)=0uˉ(0)​​=Puˉ(L)

代回去，得到弱形式（广义解形式）：

∫0L​ESdxdu​dxduˉ​dx=∫0L​ρgSuˉdx+Puˉ(L)​∀uˉ∈C01​[0,L]

（笔记里写成 ∫0L​ESu′uˉ′dx=∫0L​ρgSuˉdx+Puˉ(L)，同一个式子。）

3.4 弱形式”弱”在哪里（这段笔记只有箭头，必须自己补）

对比项强形式弱形式
对 u 的光滑性要求C2（二阶导数存在）C1 甚至只需 H1（一阶导数平方可积）
出现几阶导数两阶导数两边都只有一阶导数（对称）
边界条件全部硬性要求第一类必须满足；第二类自动包含
适用空间经典解广义解/弱解（可含”尖点”的分片函数）

正因为只有一阶导数，分片线性函数（在节点处导数不连续）才能作为合法候选解。 这就是老师说”变分原理 + 分片多项式插值 = 完美结合”的数学原因。

四、三个视角：它们是同一件事

笔记在同一页里混用了三个词——加权余量/Galerkin、虚功原理、能量泛函极小——它们等价，值得理清：

  1. 虚功原理：把 uˉ 解释为虚位移，方程说的是”外力在虚位移上做的功 = 内力在虚应变上做的功”。 Puˉ(L) 就是端部力做的功。
  2. Galerkin 法（加权余量法）：用试探函数本身作为权函数 uˉ=δu， 要求残差与试探函数空间正交。
  3. 能量泛函极小（Ritz 法）：定义总势能
Π(u)=∫0L​2ES​(dxdu​)2dx−∫0L​ρgSudx−Pu(L)

（第一项是应变能，后两项是外力势能）。Π 取极小值的充要条件就是上面的弱形式： δΠ=0∀uˉ 展开后正好得回弱形式。这就是笔记上写的”Δ 变分（能量法）”。

一句话记忆：弱形式 = 虚功方程 = 能量极小的一阶变分条件。 在弹性力学里它叫最小势能原理，在数学里它叫 Ritz/Galerkin 法，在有限元里它是”造方程”的出发点。

五、几个容易被忽略的细节

  1. 为什么检验函数取 C01​ 而不是 C1？ 只有让 uˉ(0)=0 才能消掉 x=0 处那个未知的反力项 ESu′(0)， 否则弱形式里会出现边界反力（那是支座提供的，不该出现在”已知量”里）。
  2. 第一类边界条件怎么处理？ 在有限元计算中把 u0​=0 作为已知量代入（P5–P7 的处理方式）， 或者构造满足 u(0)=0 的试探空间。
  3. 解的正则性：笔记最后写 C1[0,L]，”0,L 上一阶连续可微”。 更准确的提法是 u∈H1(0,L)（Sobolev 空间，一阶广义导数平方可积）， 教材第二章 §1.6 讨论的就是这个空间；分片线性函数属于 H1 但不属于 C1。
  4. 体力项的符号：自重是体力（沿杆分布），P 是集中力（端部）， 在弱形式里分别贡献 ∫ρgSuˉdx 与 Puˉ(L)——形式上都是”外力做功”。

六、复习要点

  1. 能写出弹性杆问题的强形式三件套（几何、本构、平衡）及边界条件。
  2. 能从强形式出发，用”乘检验函数 + 分部积分”推出弱形式，并说清边界项是怎么消掉的。
  3. 能解释”强制边界条件”与”自然边界条件”的区别，并各举一例。
  4. 能写出总势能泛函 Π(u)，并说明它取极小等价于弱形式。
  5. 能说出弱形式相比强形式的三个好处（光滑性降低、自然边界自动满足、便于分片插值）。

七、预习衔接

知道了弱形式，下一步就是把 u 和 uˉ 都写成分片多项式的组合，把弱形式变成矩阵方程。 下一节（P5–P7）要做：

  1. 构造形函数 Ni−1​(x),Ni​(x) 并验证 Ni​(xj​)=δij​；
  2. 计算单元刚度矩阵 [K]e=∫ES[B]T[B]dx（线性单元就是 lES​[1−1​−11​]）；
  3. 装配成总刚度矩阵，处理边界条件，求解，后处理。

预习工具：

  • 线性插值的 Lagrange 形式与”单位分解”性质（N1​+N2​≡1）；
  • 教材：姜礼尚第一章 §1（离散模型、虚功方程）→ 第二章（插值与基函数）。
