02 · 一维稳态热传导的有限差分法（笔记 P2）

对应原始笔记：原图/笔记-02.jpg（左半页=控制方程与三类边界条件，右半页=差分格式与三对角方程组）

这一页是整门课的”差分法样板”：从 PDE 出发 → 定解条件 → 网格 → 导数近似 → 代数方程组 → 方程组解法。 后面所有差分内容都是这套流程的重复。

一、笔记原文转写

1. 控制方程与定解条件

⎩⎨⎧​ρc∂t∂T​=∇⋅(k∇T)+Q,T=T0​,​控制方程（in Ω）边界条件（on ∂Ω）​

令时间项为零（ρc∂T/∂t=0）即得稳态方程，一维情形写为（Q 为体热源， q 为边界热流）：

dxd​(kdxdT(x)​)+Q(x)=0,−kdxdT​=q

笔记旁注：“Gauss 公式（如何引入）——理解 PDE / 如何表述物理过程”，即用散度定理把 积分形式的守恒律化为微分形式，见下文 2.1。

2. 物质导数与热对流扩散方程

T=T(x,y,z,t) 关于 t 的全导数（物质导数）：

dtdT​=∂x∂T​dtdx​+∂y∂T​dtdy​+∂z∂T​dtdz​+∂t∂T​=∂t∂T​+V⋅∇T

其中 V 为流体质点的速度；固体内部无宏观流动，对流项消失。于是热对流扩散方程

ρc(∂t∂T​+V⋅∇T)=∇⋅k∇T+Q

两种立场（笔记写”参考标价”，应为”参考系/表述”）：Euler 描述、Lagrange 描述。

一维稳态 + 两端第一类边界条件，即一个二阶非齐次常微分方程的两点边值问题：

⎩⎨⎧​dxd​(kdxdT(x)​)+Q(x)=0,T(x1​)=T1​,T(xn​)=Tn​​x1​≤x≤xn​​

3. 三类边界条件

  • 一类：边界上的温度值 T∣∂Ω​=T0​；
  • 二类：边界上的热流 −k∂T/∂n=q（q=0 为绝热）；
  • 三类：混合（对流换热）−k∂T/∂n=h(T−T∞​)。

4. 差分近似

把 [x1​,xn​] 作 n 等分，h=Δx，节点为

x1​<x2​<⋯<xn​,Δx=nxn​−x1​​,xi​=x1​+(i−1)Δx

在任意一点 xi​ 处，用相邻节点值代替导数（向前 / 向后 / 中心差分）：

dxdT​​x=xi​​≈ΔxTi+1​−Ti​​,dxdT​​x=xi​​≈ΔxTi​−Ti−1​​,dxdT​​x=xi​​≈2ΔxTi+1​−Ti−1​​

二阶导数（二阶中心差分）：

dx2d2T​​i​=Δx21​(Ti+1​−2Ti​+Ti−1​)

对每个内点 i=1,⋯,n−1：

Δx2k​(Ti+1​−2Ti​+Ti−1​)=Qi​

写成 n 阶方程组（边界项已移至右端）：

Δx2k​​−21​1−2⋱​1⋱1​⋱−21​1−2​​​T1​T2​⋮⋮Tn​​​=​Q1​−Δx2k​T0​Q2​⋮⋮Qn​+Δx2k​Tn+1​​​

笔记此处把两端边界值记为 T0​ 与 Tn+1​，未知量是内部的 T1​∼Tn​（共 n 个）； 若把两端节点 x1​,xn​ 也计入节点（下文 2.4 节的做法），则未知量为 T2​∼Tn−1​。

这个 n 阶方程组用直接法（追赶法）或迭代法求解。解出节点值后，用线性插值恢复连续解：

T(x)=ΔxTi​−Ti−1​​(x−xi−1​)+Ti−1​

5. 二维与边界条件（本页下半页，接 P3）

⎩⎨⎧​∇⋅(k∇T)+Q=0,T=T0​,−k∂n∂T​=q,​T=T(x,y)边界上（温度已知，第一类）边界上（热流已知，第二类）​
  • 处理流程：第一步离散（规则网格），第二步差商代微商；
  • q=0 即绝热边界 ∂T/∂n=0。

梯度算子的定义：

∇=∂x∂​i+∂y∂​j+∂z∂​k

二维时

∇⋅(k∇T)=∇⋅[k∂x∂T​i+k∂y∂T​j]=∂x∂​(k∂x∂T​)+∂y∂​(k∂y∂T​)

三维时

∇⋅(k∇T)=(∂x∂​k∂x∂​+∂y∂​k∂y∂​+∂z∂​k∂z∂​)T

二、补充推导（笔记跳过的部分）

2.1 从积分守恒到微分方程：Gauss 公式怎么”引入”

笔记只写了”Gauss 公式（如何引入）“，这里补上完整逻辑。 取区域 Ω 内任一控制体 V，稳态下净流出热量必须等于内部产热：

∮∂V​q⋅ndS=∫V​QdV⟹∫V​(−∇⋅(k∇T)−Q)dV=0

由于 V 任意，被积函数必须处处为零，于是

−∇⋅(k∇T)=Q

即笔记载的 ∇⋅(k∇T)+Q=0。（笔记里写的 ∮q⋅ndS=∫V​QdV 与 ∇⋅q=−Q 是同一件事的两种写法。）

Gauss（散度）定理的一般形式（P10 会用三维/二维版本）：

∫Ω​(∂x∂P​+∂y∂Q​+∂z∂R​)dΩ=∮∂Ω​(Pcos(n,x)+Qcos(n,y)+Rcos(n,z))dS

一句话总结：Gauss 公式是把”体上的微分关系”和”面上的通量”互相转换的桥梁。 这与后面有限元的”分部积分把二阶导数降到一阶”是同一枚硬币的两面——这一点老师说”理解 PDE、 如何表述物理过程”就是这个意思。

2.2 一维稳态方程的具体形式

由 dxd​(kdxdT​)+Q=0 展开，若 k 为常数：

kdx2d2T​+Q=0⟺dx2d2T​=−kQ​

物理意义：温度分布是凸的（Q>0 时开口向下），曲率由内部产热决定。

2.3 三种差分格式的 Taylor 展开推导与截断误差

笔记只写了结论。用 Taylor 展开（Ti​=T(xi​)，h=Δx）：

Ti+1​=Ti​+hTi′​+2h2​Ti′′​+6h3​Ti′′′​+O(h4) Ti−1​=Ti​−hTi′​+2h2​Ti′′​−6h3​Ti′′′​+O(h4)
格式公式截断误差阶
向前差分Ti′​≈hTi+1​−Ti​​−2h​T′′(ξ)O(h)
向后差分Ti′​≈hTi​−Ti−1​​+2h​T′′(ξ)O(h)
中心差分Ti′​≈2hTi+1​−Ti−1​​−6h2​T′′′(ξ)O(h2)
二阶中心差分Ti′′​≈h2Ti+1​−2Ti​+Ti−1​​−12h2​T(4)(ξ)O(h2)

推导要点：向前式由 Ti+1​ 的展开直接解出 Ti′​；中心式把两式相减（消去 Ti′′​）； 二阶中心式把两式相加（消去 Ti′​，因为 Ti+1​+Ti−1​=2Ti​+h2Ti′′​+O(h4)）。

面试/考试常问：为什么中心差分比向前差分高一阶？因为一阶误差项 T′′ 在相减时被消掉了。 代价是它不适用于原点附近的对流占优问题（会产生振荡），这一点在差分参考书第 2 章讨论。

2.4 完整差分方程组（把边界条件代入）

内点 i=2,…,n−1（n 个节点，1 和 n 是边界点）：

h2k​(Ti+1​−2Ti​+Ti−1​)=Qi​

写成矩阵形式（与笔记里的三对角阵一致，注意笔记把边界项移到了右端）：

[A]{T}={F},A=h2k​​−21​1−2⋱​1⋱1​⋱−21​1−2​​(n−2)×(n−2)​,Fi​=Qi​+h2k​(边界贡献)
  • 第一类边界条件（T1​=Ta​, Tn​=Tb​ 已知）：边界项移到右端，未知量只留内点， 矩阵降为 (n−2)×(n−2)： F2​=Q2​+h2k​Ta​，Fn−1​=Qn−1​+h2k​Tb​。
  • 第二类边界条件（端点给定热流）：用虚拟节点法或单侧差分，见下节。

三、三类边界条件（差分实现）

类型数学形式物理含义差分处理
第一类 Dirichlet（本质/强制）T∣∂Ω​=T0​边界温度已知直接代入/消元，或”对角置 1、右端置值”修改矩阵
第二类 Neumann−k∂n∂T​=q边界热流已知（q=0 即绝热）虚拟节点 T0​=2T1​−T2​（把 Ti−1​ 从方程中消去）或单侧差分
第三类 Robin/Cauchy−k∂n∂T​=h(T−T∞​)对流换热半节点离散后并入矩阵对角（笔记 P3 写的”+α”就是这一步）

虚拟节点法详细写一遍（第二类，左端 x1​）：

−k2hT2​−T0​​=q⇒T0​=T2​+k2hq​

把它代回 i=1 的差分方程 −2T1​+T2​+T0​=kh2​Q1​，得到

−2T1​+2T2​=kh2​Q1​−k2hq​

即边界点方程也进入了方程组，只是形式与内点不同。这就是笔记 P2 右下角 “边界条件（第二类）“那两个小图想表达的东西。

四、离散解的恢复（笔记最后两行）

解出节点值后，笔记写了

T(x)=ΔxTi​−Ti−1​​(x−xi−1​)+Ti−1​

这就是分片线性插值——把离散点用直线连起来。注意一点：

  • 差分法通常只关心节点值，这个插值是”事后补的”；
  • 有限元法（P5）恰恰相反，一开始就把这个插值当作未知解的表达式：u(x)=[N]{u}。

这个对比是理解”差分 vs 有限元”最省力的一句话：差分是先离散算子，再解节点值； 有限元是先把解写成插值，再让残差正交。

五、常见误区

  1. 符号不要混：∇⋅(k∇T)+Q=0 与 −∇⋅(k∇T)=Q 是同一式； 傅里叶定律里那个负号是 q=−k∇T 的负号，别和方程里的符号重复加。
  2. Q 的单位：[W/m3]，是体热源密度，不是热流密度 [W/m2]。
  3. 网格编号：笔记从 x1​ 开始（不是 x0​），所以内点是 i=2,…,n−1 共 n−2 个未知量。
  4. 中心差分在边界不能用：边界只有一侧的邻居，必须退化到向前/向后或虚拟节点。
  5. “绝热”的写法：绝热 = 第二类边界条件中 q=0，即 ∂T/∂n=0，不是 T=T0​。 笔记 P2 右下角小图把 T=T0​ 标成”绝热边界”是速记时的串位，以本表为准。

六、复习要点

  1. 能独立用 Taylor 展开推出三种一阶差分与二阶中心差分，并写出截断误差的阶。
  2. 能写出三对角方程组的矩阵形式，并说明第一类边界条件如何进入右端。
  3. 能用虚拟节点法处理 Neumann 边界。
  4. 能解释”为什么稳态热传导方程是椭圆型方程、为什么定解条件给在整条边界上”。
