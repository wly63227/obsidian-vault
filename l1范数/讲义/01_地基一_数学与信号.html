1. 从加速度到位移：两次积分，和它带来的放大

1.1 三者的关系

位移 d(t)、速度 v(t)、加速度 a(t) 是同一条曲线的三种”看法”：

v(t)=∫0t​a(τ)dτ,d(t)=∫0t​v(τ)dτ

反过来：加速度是速度的变化率，速度是位移的变化率。

生活类比：加速度是”油门踩多深”，速度是”车速”，位移是”走了多远”。知道每一刻的油门，理论上就能算出车走了多远——但要累加两次。

1.2 计算机里怎么做积分

记录是离散的：采样率 fs​（每秒多少个点），采样间隔 ΔT=1/fs​。两种常用做法：

方法公式特点
矩形累加（cumsum）vi​=ΔT∑k≤i​ak​最快、最常用，论文与代码里基本都是它
梯形积分（trapz）vi​=ΔT(2a0​+ai​​+∑k<i​ak​)略准，本项目的实验脚本用它

两者只差首尾半格，量级上等价。你只要记住：积分在程序里就是”乘 ΔT 再累加”。

1.3 关键现象：常数漂移被放大成抛物线

假设真实加速度是 a(t)，但记录里混入了一个常数偏移 b（这就是最简单的一种基线漂移）：

a记录​=a(t)+b

积分一次：v记录​=v(t)+bt —— 多出一条斜线； 再积分一次：d记录​=d(t)+21​bt2 —— 多出一条抛物线。

所以：漂移在加速度域几乎看不见，在速度域变成斜率，在位移域变成抛物线。 这条”三域形态”是所有论文插图的几何基础。

数值验证（来自 ../experiments/drift_demo.py 的 A 组，200 Hz / 60 s）：

量数值积分结果解析式
速度末值误差（b=0.01 gal）+0.5999 cm/sbT=0.6 cm/s
位移末值误差+17.997 cm21​bT2=18 cm

这就是四篇论文引言里反复引用的 Chiu (1997) 例子。

1.4 为什么”看不见”：量级直觉

近断层强震记录的峰值加速度大约 100∼1000 gal。而 0.01 gal 的漂移只占万分之一。

就像一面 10 米宽的墙上贴了 1 毫米的纸条——你站在 3 米外根本看不见，但它会让”墙的对称轴”偏掉。

3. 范数：L1、L2，以及”为什么 L1 会让很多数变成 0”

3.1 定义

对一个向量 x=(x1​,…,xn​)：

名称写法含义别名
L1 范数$|x|_1=\sum_ix_i$
L2 范数∥x∥2​=∑i​xi2​​平方和开根号欧氏长度
L0 伪范数∥x∥0​=#{i:xi​=0}非零个数真正想数的”段数”（不可解）

3.2 几何直觉（这一节请务必在纸上画一遍）

  • L2 球（∥x∥2​≤c）是一个圆；
  • L1 球（∥x∥1​≤c）是一个菱形（正方形转 45°），它的”尖角”正好落在坐标轴上。

最小化”数据拟合误差 + 惩罚”时，几何上等于：让一个椭圆的等值线不断膨胀，直到第一次碰到惩罚球的边界。圆是光滑的，碰点一般落在斜着的方向上（所有分量都不为零）；菱形有尖角，碰点很容易正好落在坐标轴上（某些分量恰好为零）。

这就是 L1 产生稀疏解（很多个 0）的几何原因。稀疏 = 只有少数时刻有跳变。

3.3 一行就能用的公式：软阈值

L1 问题里反复出现这一步（叫 prox 或软阈值）：

soft(z,κ)=sign(z)max(∣z∣−κ,0)

读法：

  • 绝对值比 κ 小的分量 → 直接变成 0（“丢掉”）；
  • 比 κ 大的分量 → 朝零收缩 κ（“砍掉一截”）。

L2 惩罚对应的操作是按比例缩小（z/(1+κ)），永远不会真的变成 0。

对小分量的处理结果
L2按比例缩小一大堆很小的非零值
L1直接归零少数非零值（稀疏）

3.4 L1 的代价

软阈值对大分量也会”砍掉一截”，所以 L1 的解是有偏的（幅值偏小）。这正是 2020 论文那句”任何基线校正都会压制地震信号、使校正位移幅值小于真值”在数学上的一个来源。

4. 最小二乘：什么叫”拟合”

想把数据 b 用模型 Ax 表示，最常用的标准是让误差的平方和最小：

minx​∥Ax−b∥22​

它的解满足正规方程 ATAx=ATb。

三种情况：

情形说明解
超定（方程比未知数多）一般无精确解唯一最小二乘解
恰定恰好能解精确解
欠定（未知数比方程多）无穷多组解都能拟合得一样好需要额外规则挑一个（正则化来了）

我们的基线问题天生是欠定的：能解释同一段速度的”阶梯基线”有无穷多种。所以必须加一条”偏好”——这就是正则项。

5. 正则化：从岭回归（L2）到 LASSO（L1）

统一的写法：

minx​ 拟合要准∥Ax−b∥22​​​+λ解要"合口味"R(x)​​

R(x)名称偏好典型结果
∥x∥22​岭回归 / Tikhonov分量都别太大平滑、所有分量非零
∥x∥1​LASSO大多数分量正好是 0稀疏、可解释
∥Δx∥1​融合 LASSO / 全变差跳变次数少分段常数（阶梯）

λ 的角色：它控制”信数据”还是”信偏好”。λ→0 完全拟合数据（含噪声）；λ→∞ 完全按偏好走（解被压成常数）。

6. 差分矩阵：把”阶梯”翻译成”稀疏”

6.1 差分

定义基线的一阶差分：

yi​=xi+1​−xi​(i=1,…,n−1)

注意维数：x 有 n 个点，y 只有 n−1 个——少一个，因为它描述的是”相邻两点之间发生了什么”。这就是 2020 论文式 (1) 说出这句话的全部含义：

向量 y 的维数为 n−1。（03_Dai2020_SDEE_L1优化与视觉验证/paper.md p.2，E001/S020）

6.2 “跳变稀疏” = “分段常数”

如果 y 的非零元素只有 2 个（其余都是 0），那么 x 只在两个时刻变过，其余时间保持不变——三个台阶。

x: 第 1 段0  0 0​​ 一次跳变2 2 2​​ 二次跳变−1 −1​​

对应的 y 是 [0,…,0,+2,0,…,0,−3,0,…]：绝大多数是 0。

一句话：∥x∥1​ 惩罚的是”幅值大”，∥Δx∥1​ 惩罚的是”跳变多”。基线校正要的是后者。

6.3 顺便：二阶差分对应”折线”

∥Δ2x∥1​ 小 → x 是分段直线（少拐点）；∥Δx∥1​ 小 → x 是分段常数（少台阶）。

这解释了 Iwan 方法为什么在速度域拟合折线：基线在加速度域是阶梯，积分到速度域就变成折线。

7. 凸性：为什么可以放心交给工具包

  • 凸集：集合内任意两点的连线仍在集合内。
  • 凸函数：函数图像上任取两点连线，曲线总在连线下方（像一个碗）。

为什么重要：

  1. 局部最优就是全局最优——不存在”掉进小坑出不来”的问题；
  2. 对偶理论给出可验证的最优性条件；
  3. 有成熟工具（CVX / CVXPY 等）可以直接解。
表达式凸吗
∥Ax−b∥2​、∥Ax−b∥22​凸
∥x∥1​、∥Δx∥1​凸
两者之和凸（凸+凸）
把 x 换成组稀疏 ∑g​∥xg​∥2​凸（范数是凸的）

关于”唯一性”：论文写”有且只有一个全局最优解”（2019 S010 / 2020 S022），严格来说这只在附加条件下成立：凸问题保证最优值唯一，但最优解的唯一性需要目标函数严格凸，或者 A 的零空间与惩罚项的零空间只交于原点。L1 本身不严格凸（菱形有平坦的边），所以”唯一”要靠 A 的结构来补。复现时如果发现”几乎不唯一”的解，不必惊慌，这是数学性质，不是 bug。

8.2 自己写求解器（本项目实验用的）

没有 CVXPY 也能解。本项目的 ../experiments/l1_toy_demo.py 用 FISTA（加速近端梯度法）求解，核心只有两步：

  1. 沿”拟合误差”走一小步梯度：z←z−η∇(∥Ax−b∥2)；
  2. 对惩罚项做软阈值：z←soft(z,ηλ)。

这就是 §3.3 那个公式的用途。它也是理解”λ 在做什么”的最直观方式：每次迭代都把小的跳变直接砍掉。

9. λ 的尺度问题（本项目的实验证据）

论文把 λ 固定为 1（2019 S011；2020 S024），并说”如何获取合适的超参数一直是个难题”（2019 S024）。

我们的玩具实验给出了一份可验证的证据。实验设置：12 s、50 Hz、真实基线先是 0，4 s 处跳到 +2 gal，8 s 处跳到 −0.5 gal。

λ识别出的跳变次数基线 RMSE / gal位移末值误差 / cm

未校正时位移末值误差是 +41.89 cm；选对 λ 后降到 −0.14 cm，且校正后尾部速度 −0.004 cm/s（满足判据）。

单位实验（关键）：把同一份数据从 gal 换成 m/s²（数值缩小 100 倍）重跑同一网格，能识别出 2 次跳变的 λ 从 1 变成 0.01——平移了 100 倍。

结论（可以直接写进你的研究报告）：

λ 的”合适值”同时依赖数据的单位、采样间隔与记录长度。论文中"λ=1"只在该论文自己的数据尺度下成立，不能当作普适常数照搬。

选 λ 的三种实用做法：

  1. 物理检查法：要求校正后尾部速度接近零、位移尾部平行于时间轴，且基线不要出现明显多余跳变；
  2. 已知真值法：像论文那样人工加已知漂移，用 RMSE 挑 λ（这是最可靠的，也最费事）；
  3. 交叉验证/信息准则：把残差当噪声，用 BIC/GCV 一类的标准挑 λ。

10. 滤波与频域：为什么大震近场不能用高通滤波

10.1 傅里叶视角

任何时程都可以拆成不同频率的正弦波之和。基线漂移是极低频成分（周期比记录长度还长，甚至根本不振荡）。

离散信号能表示的最低频率与最高频率：

  • 最高频率由采样率决定：fmax​=fs​/2（Nyquist 频率）；
  • 最低频率由记录长度决定：fmin​≈1/T。

10.2 高通滤波做什么

高通滤波器把低于截止频率 fc​ 的成分全部去掉。问题在于：永久位移和倾斜漂移都躲在极低频那一块，切不开。

这就是 2022 综述说的：“高通滤波会很好地消除长周期误差，但大震近场的长周期信息与永久位移也会被一起滤掉”（S010）。

10.3 三个工程细节（综述第 3 节给的清单，S018）

细节做法为什么
滤波器类型Butterworth（稳定性最好）通带平坦、设计成熟
相位非因果（正反各滤一次）零相移，不改变波形形状
端部处理首尾加等长零填充 + 余弦渐变否则积分位移端部会翘起

10.4 截止频率怎么选（Boore 2005 的三条标准，S009）

  1. 记录的傅里叶谱与噪声谱之比 ≥ 3；
  2. 记录谱的长周期部分是否偏离 f−2 的衰减趋势；
  3. 目视检查滤波后加速度二次积分得到的速度/位移是否出现非物理特征。

第 3 条其实就是回到基线校正的两条判据。这说明滤波与基线校正用的是同一套”什么算合格”的标准。

11. 评价工具：相关系数与 Bland-Altman

比较两条位移曲线 D1​、D2​ 时：

工具度量什么局限
Pearson 相关系数 r两条曲线是否”同涨同跌”（线性相关）与”数值是否相等”无关
RMSE / RMSD平均差的大小不反映偏差的方向与趋势
Bland-Altman 图逐点差值 D1​−D2​ 的均值与 95% 一致性界限需要样本足够多

为什么论文要用 B-A 图？ 2020 论文比较的是”新方法校正位移”与”参照位移”，相关系数给到 97.456% / 96.825% / 95.420%（S034）。但相关系数高不代表幅值准：两条曲线可以形状完全一致、幅值整体差 20%。

B-A 图把”差值”直接画出来：均值线的位置告诉你系统性偏差（例如整体偏小 5 cm），上下界限告诉你随机波动范围。

一句话记忆：相关系数回答”像不像”，B-A 图回答”差多少”。

12. 一页小结

你会用到的概念一句话
两次积分常数漂移 → 速度斜线 → 位移抛物线，误差随时间平方增长
gal1 gal = 1 cm/s²；单位错 100 倍，λ 也要跟着错 100 倍
L1 vs L2L1 把小的压成 0（稀疏），L2 只是按比例缩小
差分惩罚 ∥Δx∥1​ = 惩罚”跳变多” = 结果分段常数
凸性凸问题好解、局部最优即全局最优；解的”唯一性”需要附加条件
求解工具包（CVX/CVXPY）或一阶方法（ISTA/FISTA 的软阈值）
λ控制”信数据”还是”信稀疏”；合适的值随单位、采样率、记录长度变化
