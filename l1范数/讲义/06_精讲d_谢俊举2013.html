精讲 D：谢俊举等（2013）《利用强震数据获取汶川地震近断层地面永久位移》

角色：产品说明书。方法很朴素（单段 v0​ 型），但它展示了三分量记录”从校正到验证再到成图”的完整工程流程——这正是三分量方法最终要交付的东西。 原文精读：../04_Xie2013_汶川近场永久位移/paper.md

0. 一句话定位

64 个台站的三分量记录 → 逐分量 v0​ 型基线校正 → 永久位移 → 与 41 个 GPS 点及地质考察对比 → 画出近断层位移场。

它的价值不在方法，而在三件事：

  1. 示范三分量数据处理的完整链条；
  2. 示范怎么用独立观测（GPS、地质考察）验证，以及验证有多大局限；
  3. 示范结果怎么呈现（三分量波形图 + 12 站对比表 + 位移场矢量图 + 随断层距剖面图）。

2. 摘要（S001）：三个成果型结论

结论内容（概括）
①断裂上、下盘东西相向运动剧烈：下盘的 51SFB、51MZQ、51JYH 台东西向位移为负（向西），其中 51SFB 最大，达 1.49 m；上盘的 51WCW 台向东 1.26 m
②位移分布以映秀—北川断裂为核心呈相向运动；东西方向位移大于南北方向
③大的永久位移集中在断裂附近的狭长范围内，离开发震断裂衰减很快

注意：摘要给的是地震学结论（位移场特征），不是方法学结论。对你的意义在于：它示范了要把三分量处理结果做到什么程度才算”可发表”。

3. 引言（S002–S003）：为什么必须校正

S002 —— 什么条件下可以直接积分

概括：对于宽频带数字强震仪，如果仪器场址没有发生同震地面变形、且环境与仪器噪声很低，速度与位移可以由加速度直接积分得到；但当地面发生变形（近断层大震必然发生），强震仪会倾斜，导致基线偏移；加速度上影响很小，积分后逐步放大。

这句话是”能不能直接积分”的分水岭：任务从”常规处理”变成”必须校正”。

S003 —— 前人方法的三点评述

方法评述关键局限
Iwan 等（1985）针对仪器磁滞效应；认为漂移在加速度大于 50 cm/s² 时出现”分段方法带有一定主观性”
Chiu（1997）高通滤波滤波后只能得到部分永久位移
Boore（2001）、王国权和周锡元（2004）取速度末尾拟合直线与时间轴的交点作为漂移初始时刻，分段校正本文采用的就是这条路线

读法：这一段其实就是 2022 综述那两条方法路线的简化版。区别在于：综述给出全领域地图，本文只挑自己要用的那一条。

4. 第 1 节：强震记录与 GPS 数据（S004–S005，图 1）

4.1 数据规模（记住这几个数）

环节数量/参数
汶川主震记录的震相完整三分量记录420 组
加速度 > 1 m/s² 的台站50 多个
断层距 < 100 km 的三分量记录46 组
本文选用的近断层台站64 个（三分量）
对比用的 GPS 台站41 个
仪器ETNA（±2 g、18 bit、200 点/s）与 MR2002（±2 g、18 bit、200 或 500 点/s）

64 台 × 3 分量 = 192 条时程，外加 41 个独立 GPS 参考点。这就是三分量方法的理想测试集形态：多台站、多分量、有独立真值。

（图 1，p.4：三角形为强震台、圆点为 GPS 台。读这张图要关注”配对几何”——台站与 GPS 点距离越近，对比越可靠。）

5. 第 2 节：方法与原则（S006–S009，E001，图 2–图 6）

5.1 方法分类与取舍（S006）

概括：方法分两类——滤波类（USGS 基础处理程序、Chiu 的高通滤波）与分段校正类（Iwan 速度直线拟合）。滤波类不能保留永久位移，不适合近断层强震记录。

这个取舍应该背下来：目标决定方法，目标是永久位移，就不能用滤波。

5.2 具体做法（S007，E001）

vf​=v0​+af​t

步骤做法
1在速度时程的末尾段拟合一条直线 vf​=v0​+af​t
2直线与时间轴的交点 tf​=−v0​/af​ = 基线开始偏移的时刻
3直线的斜率 af​ = 该段的加速度基线偏移量
4在基线开始偏移的加速度段中减去 af​，完成校正

这就是 v0​ 型单段校正的全部内容：一条直线定一个交点、一个斜率。

与本项目实验对照：C 组把 800 cm 的位移误差压到 13 cm，识别出的漂移起始时刻是真值 20 s → 19.33 s（滞后 0.67 s），幅值 1.0 gal → 0.984 gal。这种”轻微滞后 + 幅值略有偏差”正是这一类方法的典型误差形态，也是 2020 论文里 El Centro 记录”滞后约 0.5 s”的同一种现象。

（图 2，p.5：以 51MXD 台为例，末尾段拟合直线 → 交点给出漂移起始时刻 → 斜率给出漂移量。整篇文章的方法就这一张图。）

5.3 校正判据（S008）——这一段的措辞对三轴极其重要

概括：判据有两条——① 地震动停止后速度是否为零（记录末尾速度是否趋零）；② 在没有永久位移的情况下，记录末尾位移是否为零；若台站位置发生永久位移，末尾值就是该方向的永久位移；且永久位移主要发生在强震阶段，因此末尾阶段位移应基本保持不变，即曲线大致平行于时间轴。

为什么这段是本篇最值得抄的段落：

  • 它明确写出”有永久位移时，末尾值就是永久位移”——三分量处理时，垂直分量的真实沉降必须保留；
  • 它给出可操作的检查动作：看末尾速度是否归零、末尾位移是否水平。

5.4 三分量结果的标准版式（S009、图 3、图 4）

概括：以 51PXZ 与 51MXD 为例，给出每台每个分量三行图（加速度 / 速度 / 位移），并在位移末尾标注 Dlast​（永久位移）。

建议：你以后的三分量结果图直接复用这个版式——三分量 × 三物理量，位移末尾标 Dlast​，速度图检查尾部归零。

5.5 四个近断层台站的对比（S010，图 5、图 6）

概括：给出 51WCW、51SFB、51MZQ、51JYH 四个近断层台站校正后的三分向速度与位移时程。

三轴读图要点（务必掌握）：

  1. 速度末尾是否稳定在零附近（判据 ①）；
  2. 位移末尾是否平行于时间轴（判据 ②）；
  3. 垂直分量的末尾是否保留了非零值（真实沉降）；
  4. 水平两轴的位移方向是否构成合理的相向运动。

6. 第 3 节：与 GPS 及地质考察的比较（S010–S012，表 1，图 7、图 8）

6.1 12 站对比表（表 1，p.8）

作者选了 12 个强震台站与 GPS 对比，入选标准是”参考 GPS 台站距强震台在 30 km 以内”。表的列是：强震台、断层距、强震 EW/NS/UD、GPS 台、台站距、GPS EW/NS/UD。

三个近距配对（<4 km）是定量比较的核心：

强震台台站距强震 EW / NS / UD（cm）GPS EW / NS / UD（cm）
51PXZ0.3 km−45.7 / 52.0 / −11.1−56.3 / 42.6 / −8.1
51MXD0.3 km26.7 / −5.3 / −3.631.0 / −3.4 /（无资料）
51WCW3.7 km67.5 / −38.2 / −30.164.0 / −37.4 / −22.8

读法：最近距离的两个配对，水平向差别在 10 cm 量级，垂直向在 3 cm 量级——这可以作为你以后做三分量验证时的精度基准线。

6.2 一个”GPS 不吻合、地质考察吻合”的经典案例（S010）

51SFB 位于主断裂下盘、距断层 10.4 km：校正后得到 EW −1.51 m、NS 0.93 m、UD −0.49 m（向下）。

  • 与 GPS 参考台 H044（0.12 m）、H049（0.22 m）差别很大；
  • 但与该处地质考察得到的垂直位移 0.5–0.6 m 吻合。

原因：51SFB 比 GPS 参考台离断层更近，而位移随断层距快速衰减，所以参考点本身已经”变小”了。

这条案例的价值：它告诉你”不吻合”至少有三种可能——方法误差、参考点含震后蠕变、参考点空间不一致。归因错了，结论就会错。

6.3 验证的现实约束（S011–S012、S014）

概括：

  • 汶川地震中只有 51WCW、51MXD、51PXZ 三个台站的参考 GPS 距离在 4 km 以内；
  • 其它台站只能用 GPS 判断位移的大小范围与方向；
  • GPS 的同震位移由震前震后观测差得到，包含震后蠕变；而强震仪记录的只是触发到记录结束这段时间的永久位移，两者本来就有差别。

建议直接借用这句话作为你论文里的”验证局限”表述模板。

6.4 结果成图（图 7、图 8）

（图 7，p.9：左为强震记录得到的水平位移，右为 GPS 观测；箭头方向 = 位移方向、长度 = 位移量。这就是三分量结果最终要呈现成的矢量场。）

（图 8，p.10：横轴断层距、纵轴东西向位移。用剖面检验”位移随断层距衰减”的整体规律，比单台对比更有说服力。）

7. 第 4 节：讨论与结论（S013–S014）

块要点
S013结论 1–3 即摘要那三条位移场特征（相向运动、东西向大于南北向、集中在断层附近且快速衰减）
S014结论：用强震记录获取地面位移、与 GPS 联合研究近断层位移特征是很好的途径；并再次强调只有三个台站 GPS 参考点在 4 km 以内，其余只能作参考

符号约定提醒（S013 隐含）：结论里”向西为负/向东为正”与坐标方向严格对应。三分量处理时符号写反，位移矢量场会整体反号。

8. 这篇与你后续工作的接口

  1. 方法替换点：把单段 v0​ 型校正换成 L1 稀疏校正，其余环节（逐分量处理、Dlast​ 提取、GPS 对比、成图）全部可以复用；
  2. 数据可用性：汶川 64 台三分量记录 + 41 个 GPS 点可直接作为真实数据验证集；
  3. 验证模板：表 1 的版式 + 图 7/图 8 的成图方式；
  4. 必须记住的差异：垂直分量的永久位移是信号；远距配对的差异不能用来评价方法精度。

9. 组会可能被问到的问题

  1. 为什么不能用高通滤波处理近断层记录？→ 会连永久位移一起滤掉。
  2. 本文方法的两个自由度是什么？→ 拟合直线的斜率（漂移量）与交点（起始时刻）。
  3. 强震记录与 GPS 得到的永久位移为什么会有差别？→ 观测时段不同（GPS 含震后蠕变）、观测点位不同（位移随断层距衰减）。
  4. 三分量处理时最容易犯的错误是什么？→ 把垂直分量的真实沉降当漂移抹掉；符号约定不统一。
  5. 本文对三分量方法的启示是什么？→ 它证明了”逐分量 + 简单方法 + 三分量数据”这条路线可行，也为更先进的方法留下了直接可比的基准。

10. 自测题

  1. 写出 v0​ 型校正的四个步骤，并说明每个量的物理含义。
  2. 用校正判据检查一条校正后的时程，你要做哪两个动作？
  3. 51SFB 的垂直位移 −0.49 m 为什么是信号而不是漂移？给出两条证据。
  4. 表 1 里哪几个配对适合做定量比较？其余配对能说明什么？
  5. 如果把 v0​ 型校正换成 L1 方法，流程中哪些环节需要改、哪些可以原样保留？
