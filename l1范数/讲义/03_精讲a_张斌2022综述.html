精讲 A：张斌、俞言祥（2022）《近场强震动记录基线校正方法》

角色：地图。这是四篇里最该先读的一篇。读懂它，后面三篇就有了坐标。 原文精读：../02_Zhang2022_近场强震动基线校正综述/paper.md 块号规则：S=段落、E=公式、F=图、T=表，可在精读目录的 paper.md 与 source_map.json 里检索。

0. 一句话定位与”读完要带走什么”

一句话：它把”漂移从哪来 → 怎么算合格 → 有哪些解法 → 还缺什么”这条链一次讲清，并给出两个方向（低频误差 / 倾斜旋转）的分类框架。

读完要带走五件事：

  1. 漂移的两大来源，以及它们为什么不能用同一种方法处理；
  2. 那组量级对比：0.06° 倾斜 → 水平约 1 gal → 60 s 累积约 18 m，而垂直只有毫米级；
  3. 两条验收准则（震后速度归零；位移末尾平行于时间轴，可停在非零值）；
  4. 方法谱系：滤波 vs 分段校正，以及”Iwan → Boore v0​ → 各改进 → L1 → 三维”的演化；
  5. 领域留下的两个空白：误差来源无法定量分解、旋转分量无法观测。

2. 摘要：三块（S001–S003）

S001 —— 摆出问题与框架

概括：近场强震记录常有基线偏移；微小的加速度偏移会让积分得到的速度、位移出现非物理特征；本文详细分析低频误差与地面倾斜/旋转两类原因对速度和位移的影响，并讨论校正准则。

为什么作者先讲”两类原因”？ 因为他要论证：这两类原因的处理方式不同——低频误差可以用滤波，倾斜引起的漂移不能。这是全文的骨架。

S002 —— 点出领域空白

概括：在”无法量化不同误差来源的贡献”且”无法同时测量六分量（三个平移 + 三个旋转）“的前提下，作者认为未来方向是用大数据/机器学习，基于 Iwan 原理自动、快速地从海量记录中识别稳定的强震段与结束段。

小白要理解的两点：

  • 六分量观测：现在的强震仪只测三个平移分量（EW/NS/UD），旋转分量基本测不到。倾斜正是”旋转/倾斜”家族的成员，测不到就只能靠模型近似。
  • 作者押注的技术路线是机器学习直接预测 t1​、t2​；而 2019/2020 走的是凸优化自动求解漂移结构。两条路线互为对照，这是你写引言时很好用的叙事。

S003 —— 列出被漂移拖累的四个产出指标

概括：不作处理直接积分，位移末尾可能偏出零基线很多（甚至超过地震动位移本身），导致拿不到可靠的 PGV、PGD、永久位移、长周期加速度反应谱。

这四个指标就是你以后做方法评价时的指标体系，建议直接抄进自己的检查表。

3. 第 1 节：基线偏移的原因（S004–S006，E001–E002）

3.1 原因一：低频误差（S004）

概括：Chiu（1997）认为低频误差是主因，并把它细分为仪器噪声、恒定偏移、背景噪声、初始值、操作误差；仪器噪声的典型来源包括不完善的仪器响应、分辨率不足、采样率不足、电子噪声和基线偏移。

逐项理解：

子项直观解释处理思路
仪器噪声电子器件自身的随机抖动滤波或校正
恒定偏移整条记录被抬高一个常数减常数（但要知道减多少才对）
背景噪声环境振动与仪器底噪滤波
初始值非零记录开头不在零线依赖事前部分来定零线
操作误差人工处理环节引入流程规范化

关键推论：三个通道的电子噪声与初始值彼此独立，但倾斜引起的漂移在水平两轴相关。这一句直接决定了三轴方法该不该”联合建模”。

3.2 原因二：地面倾斜/旋转（S005，E001–E002）

概括：近场地面破裂、隆起、水平位移会让强震仪倾斜；小倾角下，倾斜效应对水平摆正比于 1−cosθ≈θ2/2 之外的部分（即 sinθ≈θ，一阶），对垂直摆则正比于 1−cosθ≈θ2/2（二阶）。

公式逐条：

公式写法符号量纲直觉
E001（式 2）Δg=gθg 重力加速度，θ 倾角gal水平摆对倾斜一阶敏感：歪多少就按比例漏进多少重力
E002（式 3）Δg=gθ2/2同上gal垂直摆二阶敏感：θ 很小时可以忽略

数字（请自己复核一遍，见 02_地基二_物理与观测.md 第 2.3 节）：

  • θ=0.06∘ → 水平 Δg≈1.03 gal → 60 s 累积位移约 18.5 m（综述写 18 m ✔）；
  • 同样角度 → 垂直 Δg≈5.4×10−4 gal → 60 s 累积约 9.7 mm（综述正文写 0.9 mm，疑似单位笔误，量级结论不变）。

记住这一组对比的用途：它就是你以后论证”三分量需要区别对待”时唯一需要的物理证据。

3.3 漂移的形态清单（S006）

概括：原因复杂 → 形态也复杂：单段线性、两段式、曲线式、脉冲型、初始偏移、多段式等。

对你的意义：这是测试集的覆盖清单。2019/2020 只测了单段/两段/多段三种人工噪声；真实数据里还有曲线式与脉冲型。你做新方法时，至少要说明这几类里哪些被你覆盖了。

4. 第 2 节：基线校正方法（S007–S016，E003–E010）

4.1 校正准则（S007）：全领域的”验收标准”

概括：地震动结束时速度趋于零；位移时程末尾段重合于或平行于零轴。

逐条拆解：

  1. 速度趋于零——物理上地面停止运动，速度当然应该回到零。工程上这是一条极好用的自检：把校正后的速度尾部画出来，看它是否稳定在 0 附近。
  2. 位移末尾平行于时间轴——注意是”平行”，不是”等于零”。若台站确实发生了永久位移，末尾就该停在那条水平线上。位移曲线末尾若还在倾斜，说明漂移没扣干净。

为什么这两条能当判据？ 因为它们来自物理，不依赖任何具体方法。任何方法的结果都能用它们来检验。

本项目实验 D 组（../experiments/drift_demo.py）展示了如果这条假设被破坏（尾部速度不为零），连成熟的 v₀ 校正都会给出荒谬结果（−762 cm）。这说明”判据”不是形式要求，而是方法成立的前提。

4.2 高通滤波（S008–S010）

概括三块：

块内容你要记住的
S008高通滤波是抑制长周期噪声最广泛的手段，也是 PEER-NGA 数据库的标准流程；因果滤波会有相位失真，非因果滤波正反向各滤一次可实现零相移非因果 = 零相移
S009Boore（2005）的三条截止频率选取标准：谱比 ≥ 3；检查长周期偏离 f−2 的趋势；目视检查二次积分结果是否非物理第 3 条与校正判据同源
S010高通滤波能去掉长周期误差，但大震近场的长周期信息与永久位移也会被一起滤掉大震近场不能用滤波

为什么”永久位移”会被滤掉？ 因为永久位移在频域里就是零频成分（一条不衰减的常数位移），而高通滤波器的作用正是”把直流和极低频拿掉”。这不是滤波器不好，是任务本身要求与之矛盾。

4.3 Iwan 系方法：一条演化主线（S011–S014，E003–E010）

先把”三域形态”记牢（这是理解全部公式的钥匙）：

加速度域是阶梯 → 速度域是折线 → 位移域是抛物线。

公式逐个讲：

这条主线的读法（把 S012–S014 串起来）：

  1. Iwan 等（1985）：t1​ 取”加速度绝对值为 50 gal 的首个时刻”，物理出发点是仪器磁滞；
  2. Boore（1999/2001）、王国权和周锡元（2004）、Graizer（2005）：必须考虑地面倾斜，并把 t1​ 当成自由参数；t2​ 取”拟合速度直线变零的时间”；
  3. 各种改进（Wu 的平坦度、Akkar、Chao 的能量比 25%/65%、Wang、Lin……）：目标都是减少 t1​、t2​ 的主观性；
  4. Chao 等（2010）：用能量比自动定 t1​、t2​——但这组经验比值来自特定数据集，换地震未必成立（S013 原文自己指出了这个隐患）；
  5. 熊政辉等（2019）：用 L1 稀疏优化自动定段，不依赖固定阈值（S014），并被赵思程等（2019）与 Iwan、BAP 方法做过对比验证；
  6. Tian 等（2019）：倾斜校正 + 累积校正双模式，处理三维强震动（S015）——这是与你的目标最接近的一条线索；
  7. Chanerley 和 Alexander（2010）：小波方法；垂直分量能恢复得”几乎完美”，而水平分量因倾斜影响仍有明显偏差（S016）——又一次印证水平/垂直的不对称。

4.4 一个容易忽略的细节：υ0​ 与 v0​ 是同一个东西

中文文献里 υ0​ 是 v0​ 的排版变体（希腊字母 upsilon 被用来替代 v）。读文献时不要以为是两种方法。

5. 第 3 节：结论与展望（S017–S019）

结论内容你要记住的
S017漂移普遍存在，处理很必要；大震近场用单段/多段校正，小震近场用高通滤波最有效最不主观方法按”震级 + 用途”分流
S018工程参数清单：Butterworth 稳定性最好；非因果滤波零相位；首尾等长零填充 + 余弦渐变；严格按 Boore 标准选截止频率可以直接照做的配方
S019两个空白：无法量化各误差来源的贡献；无法测量旋转分量。已有方法多为针对特定地震的经验方法，没有通用方法。未来方向是数据驱动地自动定 t1​、t2​领域缺口 + 未来方向

S019 对你选题的价值：它承认”没有通用方法”，也就意味着任何能提升通用性的工作都有立足点。L1 方法（自动定段）与你的三分量想法，都属于”提升通用性”这一类。

6. 组会可能被问到的五个问题（提前准备）

  1. 既然滤波简单又客观，为什么还要基线校正？→ 因为滤波会连永久位移一起滤掉，大震近场的目标恰恰是永久位移。
  2. Iwan 方法和 Boore 的 v0​ 方法最本质的区别是什么？→ Iwan 用固定阈值与两段模型（物理出发点是仪器磁滞）；v0​ 用速度末尾拟合直线的交点（出发点是”位移不能再漂”）。
  3. 为什么说”现有方法主观性强”？→ 分段数与分段点位置靠经验给定，不同人处理结果不同（这也是 2019/2020 的出发点）。
  4. 水平与垂直的差别到底差在哪？→ 倾斜对水平摆是一阶（gθ）、对垂直摆是二阶（gθ2/2），差几个数量级。
  5. 这篇综述的”未来方向”是什么？→ 用大数据/机器学习自动、快速、稳定地确定 t1​、t2​。
