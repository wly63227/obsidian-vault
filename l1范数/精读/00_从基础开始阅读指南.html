从基础开始的阅读指南（四篇文献）

目标：用 5—6 天、每天 1—2 小时，建立起”读懂这四篇 + 能动手复现”的基础。每一步都给出读什么、看哪些块、要能回答什么问题。块号（S/E/F/T）可直接在对应目录的 paper.md 与 source_map.json 中检索。

第 0 步：先补 4 个概念，再碰论文（约 40 分钟）

打开 基础概念速查.md，只读第 1—4 条：

  • 强震动加速度记录是什么；
  • 单位 gal 与 cm/s²；
  • 两次积分为何被放大；
  • 基线漂移的两个来源。

做完这步你要能用一句话回答： “为什么一个 0.01 gal 的小漂移，会让 60 s 记录的位移误差达到 18 cm？”

建议的小实验（20 分钟，强烈推荐）： 造一段 60 s、200 Hz 的假加速度（一条正弦波），加上 0.01 gal 的常值偏移，然后积分两次，把”干净信号”与”带漂移信号”的速度、位移画在同一张图上。你会亲眼看到漂移从”看不见”变成”抛物线”。这一步做完，后面所有论文的动机都不需要别人再解释。

第 1 步：读综述，建立问题地图（半天）

材料：02_Zhang2022_近场强震动基线校正综述/paper.md

顺序内容块号要能回答
1摘要 + 引言S001–S003这个领域要解决什么问题？为什么小震和大震处理方式不同？
2漂移的两大来源S004–S006、E001–E002低频误差 vs 倾斜旋转；水平与垂直差多少量级？
3两条校正准则S007什么叫做”校正合理”？
4高通滤波方法S008–S010为什么近断层大震不能用滤波？
5Iwan 系方法谱系S011–S016、E003–E010、F002加速度/速度/位移三个域的形状怎么对应？
6结论与展望S017–S019领域公认的两个空白是什么？

本步自测（能答出 4 条以上即可进入下一步）：

  1. 基线漂移的两个来源分别用什么方法处理？
  2. 0.06° 的倾斜对水平向和垂直向分别造成多大影响？
  3. 两条校正判据是什么？为什么第二条允许非零？
  4. Iwan 两段式里 t1​、t2​、am​、af​ 各是什么？
  5. 为什么说现有方法”主观性太强”？

第 2 步：读中文方法论文，抓住方法原型（1 天）

材料：01_Xiong2019_L1范数正则化基线漂移识别/paper.md

阅读顺序与重点：

  1. 摘要 + 引言（S001–S006）：明确它要攻击的痛点是”人工选分段次数与起止时刻”。
  2. 方法（S007–S011、E001）：把式 (1) 手抄一遍，逐个问自己 A、b、x、λ 是什么。
  3. 试验设计（S012–S013、T001、F001）：理解”真实记录 + 已知人工噪声”这套受控实验为什么能验证方法。
  4. 结果（S014–S020、F002–F006）：三条记录误差从小到大是否与事前部分长度顺序一致？
  5. 结论（S021–S024）：把”速度恢复稳健、位移恢复敏感”这条结论写成一句话。

本步自测：

  1. 为什么用 L1 而不是 L2？L2 会得到什么样的解？
  2. 三条记录的事前部分分别是多少？哪条结果最差、为什么？
  3. El Centro 记录为什么会被”拉向零线”？这会造成什么后果？
  4. 作者自己留下的开放问题是什么？

第 3 步：读英文姊妹篇，把数学形式钉死（1 天）

材料：03_Dai2020_SDEE_L1优化与视觉验证/paper.md

这是四篇里最需要精读的一篇，重点只有四处：

  1. S019–S021 与 E001、E002：确认正则项作用在差分 y 上（这是与中文版最容易混淆之处）。
  2. S025–S030、F002、F004：与 Iwan 方法的对比方案与定量结果（TCU129 误差 <0.1 gal 等）。
  3. S038–S043、F007–F011：振动台 + 相机视觉的验证体系怎么搭的。
  4. S044–S047：三条结论，以及”任何校正都会压制真实信号”这句关键限定。

本步自测：

  1. 写出式 (1)、(2)，并说明 y 的维数为什么是 n−1。
  2. 为什么说 L1 方法是 Boore v0​ 方法的升级？
  3. 视觉验证用了什么设备、什么指标？相关性是多少？
  4. 你认为 λ=1 合理吗？为什么？（这是开放题，答不出来就记进疑问清单）

第 4 步：读汶川三分量论文，看方法怎么落地（半天）

材料：04_Xie2013_汶川近场永久位移/paper.md

  1. 数据（S004–S005、F001）：64 台三分量 + 41 个 GPS 是什么规模。
  2. 方法（S006–S008、E001、F002）：υ0​ 型单段校正，逐分量处理。
  3. 验证（S009–S012、T001、F003–F008）：重点看表 1 的三个近距配对（51PXZ–PIXI、51MXD–Z040、51WCW–H050）。
  4. 结论（S013–S014）：位移场特征与验证的局限。

本步自测：

  1. 逐分量处理时，垂直分量的永久位移该怎么处理？为什么？
  2. GPS 与强震结果不吻合时，可能有哪些原因？
  3. 如果让你用 L1 方法替换掉它的 υ0​ 型校正，改动点在哪里？

第 5 步：补必要的工具（1—2 天，可与前面并行）

只需要补到”够用”的程度，不要陷入数学教材：

工具够用的标准补课方式
微积分知道积分是累积、导数是变化率任意大学微积分入门教材的积分章节
线性代数矩阵乘向量、向量范数3Blue1Brown《线性代数的本质》前 6 集
概率统计均值、标准差、相关系数任意统计入门教材的相关章节
数字信号处理傅里叶谱、滤波、采样率读 2022 综述 2.2 节 + Boore(2005)
凸优化凸集/凸函数、L1/L2、LASSO只需读 Boyd《Convex Optimization》第 1、6 章；能看 CVXPY 文档例子即可

第 6 步：开始动手（后续 2—4 周）

  1. 复现单轴：用 CVXPY 实现 minx​∥Ax−b∥2​+λ∥y∥1​，在 TCU129 上复现”误差 <0.1 gal”。
  2. 三分量逐分量：同一套代码跑 EW/NS/UD，得到基线库（方案 A）。
  3. 联合稀疏：把三分量差分堆叠，用行稀疏（组稀疏）惩罚让跳变时刻尽量共享（方案 B），并设计”独立漂移 / 水平共享漂移”两组合成实验做公平对比。
  4. 真实数据验证：汶川近距配对台站（51PXZ–PIXI、51MXD–Z040、51WCW–H050），输出与论文表 1 同格式的对比表。
  5. 端到端验证（条件允许）：三轴振动台 + 三维视觉或激光位移计。

常见误区清单（读的时候对照检查）

  1. 以为 L1 惩罚的是”基线本身很小”，其实是”基线的跳变稀疏”（见 2020 英文版式 (2)）。
  2. 以为基线校正是纯去噪，其实会压制真实地震信号、使位移幅值偏小。
  3. 以为三轴就是把单轴方法跑三遍：水平两轴的倾斜漂移是同源的，垂直轴不受倾斜影响。
  4. 把垂直向真实的永久沉降（如汶川 51SFB 的 −0.49 m）当成漂移抹掉。
  5. 用波形相关系数作为唯一精度指标，忽略幅值误差与矢量方向误差。
  6. 忽略单位（gal 与 m/s² 混用）与采样率对正则化尺度的影响。

阅读节奏建议

天数任务产出
第 1 天基础概念速查 + 假数据积分小实验一页笔记：漂移如何被两次积分放大
第 2 天综述第 1、2.1、3 节一页问题地图（来源二分法 + 方法谱系）
第 3 天2019 中文方法论文一页方法卡（输入/假设/目标函数/验证/结论）
第 4 天2020 英文版精读两个公式 + 三处定量结果 + 我的疑问清单
第 5 天2013 汶川论文一页”三分量工作流 + GPS 验证模板”
第 6 天汇总与提问用 我的理解与疑问.md 对照补齐自己的疑问

每一步结束后，把答不上来的问题记进 我的理解与疑问.md 的对应分类里；到第 6 天你会得到一份属于自己的研究问题清单——这比读完四篇论文本身更有价值。
