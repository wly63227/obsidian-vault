第 1 讲　导论：什么是凸优化

对应：EE364a Lecture 1 / 教材第 1 章 / 主笔记第 0、0.7、1 章 时长：2 小时（讲授 70 分钟 + 例题与讨论 40 分钟）

1.1 课时目标

  1. 能用一句话说明凸优化的核心性质：局部最优 = 全局最优；
  2. 能写出凸优化问题的标准形式并指出三个凸性要求；
  3. 能列举三个把现实问题写成凸优化的例子。

1.2 板书提纲

（1）优化问题的三要素

  • 决策变量 x、目标 f0​、约束 fi​≤0、hj​=0；
  • 一律写成最小化形式（maxf=−min(−f)）。

（2）凸优化问题的定义（板书必须写全）

min s.t.  ​f0​(x)fi​(x)≤0,i=1,…,maj⊤​x=bj​,j=1,…,p​

三个要求：① f0​ 凸；② fi​ 凸；③ 等式约束仿射。

（3）为什么凸性值钱

  • 非凸：只能保证局部最优，得不到全局证书；
  • 凸：局部最优 = 全局最优；有对偶证书；有成熟算法。

（4）三个招牌例子（板书配图）

  • 最速下降方向：min∇f(x)⊤d s.t. ∥d∥≤1（范数决定算法）；
  • 稀疏恢复：min∥x∥0​⇒ 松弛为 min∥x∥1​；
  • 投资组合：∥V1/2w∥2​≤σ（SOCP）。

1.3 课堂例题

例 1（5 分钟）：把”最大化 3x1​+2x2​，满足 x1​+x2​≤4, x1​,x2​≥0“写成标准形式并求解。

（答案：min−3x1​−2x2​；顶点法得最优 x=(4,0)，值 12。）

例 2（10 分钟）：判断下列哪些是凸优化问题：minx12​−x22​；minx1​1​（x1​>0）；minx1​x2​ s.t. x1​,x2​≥0；minx12​ s.t. x12​+x22​=1。

（答案：只有第二个是。第二个是凸的，因为 1/x 在 x>0 上凸；第四个约束非仿射。）

1.4 易错点

  • 把”凸”与”光滑”混为一谈（∣x∣ 凸但不光滑）；
  • 忘记等式约束必须仿射；
  • 认为”能求导就等于凸”。

1.5 作业（第 1 讲）

  1. 把三个实际问题写成凸优化形式（成本最小化 / 拟合 / 资源分配）；
  2. 判断 5 个给定的优化问题是否为凸问题，并说明理由；
  3. 用一维例子画出凸函数与非凸函数，标出局部/全局最优。

第 3 讲　凸集（一）：定义与判别

对应：EE364a Lecture 2 / 教材第 2 章 / 主笔记第 5 章 时长：2 小时

3.1 课时目标

  1. 用定义判断一个集合是否凸；
  2. 掌握”取两点 → 构造凸组合 → 代入验证”的三步套路；
  3. 记住”圆周非凸、圆盘凸""并集一般不保凸、交集保凸”这两个高频考点。

3.2 板书提纲

（1）定义

C 凸⟺∀x,y∈C, ∀θ∈[0,1]: θx+(1−θ)y∈C

（2）三种组合（板书对比）

组合系数到达
线性任意实数张成空间
仿射和 = 1仿射集

（3）画图判别（现场画 8 个集合）

直线、线段、圆盘、圆周、三角形、月牙、两圆盘并、{x1​x2​≥1,x1​>0}。

（4）判别三部曲 + 两个完整示范

  • 示范 A：任意范数球是凸集（用三角不等式 + 正齐次性）；
  • 示范 B：{x1​x2​≥1,x1​>0} 是凸集（展开 + AM–GM 处理交叉项）。

（5）保凸与不保凸

  • 交 ✅（任意多个）、并 ❌、闵可夫斯基和 ✅、仿射像/原像 ✅。

3.3 课堂例题

例 1（10 分钟）：证明立方体 {x∣∥x∥∞​≤1} 是凸集。

例 2（15 分钟）：判断 C={(x1​,x2​)∣x1​x2​≥1} 是否凸。

（注意：不加 x1​>0 时，第三象限也满足，取 (1,1) 与 (−2,−0.5) 会失败——这是经典陷阱，用来引出”必须检查所有满足条件的点”。）

例 3（10 分钟）：给出一个凸集的例子，其”补集”非凸（半空间）。

3.4 易错点

  • 认为”圆周是凸集”（错，只有实心圆盘是）；
  • 试图用”并”来构造可行域（会破坏凸性，应改用 ≤ 或引入辅助变量）；
  • 忘记 θ 必须在 [0,1]（取 θ 任意实数会得到仿射集）。

第 5 讲　凸集（三）：分离定理、支撑超平面与极点

对应：教材第 2 章 2.5 节 / 主笔记第 8、9 章 时长：2 小时

5.1 课时目标

  1. 陈述分离超平面定理并说明”凸性为什么关键”；
  2. 理解支撑超平面与支撑函数，知道支撑函数就是对偶范数的雏形；
  3. 掌握极点与表示定理，理解”线性目标在多面体上在极点取最优”。

5.2 板书提纲

（1）分离超平面定理

C∩D=∅ (都凸) ⟹ ∃a=0,b: a⊤x≤b≤a⊤y  ∀x∈C,y∈D

配图：两个凸块之间插一块钢板。

（2）支撑超平面与支撑函数

σC​(y)=x∈Csup​y⊤x
  • 性质：次可加、正齐次 ⇒ 凸；
  • 核心特例：单位球的支撑函数 = 对偶范数（sup∥x∥≤1​y⊤x=∥y∥∗​）；
  • 凸集由支撑函数唯一确定（闭凸情形）。

（3）为什么这对对偶理论重要

  • 对偶变量 = 分离超平面的斜率 = KKT 乘子（预告第 12、13 讲）。

（4）极点、回收锥、表示定理

  • 极点：不能写成另外两点的凸组合；
  • 圆盘有无穷多极点，正方形四个极点；
  • 多面体 = 顶点凸包 + 极方向锥；
  • 线性目标在多面体上的最优解可在极点取到（非线性则不一定）。

5.3 课堂例题

例 1（15 分钟）：求 ℓ1​ 球在 R2 中的支撑函数，验证等于 ℓ∞​ 范数。

例 3（10 分钟）：说明为什么 min(x12​+x22​) 在 [−1,1]2 上的最优解在内部（反驳”最优总在顶点”）。

5.4 易错点

  • 把”极点最优”当成对任意凸目标成立（只对线性目标成立）；
  • 忘记圆盘有无限多个极点（与”多面体极点有限”混淆）；
  • 把支撑函数与指示函数混淆。

第 6 讲　凸函数（一）：定义与三种判别法

对应：EE364a Lecture 3 / 教材第 3 章 / 主笔记第 10 章 时长：2 小时

6.1 课时目标

  1. 用定义、一阶条件、二阶条件三种方法判断凸性；
  2. 熟练判断 10 个常见函数的凸凹性；

6.2 板书提纲

（1）定义（板书三个版本的等价说法）

f(θx+(1−θ)y)≤θf(x)+(1−θ)f(y)

等价说法：弦在图像上方；epif 凸；Jensen 不等式。

（2）判别法 1：上镜图

f 凸⟺epif={(x,t)∣f(x)≤t} 凸

概念上最重要：把函数问题变成集合问题。

（3）判别法 2：一阶条件

f(y)≥f(x)+∇f(x)⊤(y−x)

三个用途：全局下界、最优性判据、证明不等式（例：logy≤y−1）。

（4）判别法 3：二阶条件

∇2f(x)⪰0∀x

现场推导 log-sum-exp 的 Hessian = diag(p)−pp⊤⪰0（方差非负）——这是本讲的”技术高潮”。

（5）严格凸、强凸与它们的关系（表格）

类型保证
凸局部最优 = 全局最优
严格凸最优解至多一个
强凸唯一解 + 线性收敛

例 3（10 分钟）：判断 maxi​xi​ 的凸性，画出上镜图。

6.4 易错点

  • 忘记定义域（logx 只在 x>0 谈凸凹）；
  • 用 f′′=0 的个别点否定凸性（例：x4 在 0 处二阶导为 0，但仍凸）；
  • 认为严格凸 = 强凸（反例 x4）。

第 15 讲　算法：无约束、等式约束与内点法

对应：EE364a Lectures 9–12 / 教材第 9–11 章 / 主笔记第 28–30 章 时长：2 小时

15.1 课时目标

  1. 说出梯度下降、牛顿法、拟牛顿法的差异与适用规模；
  2. 理解”牛顿法 = 用 Hessian 范数的最速下降”；
  3. 理解对数障碍与中心路径，知道 f0​(x(t))−p⋆≤m/t 的含义。

15.2 板书提纲

（1）无约束最小化

  • 最优性：∇f(x⋆)=0（凸时充要）；
  • 梯度下降：x+←x−t∇f(x)，步长用回溯（Armijo）；
  • 收敛率：凸 O(1/k)，强凸线性收敛（因子 1−m/L）；
  • 条件数 L/m 决定速度。

（2）最速下降的范数视角

d=argmin{∇f(x)⊤d∣∥d∥≤1}
范数算法
ℓ2​梯度下降
ℓ1​坐标下降型
ℓ∞​符号梯度
∥d∥∇2f​牛顿法

（3）牛顿法与 Newton decrement

x+←x−(∇2f)−1∇f;λ2(x)=∇f⊤(∇2f)−1∇f

两阶段：阻尼阶段 + 二次收敛阶段（ϵ→ϵ2）。

（4）等式约束

KKT 系统 [∇2fA​A⊤0​]，三种解法：消元、乘子、增广拉格朗日。

（5）内点法

  • 对数障碍 ϕ(x)=−∑i​log(−fi​(x))；
  • 中心路径 x⋆(t)；
  • 精度保证 f0​(x⋆(t))−p⋆≤m/t；
  • 复杂度：O(n3) 每步，迭代数 20–50（几乎与规模无关）。

15.3 课堂例题

例 1（10 分钟）：写出梯度下降的迭代式与回溯线搜索流程。

例 2（15 分钟）：推导牛顿方向，说明它是最小化二阶泰勒近似。

例 3（10 分钟）：说明为什么 t=m/ϵ 能达到精度 ϵ。

15.4 易错点

  • 认为步长可以任意（过大会发散）；
  • 认为牛顿法总该用（n 大时 O(n3) 不可承受）；
  • 忽略条件数对收敛速度的影响。

15.5 作业（第 15 讲）

  1. 实现梯度下降与回溯线搜索（可用 NumPy）；
  2. 比较梯度下降与牛顿法在病态二次函数上的迭代数；
  3. 写出等式约束 KKT 系统并求解一个小例子；
  4. 说明对数障碍法为什么能自动保证可行性。

第 16 讲　范数建模实战、近端算法与 ADMM（总结课）

  1. 能把一个真实问题”范数化”并写出可求解的形式；

（4）ADMM（针对可分解问题）

  • 交替更新 x、z、对偶变量 u；

16.3 课堂例题（综合题）

16.4 易错点总复习（本课程 Top 7）

  1. 混淆范数与范数平方；
  2. 用 ℓ2​ 期望稀疏；
  3. 用等式范数约束（非凸）；
  4. 对偶范数记错；
  5. 忘记标准化 / 惩罚了截距；
  6. 把 KKT 用于非凸问题并断言全局最优；
  7. 只看目标函数值判断收敛。

16.5 结课作业（综合项目，建议 2 周）

自选一个数据集或工程问题，完成：

  4. 验证：用交叉验证选 λ，报告对偶间隙或 KKT 残差；
