## 导入方式（Zotero 7）

1. `文件` → `导入…`（或右键目标分类 → `导入…`）；
2. 选择 `L1三轴基线校正_待读文献清单.ris`；
3. 勾选「将导入的条目放入新分类」，导入后按 `优先级` 标签或 `N1` 备注浏览。

导入后的每条记录带三类信息：`KW` 标签（`T1-必读` / `T2-方法变体` / `T3-新发现` / `T4-数学工具`）、`N1` 备注（优先级、被引数、是否开放获取、**为什么读**）、`AB` 摘要。免费全文链接写在 `N1` 里。
