> 这套讲义是给**零基础**读者的逐节精讲：从数学与物理地基开始，逐段、逐公式、逐图讲透四篇文献，并配可运行的实验和自测题库。

## 1. 什么叫"吃透"？三层标准

别用"读过几遍"衡量，用这三层：

| 层次 | 标准 | 检验方式 |
|---|---|---|
| 第一层：能复述 | 能用自己的话讲出这篇论文在解决什么问题、结论是什么 | 题库 A/B 组 |
| 第二层：能算 | 能独立复核关键数字（18 cm、1 gal、18 m、1.17 gal…）与公式量纲 | 纸笔算一遍，与讲义里的"数字自检"对照 |
| 第三层：能判断 | 能指出前提、局限、可改进处，并说清"换成三分量要改什么" | 题库 D/F 组 + 对照 [`../我的理解与疑问.md`](../我的理解与疑问.md) |

**第三层才是真正的吃透**：读完的标志不是"我信了"，而是"我知道它在什么条件下成立、什么条件下会失效"。

## 5. 四篇贯通：一段话 + 一条链

> 近断层强震记录里，一个在加速度上几乎看不见的零点偏移，会被两次积分放大成米级的位移误差；漂移有两个来源（低频误差、仪器倾斜），前者能用滤波处理，后者不能——因为滤波会连永久位移一起滤掉。传统分段校正的软肋在于"分几段、从哪一刻开始"要靠人猜；L1 稀疏优化把这件事变成凸优化问题自动求解，并用振动台 + 相机做物理验证；最终这些方法要落到 64 个台站的三分量记录上，变成一张经得起 GPS 与地质考察检验的近断层位移场。

链条：

| 环节 | 论文 | 关键句 |
|---|---|---|
| 问题 | 2022 综述 | 0.06° → 水平 1 gal → 18 m；垂直只有毫米级 |
| 工具 | 2019 | L1 稀疏自动定段；速度稳、位移看事前部分 |
| 工具 + 验证 | 2020 | 惩罚作用在差分上；视觉验证 97.34% / 95.68%；校正必然压低幅值 |
| 产品 | 2013 | 64 台三分量 + 41 个 GPS；51SFB 向西 1.49 m、垂直沉降 0.49 m |

## 6. 术语统一表（本讲义采用的写法）

| 规范术语 | 英文/符号 | 含义 |
|---|---|---|
| 基线漂移 / 基线偏移 | baseline drift / offset | 加速度零线被整体挪走 |
| 事前部分 | prior part / pre-event part | P 波到达前的记录段，理想情况为零线 |
| 强震段 / 结束段 | strong shaking phase / post-seismic phase | 由 $t_1$、$t_2$ 划分的两段 |
| 分段线性拟合 | piecewise linear fitting | 在速度域分段拟合直线以反推基线 |
| 阶梯函数 | step function | 基线分段恒定、偶尔跳变 |
| 稀疏 | sparse | 向量中大多数元素为零 |
| 字典矩阵 | dictionary matrix $A$ | 把基线映射为速度贡献的线性算子（本质是积分算子） |
| 正则化参数 | $\lambda$ | 平衡拟合误差与稀疏惩罚 |
| $v_0$ 方法 | Boore's $v_0$ method | 用速度末尾拟合直线与零轴交点定漂移起始时刻 |
| 永久位移 | permanent / final displacement | 校正后位移末尾的稳定值，记作 $D_{\text{last}}$ |
| 同震位移 | co-seismic displacement | GPS 震前震后观测之差（含少量震后蠕变） |
| 一致性分析 | Bland-Altman (B-A) | 用差值均值与 95% 一致性界限评价两组测量 |

## 7. 六个最容易带偏人的坑（精简版）

1. 以为 L1 是"让基线小"：它让**跳变稀疏**，结果才是阶梯；
2. 以为基线校正只是去噪：它必然压制真实信号、使位移幅值偏小；
3. 以为三轴就是把单轴跑三遍：水平两轴同源（倾斜），垂直轴几乎不受影响；
4. 把垂直向真实沉降当漂移抹掉（汶川 51SFB −0.49 m）；
5. 只看相关系数就宣布精度高：还要看幅值误差与 B-A 图；
6. 忽视单位与采样率：λ 的合适值随单位平移（本项目实验实测 100 倍）。
