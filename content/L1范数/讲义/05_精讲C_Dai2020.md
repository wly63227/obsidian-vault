## 2. 第 1 节 引言（S001–S015）

### 2.1 为什么这件事重要（S001–S003）

| 块 | 概括 | 读法 |
|---|---|---|
| S001 | 强震记录是震源机制、地震动预测方程、场地与断层效应、土-结构相互作用等研究的基础数据；**基线漂移普遍存在** | 数据价值 → 数据质量 |
| S002 | 0.01 gal 的漂移持续 60 s → 速度误差 0.6 cm/s、**最终位移误差 18 cm** | 全文动机数字 |
| S003 | 基线校正决定了最终位移的可靠性；大型结构（尤其跨断层）的非线性抗震分析强烈依赖位移时程 | 说明"为什么要准确的永久位移" |

### 2.2 从模拟记录到数字记录（S004–S005）

- **模拟记录时代**：缺少事前部分、放大器温度漂移、传感器频带外低频性能不稳定 → 一般认为从模拟记录估计位移很困难；
- **数字强震仪（1970s 起）**：高精度、宽频带、**预存储** → 克服了模拟记录的弱点。

**为什么要把这段历史写进引言？** 因为数字记录的"预存储"正是事前部分的来源，而事前部分又是后面全部结论的关键变量。

### 2.3 为什么用速度域、为什么不用滤波（S006）

概括：有文献明确提出**应避免对强震记录直接滤波**，因为会损失或畸变永久位移信息；由于加速度域的漂移很难直观判断起止与幅度，**多数方法改从速度时程入手**。

这就是"速度域是主战场"的理由：漂移在加速度域隐形，在速度域才表现为斜率。

### 2.4 痛点：主观性（S007–S011）

| 块 | 要点 |
|---|---|
| S007 | 常用方法要预先假设漂移时段并给定跳变次数（凭经验），分段数与分段位置要专家判断 → **主观、无法自动化与标准化** |
| S008 | 早期用多项式校正基线（该领域最早有影响的进展之一）；**Iwan 等（1985）是应用最广的方法**，奠定了对漂移特征的认识；并强调漂移通常是随机的 |
| S009 | 漂移起始时刻的两种常用取法：加速度首次超过 **50 gal**；或 P 波到达时刻 |
| S010 | 成因既含低频误差（仪器噪声、背景噪声、初始值），也含地面扭转/倾斜导致的仪器倾斜；两种取法都是**经验判断** |
| S011 | 对集集、汶川大量记录的处理显示：**人为选择分段起止点对结果影响很大**；多个改进（Boore 等）与 EMD 类尝试相继出现 |

**把 S007–S011 当作"问题清单"读**：① 分段数靠猜；② 分段点靠猜；③ 起止时刻靠经验阈值；④ 结果对人工选择敏感。**2019/2020 的方法就是针对这四条。**

### 2.5 其他路线（S012–S013）

- 初始条件一致性分析与"基于目标值的去趋势"算法；已知 GPS 位移时，可把位移当作约束；
- 修改拟静力分量以满足目标位移；
- Whitney（2018）：带通滤波 + 速度趋势调整的半自动方案（用于恢复近源的构造性 fling），要求校正点不产生虚假尖峰，并考虑位移平坦度；
- 基于"校正模式"的方法：指出**无倾斜二维振动台记录**与**三维强震动记录**的校正模式显著不同。

**最后这条对你特别有价值**：它从另一个方向说明"二维/单轴的结论不能直接外推到三维"。

### 2.6 本文的位置（S014–S015）

概括：作者先以中文发表了初步成果（即 2019 篇），其目标是"最小化分段线性拟合速度时程的方差与基线漂移绝对值之和"，并用人工加噪验证；本篇（英文）**深入分析 L1 方法的假设与性质**，第 3 节与 Iwan 全面对比，第 4 节给出视觉验证，第 5 节讨论。

同时作者坦率承认：由于漂移成因难以确定，**没有哪种方法尽善尽美，基线校正仍是开放且具挑战的问题**。

## 3. 第 2 节 方法（S016–S024，E001–E002）

### 3.1 物理假设（S016、S018）

S016 给出关键的物理动机：地震中仪器的倾斜被认为是一种**稀疏现象**——不是持续发生，而是偶尔发生。**"稀疏优化"正是为这种"偶发跳变"量身定做的工具。**

S018 给出三条假设（与 2019 完全一致）：

a) 漂移随机、次数未知；b) 漂移在某时刻突变后在段时间内保持不变，即**分段线性（阶梯）函数**；c) 地震动结束后速度趋于零。

### 3.2 数学形式（E001–E002，p.2）

设加速度记录为 $a_g$，时长 $T$，采样间隔 $\Delta T$，点数 $n=T/\Delta T$，其基线为 $x$。

<a id="E001"></a>

$$y_i=x_{i+1}-x_i\qquad(\text{维数 }n-1)$$

<a id="E002"></a>

$$\min_x f(x)=\|Ax-b\|_2+\lambda\|y\|_1$$

| 符号 | 含义 | 维数/单位 |
|---|---|---|
| $a_g$ | 观测加速度 | $n$，gal |
| $x$ | 待求的加速度基线（阶梯函数） | $n$，gal |
| $y$ | 基线的差分＝跳变量 | $n-1$，gal |
| $A$ | **完备字典**（论文只给名称，未给元素级定义） | $m\times n$ |
| $b$ | 拟合目标（= 观测速度） | $m$，cm/s |
| $\lambda$ | 正则化参数（本文取 1） | 见 3.4 的量纲分析 |

### 3.3 论文没写清、但你必须补上的一步：$A$ 到底是什么

论文原文（S020）说：**"对 $a_g-x$ 积分得到校正后的速度，它与 $x$ 成线性关系，记作 $Ax-b$。"** 把这句话写成矩阵就是：

设 $v_{\text{obs}}=\Delta T\,C\,a_g$，其中 $C$ 是下三角全 1 的累加矩阵（cumsum）。那么

$$v_{\text{校正}}=\Delta T\,C\,(a_g-x)=v_{\text{obs}}-\Delta T\,C\,x$$

把"要最小化的量"写成 $Ax-b$ 的形式，最自然的取法就是 $A=\Delta T\,C$、$b=v_{\text{obs}}$（符号方向不影响范数最小化）。

<a id="E003"></a>

**所以 $A$ 就是"积分算子"的离散矩阵**，而它在"字典"语言里的含义非常直观：

> **$A$ 的第 $j$ 列 = "在第 $j$ 个时刻发生一次单位阶跃"所贡献的速度波形 = 一条从该时刻开始线性上升的折线。**

于是整个模型可以说成一句话：

> 速度曲线 $\approx$ 若干条"从不同时刻开始的折线"的加权和；权重就是各次跳变的幅度；而 $y$ 稀疏表示**用到的折线数量很少**。

这就是"完备字典（稀疏表示）"的含义，也解释了为什么基线的解是阶梯、速度的解是折线。

**量纲检查（吃透的硬标准）**：

| 项 | 单位 | 说明 |
|---|---|---|
| $Ax$ | s × gal = cm/s | 与 $b$（速度）一致 ✔ |
| $\|Ax-b\|_2$ | cm/s | 速度量纲 |
| $\|y\|_1$ | gal | 加速度量纲 |
| $\lambda$（未平方版本） | s | 让两项量纲对齐所需的单位 |

**结论**：$\lambda$ 不是无量纲常数，取 $\lambda=1$ 相当于默认"1 cm/s 的速度残差与 1 gal 的跳变等权"。改变单位或采样间隔，这个平衡就被打破——这与本项目实验测到的"换单位后合适 λ 平移 100 倍"是同一件事。

### 3.4 为什么可以放心求解（S021–S024）

| 块 | 要点 |
|---|---|
| S021 | L1 正则化是**双准则**：既要残差小，又要解"小"；残差用 L2，正则用 L1 |
| S022 | 该式是 **LASSO** 的等价形式，也可看作带约束的最小二乘；是典型凸优化，**存在且仅存在一个全局最优解**；算法流程见 Fig. 1 |
| S023 | 求解这类问题的方法有四类：经典迭代优化（最速下降、共轭梯度、迭代加权最小二乘、**内点法**）、同伦算法、贪婪算法、迭代收缩算法 |
| S024 | 本文用 **MATLAB 的 CVX** 求解；依据文献把 **λ 设为 1**；并称 L1 方法能减少计算量、得到更准确的速度拟合线，还能控制跳变次数与漂移幅度 |

> **对 S022"有且只有一个全局最优解"的严谨读法**：凸性保证"最优值"唯一、且没有局部陷阱；"最优解唯一"还需附加条件（例如 $A$ 的零空间与稀疏约束的零空间只交于原点）。做三分量扩展时，只要目标函数仍是凸的（例如把三分量差分堆叠后取组稀疏惩罚），"好解、无局部陷阱"这条性质就仍然成立——这是三轴扩展在数学上"安全"的依据。

## 4. 第 3 节：与 Iwan 方法的定量对比（S025–S037）

### 4.1 对比设计（S025–S027）

| 块 | 要点 |
|---|---|
| S025 | 两种方法都用最小二乘在速度域做分段线性拟合；分段拟合的两个基本参数是**段数与分段点位置**；Iwan 方法认为漂移发生在**首末次加速度超过 50 gal** 的时刻 |
| S026 | L1 方法依据速度信息本身的特征分段，**不预设段数与位置**；对比流程见 Fig. 2：原始记录 → 加人工噪声 → 两种方法各自校正 → 与已知噪声、原始速度位移比对 |
| S027 | 比较两件事：① 识别的漂移函数 vs **已知**人工噪声；② 校正后的速度/位移 vs 原始记录的**真值**速度/位移 |

**为什么要两条比较线？** 第一条比"漂移识别得准不准"，第二条比"最终结果好不好用"。二者不一定同时成立——这就是为什么"校正会压制信号"这类结论必须单独说。

### 4.3 位移重构与一致性分析（S033–S035，图 5）

| 块 | 要点 |
|---|---|
| S033 | **Iwan 方法的位移时程存在明显的尾部漂移**；L1 方法的位移与参照位移高度相似，基本保持了位移信息的完整性 |
| S034 | 用 **Bland-Altman** 分析位移差 $D_{\text{origin}}-D_{L1}$：三种记录的相关系数为 **97.456%、96.825%、95.420%**（TCU129 > Bolu > El Centro） |
| S035 | 差异的根源是事前部分长度；**当速度零线的正负面积差（积分误差）较小时，位移更准确**；并指出对缺失事前部分的记录，"拟合速度可能已经包含了事前部分的积分漂移误差" |

> **重点理解 S035 里的"面积差"**：速度曲线与零线之间的正负面积相抵后的余量，就是位移的最终偏移。基线校正的目标，某种意义上就是把这块"多余的面积"去掉，同时不能把真实地震动造成的面积也削掉。这就是"**校正精度**与**信号保真**"之间不可兼得的根源。

## 6. 第 5 节：讨论与结论（S044–S048）

| 块 | 要点 |
|---|---|

## 9. 组会可能被问到的问题

1. $A$ 是什么？→ 论文只说"完备字典"；按它的描述，$A$ 是**积分算子的离散矩阵**，其每一列是"某时刻发生单位阶跃"对应的速度折线。
2. 为什么惩罚 $\|y\|_1$ 而不是 $\|x\|_1$？→ 前者惩罚"跳变次数"（得到阶梯），后者惩罚"基线幅度"（得到被压小的基线），语义完全不同。
3. 视觉验证解决了什么问题？→ 用独立物理测量替代"另一个方法算出的参照位移"，避免循环论证。
4. Iwan 方法失败在哪？→ 它的漂移结构被固定在两段，零线差值无法按需调整，误差在积分中累积，尾部出现明显漂移。
5. 这篇论文自己承认的最大局限是什么？→ **任何校正都会压制地震信号、使位移幅值偏小**；另外 $\lambda$ 固定为 1、$A$ 未给出元素级定义。
