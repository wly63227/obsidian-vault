L1（融合稀疏）基线校正最小演示
采样率 50 Hz，记录长度 12 s，点数 600，dt = 0.0200 s
真实基线：0 -> +2 gal (t>=4 s) -> -0.5 gal (t>=8 s)，共 2 次跳变

不校正时的位移末值误差：
  d_obs(T) - d_true(T) = +41.89 cm

lambda 扫描（跳变判定：单点差分 > 0.01 gal，且累积幅度 >= 0.3 gal）：
    lambda     跳变次数     基线RMSE/gal             识别跳变时刻/s          位移末值误差/cm
   1.0e+00        2          0.611              5.3,9.0             -0.136
   1.0e+01        3          0.557          1.2,5.0,8.9             -0.198
   1.0e+02        3          0.433          2.9,3.6,8.7             -0.084
   1.0e+03        0          1.081                    -             -4.118
   1.0e+04        0          1.090                    -             -4.533
   1.0e+05        0          1.090                    -             -4.533

选中的 lambda（要求跳变次数=2，取基线 RMSE 最小）：1.0e+00
  识别出的跳变: t=5.32 s, 幅度=+2.25 gal; t=8.96 s, 幅度=-2.53 gal
  （真值 4 s 与 8 s）
  基线 RMSE: 0.611 gal
  校正后位移末值误差: -0.136 cm
  未校正位移末值误差: +41.888 cm
  校正后尾部速度: -0.004 cm/s（判据要求趋于零）

基线取值检查（真值：t<4 s 为 0，4—8 s 为 +2 gal，t>8 s 为 -0.5 gal）：
  t =  2.0 s：真值 +0.00 gal，识别值 -1.16 gal
  t =  6.0 s：真值 +2.00 gal，识别值 +2.13 gal
  t = 10.0 s：真值 -0.50 gal，识别值 -0.57 gal

尺度提示（为什么 lambda = 1 不是普适值）：
  残差项是 n 个采样点上的平方和，量级随记录长度 n 与采样间隔 dt 变化；
  惩罚项是跳变绝对值之和，量级只与 gal 数有关。两者的相对权重因此依赖 n、dt 与单位。
  本演示中合适的 lambda 落在 1—100 之间（按跳变次数与 RMSE 选中 1e+00）；
  但把单位换成 m/s² 后，同一网格的合适值就变成 0.01 量级——差 100 倍。

单位一致性检验（把加速度从 gal 换成 m/s²，数据值缩小 100 倍后重跑同一网格）：
    lambda     跳变次数     基线RMSE/gal
   1.0e-02        2          0.611
   1.0e-01        3          0.557
   1.0e+00        3          0.433
   1.0e+01        0          1.081
   1.0e+02        0          1.090
  换单位后能识别出 2 次跳变的 lambda 变成 1e-02（原单位下是 1e+00）——两者相差 100 倍，说明 lambda 的合适值随单位漂移。
