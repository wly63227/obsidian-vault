# 精读产物说明

本目录是四篇参考文献的 Markdown 精读包，由 `nature-reader` 技能流程生成（源格式：pdf-text）。

## 目录结构

| 目录 | 论文 | 模式 | 覆盖 |
|---|---|---|---|
| `01_Xiong2019_L1范数正则化基线漂移识别/` | 熊政辉等（2019），地震学报 | 原文摘录 + 逐节解读 | 摘要、引言、方法、试验、结果、结论 |
| `02_Zhang2022_近场强震动基线校正综述/` | 张斌、俞言祥（2022），地球与行星物理论评 | 原文摘录 + 逐节解读 | 摘要、原因分类、三类方法、结论 |
| `03_Dai2020_SDEE_L1优化与视觉验证/` | Dai et al.（2020），SDEE | **段落级中英对照（全文）** | 正文第 1—5 节 + Data and resources |
| `04_Xie2013_汶川近场永久位移/` | 谢俊举等（2013），地震学报 | 原文摘录 + 逐节解读 | 摘要、引言、数据、方法、比较、结论 |

每个目录包含：

- `paper.md` —— 阅读主体（含段落级对照、公式块、图卡、术语表、阅读提示）；
- `source_map.json` —— 稳定源锚点（S/E/F/T 块 ID、页码、公式 LaTeX、图件路径）；
- `translation_notes.md` —— 术语决定、公式置信度、图件近似裁切、待补内容；
- `assets/pages/` —— 每页整页渲染（图件裁切不确定时的兜底证据）；
- `assets/figures/` —— 图件近似紧裁；
- `assets/figure_manifest.json` —— 每张图的页码、裁切框、图注与置信度。

工具脚本位于 `tools/`：`extract_assets.py`（页面渲染与通用图注检测）、`extract_figures_explicit.py`（按显式图注表切图）、`build_source_map.py`（由 `paper.md` 生成 `source_map.json`）。

## 阅读顺序建议

1. 先读 `02_Zhang2022`（建立问题地图）→ 2. 再读 `01_Xiong2019`（方法原型）→ 3. 再读 `03_Dai2020`（方法正式版 + 验证体系）→ 4. 最后读 `04_Xie2013`（三分量工程应用与 GPS 验证）。

跨篇的整体理解与开放问题见 [`我的理解与疑问.md`](我的理解与疑问.md)。
