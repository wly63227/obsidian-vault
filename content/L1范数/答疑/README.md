## 三句话摘要

1. **第一周那 7 个疑问里，公式类的基本清空了**：正则项作用在差分 $y$ 上（不是 $x$）、$A=\Delta t\,C$ 是积分算子、50 m/s² 是单位误写、凸性推不出唯一解——这四条现在都有可复算的数字支撑。
2. **剩下的空白只有两处**：$\lambda$ 该怎么标定（它有量纲，单位是秒），以及"事前段基线为零"如何显式写成约束。
3. **下一层的入口也清楚了**：复现单轴 L1 → 用 2019 表 1 的三条记录验证"事前段越长越准" → 把算子堆叠成三分量并检查它的秩。
