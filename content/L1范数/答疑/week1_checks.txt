==============================================================================
1  基线校正的必要性：0.01 gal 为什么等于 18 cm
==============================================================================
常数零偏 b = 0.01 gal，记录长度 60 s（200 Hz）：
  速度末值误差  解析 bt      = 0.6000 cm/s   数值 0.6000 cm/s
  位移末值误差  解析 (1/2)bt^2 = 18.00 cm     数值 18.00 cm
  => 18 cm 这个数字可以被完整复现。

反推：若要求 60 s 记录的位移误差不超过给定容差，零偏必须小于
   容差 / cm |       允许零偏 / gal |              相当于
--------------------------------------------------
       0.5 |          0.00028 |          0.03 x 0.01 gal
       1.0 |          0.00056 |          0.06 x 0.01 gal
       5.0 |          0.00278 |          0.28 x 0.01 gal
      18.0 |          0.01000 |          1.00 x 0.01 gal
  => 60 s 记录上，位移误差要压到 1 cm 以内，零偏必须小于约 5.6e-4 gal。
     这就是“加速度上看不见、位移上不可接受”的定量含义。

==============================================================================
2  正则项作用在 x 上还是差分 y 上：两种解不是一回事
==============================================================================
真实基线：0 -> +2 gal (t>=4 s) -> -0.5 gal (t>=8 s)。
未校正时位移末值 = +41.71 cm，真值 -0.18 cm （误差 +41.89 cm）。

判读方式：看识别出的基线在三个时间窗内的平均电平，是否等于真值的 0 / +2 / -0.5 gal。

[甲] 中文版写法  min ||A x - b||_2^2 + lambda * ||x||_1
  lambda | 基线电平（0.5-2s / 5.5-7.5s / 9.5-11.5s）                  |       位移末值误差 |       末段速度
------------------------------------------------------------------------------------------------
     0.1 | -7.42 / +4.56 / -0.50   (真值 +0.00 / +2.00 / -0.50)   |       +0.13 cm |    -0.050 cm/s
     1.0 | -4.71 / +2.51 / -0.20   (真值 +0.00 / +2.00 / -0.50)   |       +0.01 cm |    -0.457 cm/s
    10.0 | -4.13 / +0.47 / +0.00   (真值 +0.00 / +2.00 / -0.50)   |       -0.06 cm |    +0.243 cm/s
    50.0 | +0.00 / +0.00 / +0.00   (真值 +0.00 / +2.00 / -0.50)   |      +13.77 cm |    +2.912 cm/s
   100.0 | +0.00 / +0.00 / +0.00   (真值 +0.00 / +2.00 / -0.50)   |      +38.77 cm |    +5.717 cm/s
  1000.0 | +0.00 / +0.00 / +0.00   (真值 +0.00 / +2.00 / -0.50)   |      +41.89 cm |    +6.064 cm/s
  注：惩罚 x 本身时，lambda 一旦超过 106，最优解就恒等于 0
      （LASSO 的经典性质：梯度在原点处落进次微分区间），与数值收敛无关。

[乙] 英文版写法  min ||A x - b||_2^2 + lambda * ||D x||_1
  lambda | 基线电平（0.5-2s / 5.5-7.5s / 9.5-11.5s）                  |       位移末值误差 |       末段速度
------------------------------------------------------------------------------------------------
     0.1 | -9.80 / +3.05 / -0.50   (真值 +0.00 / +2.00 / -0.50)   |       -0.22 cm |    +0.000 cm/s
     1.0 | -9.42 / +2.82 / -0.50   (真值 +0.00 / +2.00 / -0.50)   |       -0.22 cm |    +0.000 cm/s
    10.0 | -7.03 / +1.71 / -0.48   (真值 +0.00 / +2.00 / -0.50)   |       +0.06 cm |    -0.031 cm/s
    50.0 | -4.49 / +2.07 / -0.41   (真值 +0.00 / +2.00 / -0.50)   |       -0.37 cm |    -0.142 cm/s
   100.0 | +0.05 / +1.89 / -0.33   (真值 +0.00 / +2.00 / -0.50)   |       -0.26 cm |    -0.267 cm/s
  1000.0 | +0.60 / +0.68 / +0.68   (真值 +0.00 / +2.00 / -0.50)   |       -4.10 cm |    -1.459 cm/s

同一行对照（lambda = 100）：
  甲 ||x||_1 : 基线电平 +0.00 / +0.00 / +0.00   (真值 +0.00 / +2.00 / -0.50)
                 位移末值误差 +38.77 cm
  乙 ||Dx||_1: 基线电平 +0.05 / +1.89 / -0.33   (真值 +0.00 / +2.00 / -0.50)
                 位移末值误差 -0.26 cm

两条结论：
(1) 惩罚 x 本身时，lambda 一大，整条基线（连同台阶）被一起压向 0：
    lambda >= 106 的解就是“零基线”，等于没做校正，
    位移误差回到未校正的 +41.89 cm。
    惩罚差分时，常数段本身不花成本，只有跳变花成本，所以 lambda 增大只减少跳变次数，
    不会把台阶整体压掉——lambda = 100 仍给出 +0.05 / +1.89 / -0.33 的分段常数基线。
(2) 所以“稀疏”指的是基线的**变化**稀疏，不是基线**本身**小。
    这就是老师第 2 条答复的全部内容，也是复现时最容易搞反的一处。

附：第一项不可能被压到很小——把**真实**基线代进去，残差仍有 683 cm/s，
    因为 b 里本来就含真实地震动（本例解处 675 cm/s）。
    所以起作用的是“第一项与 λ 的平衡”，而不是“把第一项最小化”。
    另外这次求解用的是平方形式 ||Ax-b||_2^2，论文写的是未平方的 ||Ax-b||_2：
    同一个解处两者梯度相差 2||Ax-b||_2 倍，λ 的数值必须连同“写不写平方”一起说明。
    这正是答复里那句“复现时应明确单位、采样间隔、积分方式和是否归一化”的具体后果。

3  字典矩阵 A 的构造，以及矩形积分 / 梯形积分的差别
==============================================================================
按回复给出的离散化（4 个采样区间、等间隔 dt、零初始速度、矩形积分）：

   A = dt * [1  0  0  0 ]
   A = dt * [1  1  0  0 ]
   A = dt * [1  1  1  0 ]
   A = dt * [1  1  1  1 ]

  更一般地：A[i, j] = dt (j <= i)，其余为 0 —— 下三角、对角非零。
  含义：A 的第 j 列 = 第 j 时刻发生一次单位阶跃时贡献的速度波形。
  量纲：A 的单位是 s，Ax 的单位是 gal*s = cm/s，与 b（观测速度）一致。

用梯形积分替代矩形积分（同样是 4 个区间，dt = 0.020 s）：
   矩形：1.00  1.00  1.00  1.00
   梯形：0.50  1.00  1.00  0.50
   差异出现在首末样本的权重（0.5 与 1 的差别），中间样本两种积分一致。

[实验] 同一份记录、同一个 lambda 网格，分别用矩形 / 梯形积分算子做反演：
算子          lambda | 基线电平（0.5-2s / 5.5-7.5s / 9.5-11.5s）                  |             跳变时刻 |       位移误差
--------------------------------------------------------------------------------------------------------
矩形积分             1 | -9.42 / +2.82 / -0.50   (真值 +0.00 / +2.00 / -0.50)   |    2.82 / 6.18 s |     -0.22 cm
矩形积分            10 | -7.03 / +1.71 / -0.48   (真值 +0.00 / +2.00 / -0.50)   |    2.82 / 8.06 s |     +0.06 cm
矩形积分           100 | +0.05 / +1.89 / -0.33   (真值 +0.00 / +2.00 / -0.50)   |    3.16 / 7.96 s |     -0.26 cm
矩形积分          1000 | +0.60 / +0.68 / +0.68   (真值 +0.00 / +2.00 / -0.50)   |    3.50 / 5.98 s |     -4.10 cm
梯形积分             1 | -11.27 / +2.89 / -0.50   (真值 +0.00 / +2.00 / -0.50)  |    2.82 / 6.18 s |     -0.23 cm

  矩形积分 最像真值的一组：lambda=100，跳变定位 3.16 / 7.96 s，位移末值误差 -0.26 cm
  梯形积分 最像真值的一组：lambda=100，跳变定位 3.14 / 7.96 s，位移末值误差 -0.33 cm
  真值：跳变 t = 4.00 / 8.00 s，电平 0 / +2 / -0.5 gal。
  两种离散化都能把电平恢复住，但跳变时刻会偏晚——这正是论文里 0.1~0.5 s
  时刻偏差的一部分来源，也说明“时刻”和“电平”要分开评价。
  结论：A 的“取值由积分关系决定”这句话是对的，但必须写出你用的是哪一种积分，
  否则复现的数值不可能逐位对上。

4  加速度阈值的单位：50 gal / 50 cm/s^2 / 50 m/s^2 到底差多少
==============================================================================
写法                     换算成 m/s^2         换算成 gal       相对 50 gal
------------------------------------------------------------------
50 gal                     0.500            50.0              1x
50 cm/s^2                  0.500            50.0              1x
0.5 m/s^2                  0.500            50.0              1x
50 m/s^2                  50.000          5000.0            100x

  50 m/s^2 = 5000 gal ≈ 5 g。工程强震仪量程通常为 ±2 g（约 ±1960 gal），
  这个“阈值”已经超过仪器量程 2.5 倍，不可能作为强震段起点判据使用。
  结合中文第 113 页写 50 cm/s^2、英文写 50 gal，可判定中文第 115 页系单位误写。

  这一条同时说明：这个阈值只属于 Iwan 方法的经验设定，
  L1 方法不需要预先知道跳变时刻，也不用它。

5  事前部分：长度到底影响什么
==============================================================================
假设事前段是均值为 0、标准差 1.0 gal 的背景噪声，采样率 200 Hz。
用“事前段均值”估计零偏，其标准误差约为 sigma/sqrt(N)：
     事前段长度 / s       样本数            零偏估计标准误差 / gal          折算成 60 s 位移误差 / cm
--------------------------------------------------------------------------------
          0.04         8                     0.354                       636.4
          5.39      1078                     0.030                        54.8
         20.65      4130                     0.016                        28.0

  20.65 s 的事前段把零偏估计精度提高了约 23 倍（相对 0.04 s）。
  即：0.04 s 的事前段若把零偏估偏 0.35 gal，60 s 后就是 6 m 量级的位移误差；
  20.65 s 的事前段把同一项压到 0.3 m 量级。

  注意：上表说的是“零偏估计的随机误差”随事前段变短而变大。
  真正致命的是下一种情形——事前段是“错的”，不是“短的”。

[对照] “丢头”记录：如果记录开头已经含真实运动，会发生什么
合成记录：地震动集中在 t=25 s 附近，60 s 记录本身有 25 s 的干净事前段。
    记录起点 / s        丢失的事前段 / s          起点处真实速度 / cm/s           末尾位移误差 / cm
------------------------------------------------------------------------------
         0.0               0.0                    0.00                 -0.00
        10.0              10.0                    0.00                 -0.00
        24.0              24.0                    9.85               -354.52
        26.0              26.0                    9.74               -331.13
        28.0              28.0                    3.96               -126.71
        30.0              30.0                    0.66                -19.86

  这里的误差不是随机的，而是确定性的：把一段真实的非零速度强行当作零线，
  等于在整条位移上减去一个常数速度的积分，误差随时间线性增长。
  这正是 2019 论文里 El Centro 台（事前部分仅 0.04 s、且开通段不为零）
  被“尽量拉近零线”、位移被压小的原因：丢的是“锚点”，不是“样本数”。

==============================================================================
6  凸性 ≠ 最优解唯一：把反例算出来
==============================================================================
(a) 老师给的例子：f(x) = |x-1| + |x|
    x in [-1, 2] 上的最小值 = 1.0；在 x in [0, 1]（201 个采样点）上取值恒为 1。
    f(0.00) = 1.0
    f(0.25) = 1.0
    f(0.50) = 1.0
    f(0.75) = 1.0
    f(1.00) = 1.0
    => 最优值唯一、最优解无穷多。凸性推不出唯一性。

(b) 这个例子其实对应哪一种模型？（这里是我的补充，建议和老师确认）
    取 A = 1、b = 1、lambda = 1，若要得到 |x-1| + |x|，
    第二项必须是 ||x||_1，而不是 ||Dx||_1 —— 也就是**中文版式的形式**。
    一维情形下差分算子作用在标量上是 0，英文形式退化为 f(x) = |x-1|，唯一。
    换句话说：非唯一性恰好出现在“惩罚基线本身”的写法里。

(c) 结构性反例：只要 A 的零空间与差分算子的零空间有交集，唯一性就失效。
    min_x ||A x - b||_2 + lambda * ||D x||_1,  A = [1, -1], b = 0, lambda = 1
    x = (-2.0, -2.0) -> 目标值 = 0.0
    x = (0.0, 0.0) -> 目标值 = 0.0
    x = (3.0, 3.0) -> 目标值 = 0.0
    A 把常数向量映到 0，差分又把常数向量映到 0，所以任意常数向量都是最优解。

(d) 正面结论：论文自己那个 A 反而保证了唯一性
    A = dt * C 是下三角，对角元全为 dt = 0.0200 s 且非零，
    所以 det(A) != 0、rank = 600 = n，A 是单射（满列秩）。
    最小奇异值 = 1.0000e-02，最大 = 7.6458e+00，条件数 = 764.6
    此时 x -> ||Ax - b||_2 是**严格凸**的（欧氏范数严格凸 + A 单射），
    加上凸的 L1 项仍是严格凸，因此最优解**确实只有一个**。

    => 所以对第一周那条疑问的完整回答是：
       论文写的理由是错的（凸性不够），但在它自己的 A 之下结论是对的；
       老师的告诫也是对的（不能只由凸性推出），只是“没有平方就不能用”这一点
       再往下追一步的话：真正起作用的是 A 是否满列秩，而不是有没有平方。

    旁证：英文形式的算子 B = [dt*C*S, dt*C*1] 是 (600, 600)，
    最小奇异值 = 5.0000e-03（> 0），同样可逆，所以“解不唯一”不是这套模型的隐患。

==============================================================================
小结
==============================================================================
1) 18 cm 可复现；反推出 60 s 记录上“位移误差 < 1 cm”要求零偏 < 5.6e-4 gal。
2) ||x||_1 与 ||Dx||_1 在同一份数据上给出完全不同的解；复现时以英文式(1)(2)为准。
3) A 由积分关系决定，必须写明是矩形还是梯形；两种离散化都会让跳变时刻偏晚。
4) 50 m/s^2 = 5000 gal 超过 ±2 g 量程，可以确定为误写。
5) 事前段的作用是约束初始零偏；“丢头”造成的位移误差是确定性的、随时间线性增长。
6) 凸性只保证没有局部陷阱；唯一性要么来自严格凸（A 满列秩），要么来自零空间条件。
