# 《工程地震学》复习总结 · 总导读

> 主讲：章文波（中国科学院大学）　教材参考：袁一凡、田启文《工程地震学》（地震出版社，2012）
> 本套笔记依据 7 次课件（2026-09-07 至 2026-09-30）、课程大纲、作业一及参考书整理。

---

## 一、先看结论：这门课考什么

课程考核与进度（课件01 P34、P41）：

| 项目 | 内容 |
| --- | --- |
| 成绩构成 | 平时作业 **30%** + 期末考试 **70%** |
| 学时 | 授课 57 节 |
| 期末考试 | **11 月 30 日**（全课程范围） |
| 已讲进度 | 第零章 → 第三章（共 7 次课） |

**关键判断：**作业一（《概述、基础知识》）已经把"考试口径"暴露得非常清楚。它考的 8 道题中，有 6 道是**地震学基础知识**（体波与面波、走时与首波、震级、烈度、海啸、斜坡失稳），只有 2 道直接对应课件（学科关系、标志性地震）。

这说明：**工程地震学的考试 = 课件体系 + 地震学基础功底**。只背课件远远不够，必须把《地震学教程》《地震学引论（Shearer）》里的基本功补齐。本套笔记中的 [[07_基础知识专题]] 就是为这个目的写的。

## 三、三次讲课的推进逻辑（考试的叙述主线）

理解这条主线，论述题就能写"顺"：

```
地学背景          地震学工具            工程目标
──────────────────────────────────────────────────────
板块运动/断层      地震波 → 震级/烈度    地震动参数
  （第三章）          （第二章）           （第四、五、六章）
     │                    │                    │
     └── 发震构造 ────────┴── 危险性分析 ──────┘
              （潜在震源区 + 地震活动性参数）
                        │
                   场地效应 → 设计地震动 → 抗震设计
```

一句话概括全课逻辑：**从地质构造出发，判断"哪里可能发生多大震级的地震、多频繁"（第三章），再用地震学方法把这些地质结论转换成工程可用的地震动参数（第二、四章），最后服务于抗震设计（第五至九章）。**

| 文件 | 内容 | 用途 |

| [[05_地震地质_上_绪论与新构造活动构造|05_地震地质（上）]] | 第三章：绪论、术语、典型震例、新构造、活动断层特性、分段与级联 | 复习，重点+难点 |
| [[06_地震地质_下_定量研究与潜源危险性|06_地震地质（下）]] | 第三章：定量研究方法、安评调查、板块构造环境、潜在震源区、地震危险性分析 | 复习 + 预习衔接 |
| [[07_基础知识专题]] | 地震波、Snell、走时与首波推导、震级体系、烈度、海啸、斜坡 | **考试硬通货**，配套作业一 |
| [[08_考点速查手册]] | 定义、公式、数值、对比表 | 考前最后冲刺 |
| [[09_作业一精解]] | 8 道作业题的规范答案与首波走时完整推导 | 直接对应考试题型 |
| [[10_参考书对照与预习指引]] | 每章读哪本书的哪一章；第四至十一章预习路线 | 拓深与预习 |

**建议节奏（考前 2 周）：**

1. D1–D2：通读 01、02、03、04，配合课件快速过一遍（每个文件 30–40 分钟）。
2. D3–D4：攻 05、06（第三章是"重点最多、难点最多"的一章，值得花最多时间）。
3. D5：做 07 的推导题（首波走时一定自己推一遍，不要只看）。
4. D6：背 08 速查手册。
5. D7–D8：做 09 的题目，闭卷复述每道题的答题框架。
6. D9–D10：用 10 预习第四至六章（尤其 PSHA 四步与地震动三要素，通常期中/期末都会涉及）。
