## 2. 人类认识地震的历史

### 2.1 从神话到科学

古人想象：中国古代"阴阳失调"、古代印度"地下大象"、台湾"地牛翻身"、日本"鲶鱼嬉戏"。

**真正对地震的科学认识始于我国东汉 132 年张衡的候风地动仪。**它的科学价值在于隐含了一个本质性理解：

> **地震是一种远方传过来的地面震动**——这一概念建立了**地震与地震波的直接联系**。

这个概念直到 18 世纪才被西方科学家所认识。

### 2.2 现代地震学与两条发展主线

- **现代地震学开始于 19 世纪末精密地震仪的出现**（如 Palmieri 的电磁式地震仪）。
- 从地震科学诞生之日起，一直沿两个方向发展：**① 认识地震；② 利用地震**。

## 3. 认识地震

### 3.1 物理机制（必背的三句式表述）

> 地震是由**地下岩石的突然断裂**造成的；地球内部的不断运动造成**地壳大规模变形是地震的根源**；**地壳沿地震断裂的突然滑移是地震波能量辐射的直接原因**。物理本质上是因地球内部缓慢积累的能量突然释放，引起地球表层的振动。

### 3.2 成因学说：板块构造学说

全球地震活动性分布（1964–1997，所有深度）显示地震主要集中在板块边界——这是板块构造学说最有力的证据之一。

### 3.3 局部成因：弹性回跳说（Reid，1911）

1906 年旧金山地震后，Reid 根据圣安德烈斯断层（Carrizo Plain 段）错动提出**弹性回跳假说**：

断层两侧岩体长期受构造力作用发生弹性应变积累（岩石"弯而不破"）→ 应力超过摩擦强度时突然滑动 → 应变能突然释放（地震）→ 岩体回弹到未变形状态。之后 Brace 和 Byerlee（1966）根据岩石力学实验结果指出，地震发生过程类似岩石摩擦实验中的**粘滑**现象，从而较完整地概括了地震的成因机制。

### 3.4 地震的基本类型（五套分类，务必记全）

| 分类依据 | 类型 |
| --- | --- |
| **按震动的性质** | 天然地震、人工地震、脉动 |
| **按成因** | 构造地震、火山地震、陷落地震 |
| **按震源深度** | 浅源地震（< 60 km）、中源地震（60–300 km）、深源地震（> 300 km） |
| **按震中距** | 地方震（Δ < 100 km）、近震（Δ < 1000 km）、远震（Δ > 1000 km） |
| **按震级** | 弱震（M < 3）、有感地震（M ≈ 3 ~ 4.6）、中强震（M ≈ 4.5 ~ 6）、强震（M > 6，其中 M > 8 为巨大地震） |

> 记忆技巧：**性质—成因—深度—距离—震级**，五把尺子量同一个地震。

### 3.5 震源机制与断层

课件用 1976 唐山、1979 Imperial Valley、Guatemala 等震例照片说明地表破裂现象，并给出断层的几何参数与基本类型。

**断层三要素（必背，课件特别提示"滑动角容易出错"）：**

| 参数 | 定义 | 注意 |
| --- | --- | --- |
| **走向（strike）** | 断层面与水平面交线的方向（取 0°–360°） | 有 180° 的不确定性 |
| **倾角（dip）** | 断层面与水平面的夹角（0°–90°） | - |
| **滑动角 / 倾伏角（rake）** | 断层面上**滑动方向**与**走向**的夹角（-180°–180°） | **最易错**：是"滑动方向"相对走向的角度，不是相对水平面的角度 |

两个辅助概念：**上盘 / 下盘**（断层面上方与下方的岩块）、**foot wall / hanging wall**（同义）。

**断层基本类型：**

| 类型 | 上盘运动 | rake 大致范围 | 力学背景 |
| --- | --- | --- | --- |
| **正断层**（Normal） | 上盘相对下降 | ≈ -90° | 拉张 |
| **逆断层 / 逆冲断层**（Reverse/Thrust） | 上盘相对上升 | ≈ +90° | 挤压 |
| **走滑断层**（Strike-slip） | 两盘水平错动 | ≈ 0° 或 180° | 剪切 |

走滑断层再分**左旋**（左行，站在一侧看对侧向左）与**右旋**（右行）。

> 工程意义：逆断层（逆冲）的**垂直运动最大**，正断层次之，走滑断层几乎没有垂直运动——这直接决定了哪类地震容易产生海啸（见 [[04_地震地质灾害]]）。

## 4. 地震波：认识地球的"一盏明灯"

### 4.1 体波

地震在地球内部产生两种体波：

- **P 波（纵波 / 压缩波）**：质点振动方向与传播方向**平行**，产生体积压缩与膨胀；
- **S 波（横波 / 剪切波）**：质点振动方向与传播方向**垂直**，只产生剪切变形、无体积变化。

按质点振动方向与射线所在铅垂面的关系，S 波分为：

- **SV 波**：振动在铅垂面内；
- **SH 波**：振动在水平面内（垂直于铅垂面）。

### 4.2 面波

> 面波是沿地球表面附近传播的一种弹性波，**传播速度比体波慢**。

最重要的两种：

| 面波 | 质点运动 | 速度 |
| --- | --- | --- |
| **Rayleigh（瑞利）波** | 质点在**沿波传播方向的垂直平面内**作**逆进椭圆运动**（像水面上的波浪） | 约为 0.92 V_S，较慢 |
| **Love（勒夫）波** | 质点作**水平运动**，运动方向与传播方向垂直；**地面质点运动最大，越往地下深处振幅越小** | **比 Rayleigh 波快** |

（更系统的体波/面波、频散与产生条件，见 [[07_基础知识专题]] 第 3 节。）

### 4.3 利用地震波揭示地球分层结构（大事年表，必背）

| 年份 | 人物 | 贡献 |
| --- | --- | --- |
| 1906 | **奥尔德姆**（Oldham） | 首先试图从地震波穿过地球的时间推断整个地球内部构造 |
| **1909** | **莫霍洛维奇**（Mohorovičić） | 根据近震初至波走时，算出地下 56 km 处存在间断面，其上下平均速度分别为 5.6 km/s 与 7.8 km/s。后确认该界面普遍存在，平均深度约 30 km → **莫霍界面**；界面以上为**地壳**，以下为**地幔** |
| 1914 | **古登堡**（Gutenberg） | 根据体波"影区"确认地核存在，测定地幔-地核间断面深度 **2900 km**（数值至今改动不大）；根据地核不能传播横波推断地核为液态 |
| 1936 | **赖曼**（Lehmann） | 通过对影区的进一步研究，发现在液态地核中还有一个**固态内核** |
| 1996 | 宋晓东（旅美中国学者） | 通过穿过地核的地震波推断**内核旋转速度比外核快**，被评为该年度美国十大科学新闻之一 |
| 2025 | 中国科大孙道远、毛竹团队 | 分析 NASA"洞察号"记录的火震数据，首次确证**火星内部存在半径约 600 km 的固态内核**（发表于《自然》） |

**影区的物理意义（必考）：**20 世纪初，地震学家发现大地震发生后，在距震中约 **103°–143°** 的范围内记录不到 P 波，于是猜想地球具有分层结构——地球内部有一个**低速的地核**，P 波由于折射到达不了该范围。这是"用地震波照亮地球内部"的经典范例。

> 类比：拍西瓜听声音判断成熟度——地球物理工作者通过"倾听"地球内部的振动（地震波）来判断内部结构与状态。**迄今为止，地震波是唯一能够贯穿地球的波动。**

### 4.4 利用地震（认识之外的"第二条线"）

课件列举的用途，考试常以简答或论述的形式出现：

1. **地震勘探**——石油与矿产资源勘探中最主要和最有效的方法之一（利用反射与折射）；
2. **核爆炸监测**——全面禁止核试验条约（CTBT）的地震台站；地下爆炸记录特征是**"大头小尾"**，天然地震是**"小头大尾"**，据此可区分；
3. **爆炸/事故监测**——2000 年 8 月俄罗斯"库尔斯克号"潜艇爆炸事件由波罗的海地震台记录的地震波最终澄清起因；"9·11"事件中距世贸中心 34 km 的地震台记录了全过程；
4. **火山喷发预测**、**水库诱发地震研究**（如三峡工程库区）、**矿山地震监测**（保护矿山安全）；
5. **行星探测**——通过行星自由振荡研究揭示行星内部大尺度结构。

## 5. 地震的特点

### 5.1 能量巨大

表示地震大小基本有两种方法：**① 用震级表示地震的大小；② 根据破坏程度（烈度）确定地震的大小。**

1935 年 **Charles Richter** 首次引入震级概念。零级定义为：Δ = 100 km 处，A₀ = 1 微米时所对应的震级：

$$M_L=\lg A(\Delta)-\lg A_0(\Delta)$$

震级与能量的经验关系（Gutenberg–Richter，**erg** 制）：

$$\lg E = 11.8 + 1.5M \quad (E \text{ 为地震波能量，erg})$$

> **因此：震级每相差 1 级，能量相差约 31.6 倍（10^1.5）。** 课件提问"震级相差 1 级，能量相差多少倍"，答案就是这个数。

（更完整的震级体系与饱和问题见 [[07_基础知识专题]] 第 5 节。）

### 5.2 破坏力巨大：烈度与震级的区别

课件用一张表说明"烈度表征破坏程度"：

| 烈度 | 宏观现象 |
| --- | --- |
| < III 度 | 人无感受，只有仪器能记录到 |
| III 度 | 夜深人静时人有感受 |
| IV–V 度 | 睡觉的人惊醒，吊灯摆动 |
| VI 度 | 器皿倾倒、房屋轻微损坏 |
| VI–VII 度 | 房屋破坏，地面裂缝 |
| VIII–X 度 | 房倒屋塌，地面破坏严重 |
| XI–XII 度 | 毁灭性的破坏 |

> **某地点的地震烈度表示地震引致该地地面运动的猛烈程度。** 一次地震只有一个震级，但不同地点有不同的烈度。

### 5.3 分布规律：规律性与随机性共存

**三个主要地震带（比例必记）：**

| 地震带 | 占全球地震比例 | 说明 |
| --- | --- | --- |
| **环太平洋地震带** | **约 70%** | 日本、台湾、美国加州圣安德烈斯断层区等 |
| **欧亚地震带**（地中海—喜马拉雅） | 约 15% | 分布比较分散，不像环太平洋带那样集中、有规则 |
| **洋脊地震带**（沿各大洋洋中脊） | 约 5% | - |

**剩余约 10% 的地震是"板内地震"**——分布在这些地震带之外、离板块边界相当远的地方，如美国新马德里地震带。**中国大陆发生的地震多属板内地震，其发生机制仍是个未解之谜。**

### 5.4 突发性和毁灭性

- 地震发生具有**突发性，难以预报**——世界性难题；
- 地震灾害具有**毁灭性**。
