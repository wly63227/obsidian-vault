# 第二章（二）　地震烈度与震害

> 课件：03_260914（P13–P67）、04_260916（P1 回顾）
> 重点：地震学基础知识及地震宏观现象
> 难点：地震灾害分析，**地震烈度的发展与现状**

---

## 1. 地震烈度的含义（必背定义）

> **地震烈度（Intensity）是指地震发生时在某一地区引起的地震动强度及其所产生的影响、造成破坏的强烈程度。**

三个要点：

1. 烈度以**人的感觉、器物反应、房屋等结构和地表破坏程度**综合评定；
2. 反映的是**一定地域范围内**（如自然村或城市部分区域）的**平均水平**；
3. 与震级的本质区别：**震级描述地震本身的大小（一次地震只有一个震级）；烈度描述地震在某地点的影响（同一次地震各地烈度不同）。**

---

## 2. 烈度的起源与发展（时间线）

| 时间 | 事件 | 意义 |
| --- | --- | --- |
| **1564** | 意大利地图绘制者**伽斯塔尔第**（J. Gastaldi）在地图上用各种颜色标注滨海阿尔卑斯（Maritime Alps）地震影响和破坏程度不同的地区 | **地震烈度概念和烈度分布图的雏形** |
| **1874** | 意大利人**罗西**（M. S. de Rossi）编制了**最早有实用价值的地震烈度表** | 确立了烈度评定的基本共识 |
| 19 世纪末至今 | 各国编制并修订烈度表 | 苏联烈度表、MSK、MM（麦加利）、JMA（日本气象厅）、EMS（欧洲）等 |

**罗西烈度表确立的四点共识（常考）：**

1. 从弱到强按等级划分地震烈度，**烈度只有整数值**；
2. 利用地震的**宏观影响和各种破坏现象**评定烈度；
3. **不探究这些现象间的联系或因果关系**，最终结果以**综合平均**的方式确定；
4. 烈度由评定者根据烈度表**主观判定**。

**烈度表的定义：**说明地震烈度的等级划分、评定方法与评定标志的技术标准。

**常用烈度表对照（课件给出 8 级左右的宏观现象对比）：**

课件给出的一张横向对比图，把各烈度表划分的等级与宏观现象并列。要点是：**各表虽然等级划分数量不同（多数表为 12 度，日本 JMA 为 0–7 的 8 级体系），但描述的现象由弱到强的顺序是一致的**：

| 由弱到强的宏观现象 | 说明 |
| --- | --- |
| 几乎没有感觉 | 只有仪器能记录到 |
| 感觉如车边的震动 | 少数人有感 |
| 人人有感，睡者惊醒 | 器皿倾倒 |
| 对砖石建筑造成破坏 | 部分墙倒 |
| 人难以站立，大范围破坏，山崩滑坡 | 地面破坏 |
| 全面破坏，地面起伏如波浪 | 毁灭性破坏 |

> 复习提示：考试更可能考**我国烈度表的等级、评定指标与房屋分类**，以及**烈度与震级的区别**，而不是各表之间的逐度对应关系。

## 3. 中国地震烈度表（GB/T 17742—2020）★重点

### 3.1 与以往烈度表的区别（核心：增加了仪器烈度指标）

> a) 不具备仪器测定地震烈度条件的地区，**应**使用宏观调查评定地震烈度；
> b) 具备仪器测定条件的地区，**宜**采用仪器测定的地震烈度。

**评定指标包括：**房屋震害、人的感觉、器物反应、生命线工程震害、其他震害现象和仪器测定的地震烈度。
**评定方法：综合运用宏观调查和仪器测定的多指标方法。**

### 3.2 术语与定义

| 术语 | 定义 |
| --- | --- |
| 地震烈度 | 地震引起的地面震动及其影响的强弱程度 |
| **震害指数**（damage index） | 房屋震害程度的**定量指标**：以 0.00 到 1.00 之间的数字表示由轻到重的震害程度 |
| **平均震害指数** | 同类房屋震害指数的加权平均值，即各级震害的房屋所占比率与其相应震害指数乘积之和 |

### 3.3 烈度等级与数量词界定

- 地震烈度分为 **12 等级**，分别用罗马数字（Ⅰ–Ⅻ）或阿拉伯数字（1–12）表示。

**数量词界定（容易出填空 / 选择）：**

| 数量词 | 范围 |
| --- | --- |
| 个别 | 10% 以下 |
| 少数 | 10% ~ 45% |
| 多数 | 40% ~ 70% |
| 大多数 | 60% ~ 90% |
| 绝大多数 | 80% 以上 |

### 3.4 评定烈度的房屋类型（五类，必背）

| 代号 | 类型 |
| --- | --- |
| **A1 类** | 未经抗震设防的土木、砖木、石木等房屋 |
| **A2 类** | 穿斗木构架房屋 |
| **B 类** | 未经抗震设防的砖混结构房屋 |
| **C 类** | 按照 Ⅶ 度（7 度）抗震设防的砖混结构房屋 |
| **D 类** | 按照 Ⅶ 度（7 度）抗震设防的钢筋混凝土框架结构房屋 |

### 3.5 房屋破坏等级及对应震害指数（必背数值）

| 破坏等级 | 定义 | 震害指数范围 |
| --- | --- | --- |
| 基本完好 | 承重和非承重构件完好，或个别非承重构件轻微损坏，不加修理可继续使用 | 0.00 ≤ d < 0.10 |
| 轻微破坏 | 个别承重构件出现可见裂缝，非承重构件有明显裂缝，不需修理或稍加修理即可继续使用 | 0.10 ≤ d < 0.30 |
| 中等破坏 | 多数承重构件出现轻微裂缝，部分有明显裂缝，个别非承重构件破坏严重，需要一般修理后可使用 | 0.30 ≤ d < 0.55 |
| 严重破坏 | 承重构件严重破坏，需大修或局部拆除 | 0.55 ≤ d < 0.85 |
| 毁坏 | 承重构件多数破坏，结构濒于崩溃或已倒毁 | 0.85 ≤ d ≤ 1.00 |

### 3.6 评定指标的其他方面

除房屋震害外，烈度表还按烈度逐度给出：**人的感觉**（静止中的人有感 → 室内少数人有感 → 多数人有感 → 绝大多数人有感、少数人惊逃户外 → 多数人惊逃户外 → 多数人站立不稳、惊逃户外）、**器物反应**（悬物微动 → 悬物明显摆动 → 悬挂物大幅度摆动、器皿作响声 → 少数家具移动 → 物品掉落、器物翻倒）、**生命线工程震害**（梁桥挡块破坏、拱桥主拱圈裂缝桥台开裂 → 变压器套管破坏、供水管道破坏 → 桥梁垮塌、管网破坏、区域停水）、**其他震害**（河岸和松软土出现裂缝、喷水冒砂 → 地面裂缝、滑坡、崩塌常见；独立砖烟囱多数倒塌）。

## 4. 烈度分布图：等震线及其信息（必考）

### 4.1 定义

把烈度相同的点连接起来的封闭曲线称为**等震线（烈度等值线）**，其分布图称为**烈度分布图**。

课件给出的经典图件：1970 年通海 7.7 级地震等震线图（据胡聿贤）、1976 年唐山 7.8 级地震烈度分布图（据杨理华，含**高烈度异常区 7–8 度**）、1556 年华县 8 级地震等震线图（据郭增建）、1976 年危地马拉 7.9 级等震线图。

### 4.2 从等震线形状可获得的信息（课件明确列出：断层走向、倾向、破裂传播方向、地震动衰减特性等）

| 信息类型 | 具体内容 |
| --- | --- |
| 宏观震中与震中烈度 | 最内圈等震线（极震区）中心即宏观震中，其烈度为震中烈度 I₀ |
| **断层走向与破裂方向** | 等震线**长轴方向通常与发震断层走向一致**；长轴长度与破裂长度相关；极震区常偏向**破裂传播方向**前方（方向性效应） |
| 烈度衰减规律 | 等震线疏密反映烈度随距离衰减的快慢（越密衰减越快） |
| 震源深度 | 深源地震等震线面积小、极震区烈度低 |
| 场地条件与烈度异常 | 等震线不完全同心、出现高/低烈度异常区，反映**局部场地效应**（软弱土层、盆地、地形放大）或介质横向不均匀 |
| 抗震设防基础资料 | 等震线是编制烈度区划图、震害预测、历史地震参数评定的主要依据 |

### 4.3 影响地震烈度的因素（课件图）

**震级、震源深度、震中距、地质条件、建筑性能、地下水、波动时间**（不同地层和建筑对同一地震波的反应不同；不同地质结构有不同的地震波谱）。

另外课件特别指出**"烈度等震线和震中的两种定义"**问题——宏观震中（极震区几何中心）与仪器震中（微观震中）可能不重合。

## 5. 传统地震烈度的特性、适用性与用途

### 5.1 特性（三个）

1. **多指标的综合性**；
2. **分等级的宏观性**；
3. **以后果表示原因的间接性**。

### 5.2 适用性（课件原话，注意其"警示"意味）

> 地震烈度是一个**粗略的等级概念**，是一定范围内地震影响强弱程度的**总体评价**，这种衡量是**定性的、宏观的、综合性的**。**不应过分外推其应用范围**，用其表示地震动的多种特性，或从中推求出多种设计地震动参数。

### 5.3 用途（三条）

1. 作为**震害的简便估计**；
2. 为地震工作者提供一种**宏观尺度**来描述地震影响的大小；
3. 作为一种**粗略而简便的指标**，为地震工程总结抗震经验、进行**烈度区划**，从而规定地震动设计参数。

## 6. 现代地震烈度的发展：仪器烈度 ★

### 6.1 为什么需要仪器烈度

传统烈度靠宏观调查，滞后、主观、覆盖面差。现代做法是**采用地震动参数使之定量化**（课件引用 Wald et al., 1999, *Earthquake Spectra*, Vol.15, No.3, 557–564）。

> 课件同时提醒：仪器烈度本身并不足以做损失估计——**峰值速度（PGV）和谱反应能提供更"物理"的定量基础**；但对多数用户，烈度图比其他地震动参数图更易理解、更有用。

### 6.2 Wald 等的换算关系（I < IX 时）

$$\mathrm{MMI} = 3.66\lg(\mathrm{PGA}) - 1.66 \quad (\mathrm{PGA}\ \text{单位为 g},\ \sigma = 1.08)$$

$$\mathrm{MMI} = 3.47\lg(\mathrm{PGV}) + 2.35 \quad (\mathrm{PGV}\ \text{单位为 cm/s},\ \sigma = 0.98)$$

### 6.3 应用

- **ShakeMap**（USGS）：以仪器烈度显示地震动分布，颜色对应潜在损害等级；
- **PAGER**：给出暴露人口（暴露于各烈度级的人口数）的快速估计；
- 2008 年汶川地震、2004 年苏门答腊地震等均发布过仪器烈度图 / PAGER 图；
- 我国 2005 年瑞昌 5.7 级地震中，仪器记录显示震中东南约 28 km 处仪器烈度（PGA）达 9 度。

## 7. 震害实例（可用于论述题的论据）

### 7.1 1906 年旧金山大地震

- 1906 年 4 月 18 日清晨 5 点 20 分，旧金山发生约 8.3 级地震，**6 万余人遇难**；
- 震时**全城起火**，社会秩序混乱，抢劫杀人等恶性事件多有发生，全市进入紧急状态，近 10 万人逃离城市，经济损失超过 5 亿美元；
- 课件出示了市长令（授权射杀抢劫者、命令所有煤气和电力公司停止供气供电、居民集中于家中不外出）；
- 圣安德烈斯断层错动使栅栏**水平错开 2.6 m**（照片）→ 现代地震科学的诞生。

**教学要点：**次生灾害（火灾）往往比地震动本身造成的损失更大——这是"城市地震灾害特点"的前置知识。

### 7.2 其他典型震害类型

| 震例 | 破坏特征 | 工程教训 |
| --- | --- | --- |
| 1984 Morgan Hill、1980 El Asnam、1994 Northridge | 建筑物破坏 | 结构抗震设计 |
| 1965 Seattle | 交通系统破坏 | 生命线工程 |
| 1964 Alaska（Valdez 油罐区火灾）、1979 El Centro、1964 Niigata | 次生火灾、**砂土液化（sand boil）** | 地基失效 |
| 1985 墨西哥地震 | **场地效应**（不同土层厚度处加速度差异巨大） | 场地分类与土层反应 |

### 7.3 现代地震学史上标志性大地震（课件汇总，必背对应关系）

| 时间 | 地震 | 标志性意义 |
| --- | --- | --- |
| 1906 | 美国旧金山 8.3 级 | **现代地震科学的诞生**；弹性回跳说提出 |
| 1923 | 日本关东 7.9 级 | **工程地震学的诞生**；日本首次规定设计地震力 |
| 1933-03-10 | 美国 Long Beach M6.3 | **世界上第一次记录到强震加速度记录**，工程地震学作为学科研究的起点 |
| 1960-05-22 | 智利 Mw9.5 | **迄今全球震级最大的地震**；震中烈度可达 Ⅻ 度；破裂长度约 1000 km；引发跨太平洋海啸 |
| 1966-06-27 | 美国 Parkfield M5.6 | 首次获取台阵观测记录（2 号加速度仪距地表破裂约 80 m）；促成**强震地震学**形成 |
| 1964 | 日本新潟 Niigata M7.5 | **砂土液化**导致钢筋混凝土建筑整体倾倒（结构本身未破坏），推动土动力学与液化判别方法 |
| 1975-02-04 | 中国海城 M7.3 | **历史上首次（且迄今唯一一次）成功的 7 级以上地震短临预报**，大幅减少人员伤亡 |
| 1976-07-28 | 中国唐山 M7.8 | **现代地震史上伤亡、破坏最惨烈**；24 万余人遇难，城市几乎被毁；我国抗震设防与地震预报研究的重要转折 |
| 1985 | 墨西哥 | **场地效应**的经典震例（不同土层厚度处加速度差异巨大） |
| 1995-01-17 | 日本阪神（兵库县南部）Mw7.3 | **改变了"破坏性大地震可能发生区域/地点"的观念**；**首次出现地下工程的明显破坏**；约 6400 人死亡；高架桥倒塌 |
| 1999-09-21 | 中国台湾集集 Mw7.6 | **历史上首次最为完备的近场强震观测数据**、研究最为透彻的大地震；车笼埔断层地表破裂约 100 km；石冈大坝被断层破坏 |
| 2011-03-11 | 日本东北 9.0 级 | 板间逆冲型巨大地震；引发最高约 40 m 海啸；**历史上首次由于自然灾害造成的核电站毁坏**（福岛核事故） |

### 7.4 中国的重要震例（第三章也会用到）

| 地震 | 关键数据 | 工程地震意义 |
| --- | --- | --- |
| **1966-03-08 邢台** M6.8（震源深度 10 km，震中烈度 Ⅸ 度强） | 3 月 8–29 日 21 天内连续发生 5 次 6 级以上地震，最大为 3 月 22 日 7.2 级（深 9 km，震中烈度 Ⅹ 度） | **中国强震观测的起点**；邢台震区存在一条北东向河流坡降异常带 |
| **1975-02-04 海城** M7.3 | 波及 9000 km²，受灾人口 800 万 | 成功预报，大量减少伤亡 |
| **1976-07-28 唐山** M7.8 | 24 万余人遇难 | 城市直下型地震的惨痛教训 |
| **2008-05-12 汶川** M8.0 | 69227 人遇难、17923 人失踪；倒塌房屋 778.91 万间、损坏 2459 万间；16 条国道省道干线与 6 条铁路受损；形成较大堰塞湖 35 处；2473 座水库出现险情；6443 个规模以上工业企业一度停产 | 新中国受灾最大的地震之一；**引发大量灾难性滑坡与堰塞湖**（见第 04 篇） |
| 2011-03-11 日本 M9.0 | 破裂面长 450–500 km、宽 150 km；逆冲断层；最大错动 18 m；宫城县记录到 PGA **2933 gal**；福岛核电站海啸爬高 14 m（实际海啸高 15 m，远超设计考虑的 5 m） | **超预期地震**的典型：震级与海啸规模都超出原先估计 |
