## 0. 知识地图：两条主线

计算机视觉解决"从图像理解世界"的问题，历史上形成两条互补的技术路线：

```
                        计算机视觉
                            │
        ┌───────────────────┴───────────────────┐
        ▼                                       ▼
  几何 / 解析派                            数据驱动派
  （Multi-view Geometry）                （Deep Learning / CNN）
        │                                       │
  相机模型 → 对极几何 →                  CNN基础 → 图像分类 →
  三角化 / 位姿估计(PnP) /               目标检测(YOLO/R-CNN) →
  相机标定 / SfM-SLAM                    神经风格迁移 / 人脸验证
        │                                       │
  特点：可解释、白盒、解析解              特点：端到端、黑盒、数据驱动
        └───────────────────┬───────────────────┘
                            ▼
                    交汇：混合方法
        CNN提特征（SIFT→SuperPoint）→ 喂给几何求解器
        深度估计 / NeRF / SLAM 前端的深度学习化
```

**核心洞见**：传统方法每一步都可解释（代数式子、矩阵分解），深度学习端到端但需大量数据。工程实践中两者常结合——用网络做感知（特征匹配、深度），用几何做约束（BA 优化、位姿解算）。

## 第一部分 成像几何基础

### 1.1 三维视觉的基本问题

- **本质**：成像是 3D→2D 的**降维压缩**过程，深度信息在此过程中丢失；三维视觉 = **成像的逆问题**，从低维图像还原原本的三维信息。
- **要还原的内容**：
  1. **场景结构**（三维点的几何关系）；
  2. **相机几何** = **内参**（焦距、主点、畸变等相机固有物理参数）+ **外参**（相机在场景中的位置与朝向，共 **6 个自由度**：3 旋转 + 3 平移）。
- **难点**：逆问题欠定——无穷多组（场景 + 相机）可以成像出同一张图，因此必须**联立求解**，无法单独还原场景或相机。
- **人 vs 计算机**：人眼是"标准双目系统"——内参固定且已内化于大脑，两眼光轴水平、瞳距约 8.5 cm（即外参已知），因此人脑做的是**已知内外参的三角化**，轻松获得空间结构。计算机视觉则希望用算法（单目/多目/多视角）复现并超越这一能力。

### 1.2 相机模型与坐标系

**小孔成像模型（Pinhole Camera Model）** 是整个几何派的数学基石：

$$
s\begin{bmatrix} u \\ v \\ 1 \end{bmatrix} = \underbrace{\begin{bmatrix} f_x & s & c_x \\ 0 & f_y & c_y \\ 0 & 0 & 1 \end{bmatrix}}_{\text{内参矩阵 } K}\; \underbrace{\begin{bmatrix} R & t \end{bmatrix}}_{\text{外参 } [R|t]}\; \begin{bmatrix} X \\ Y \\ Z \\ 1 \end{bmatrix}
$$

| 符号 | 含义 | 自由度 |
|---|---|---|
| $K$ | 内参矩阵：$f_x, f_y$ 焦距（像素），$s$ 倾斜系数，$(c_x, c_y)$ 主点 | 5 |
| $R$ | 旋转矩阵 | 3 |
| $t$ | 平移向量 | 3 |
| 投影矩阵 $P = K[R|t]$ | 3×4，尺度意义下 | 11 |

- 内参是相机**固有物理属性**，制造完成即确定，与拍摄场景无关；
- 外参描述相机在世界坐标系中的位姿；无世界坐标系时，可把第一个相机坐标系当作世界系（此时 $R=I,\ t=0$）。

### 1.3 射影空间与齐次坐标

- **动机**：欧氏几何中无穷远点/线/面无法直接参与计算，而相机标定与重建中**无穷远元素至关重要**。
- **做法**：把欧氏空间提升到**射影空间**——非齐次坐标 $(X,Y,Z)$ 加一维变成齐次坐标 $(X,Y,Z,1)$。
- **妙处**：无穷远元素 = 最后一维为 0 的齐次坐标（除回去即得无穷大），于是**有限远与无穷远元素都可用有限数值统一表达、参与计算**。摄影几何中大量"无穷远"概念（如消隐点、无穷远直线）由此变得可计算。

### 1.4 稀疏重建 vs 稠密重建

实际 pipeline 中，图像进来先**提特征**（传统 SIFT / 深度网络特征），后续只操作特征：

- **稀疏重建（Sparse）**：只还原**特征点**的三维空间关系 → 得到稀疏三维点云；
- **稠密重建（Dense）**：还原（几乎）每个像素的深度 → 稠密点云 / 网格（后续内容，涉及立体匹配、光度一致性等）。

## 第二部分 四大核心子问题

从"已知图像 + 图像间匹配，反推全部几何"的总问题出发，按**已知信息的多少**可分解为四个子问题，复杂度递增：

| 子问题 | 已知 | 求解目标 | 典型应用 |
|---|---|---|---|
| 三角化 | $K,\ R,\ t$ + 图像匹配点 | 三维点 $X$ | 双目立体视觉（人眼） |
| 姿态估计 PnP | $K$ + 3D 场景 $X$ + 2D-3D 匹配 | 相机位姿 $R,\ t$ | 机器人定位、AR |
| 相机标定 | 3D 场景结构 $X$ + 图像匹配点 | 内参 $K$（连带解出 $R,t$） | 获取相机内参 |
| 稀疏重建 SfM / SLAM | 只有图像（+匹配） | $K,\ R,\ t,\ X$ 全部 | 三维重建、机器人 SLAM |

> 术语：计算机视觉称 **SfM**（Structure from Motion，运动恢复结构），机器人领域称 **SLAM**（Simultaneous Localization and Mapping，同步定位与建图）——二者数学原理完全相同（$X$ = 建图，$Rt$ = 定位）。更严格的叫法是**"结构与运动的同步估计"**。

### 2.1 三角化（Triangulation）——最简问题

**定义**：已知两（多）相机内外参与图像匹配点 $(x_1, x_2)$，求三维点 $X$。

**几何直觉**：从左相机光心过 $x_1$、右相机光心过 $x_2$ 各发一条**反投影射线**，两射线交点即 $X$。

**求解**：
1. 相机参数已知 → 两条射线方程可**解析写出**；
2. 理想情况下相交；实际因参数误差、像素量化误差**不相交**；
3. **解析近似解法**：求两条射线的**公垂线**，取公垂线段**中点**作为 $X$ 的估计——几何直观合理，且给定射线方程后公垂线可解析求出，无需迭代优化。

**人类类比**：人眼双目 = 内参已知（大脑内化）+ 外参已知（固定瞳距 8.5 cm、光轴水平），匹配两眼图像后做三角化即得空间位置——这是最"标准"的三角化实例。

### 2.2 姿态估计 / PnP（Perspective-n-Point）

**定义**：已知内参 $K$ 与三维场景点（地图）及其在图像中的对应点，求相机当前位姿 $(R,t)$。数学上 = "**已知 $K$ 的相机标定**"，只是输入从干净的人工标定物变成真实场景匹配（噪声、误匹配、光照/季节变化更多）。

**最小配置分析**（理解 RANSAC 效率的关键）：
- 投影矩阵 $P$ 有 **11 个自由度** = $K$ 的 5 + $R$ 的 3 + $t$ 的 3；
- 一组 2D-3D 对应点提供 **2 个约束** → 一般需 6 组点（12 约束）线性解算 $P$；
- **已知 $K$ 后只剩 6 个自由度** → 最少 **3 组点**即可解出位姿；
- 点数直接决定 RANSAC 的成功率：3 点 vs 6 点，同等迭代次数下成功率**指数级提升**。

**算法家族**：

| 算法 | 点数 | 解的个数 | 说明 |
|---|---|---|---|
| P2P | 2 | 无穷多 | 欠定，不存在 |
| **P3P** | 3 | 4 个 | 经典代数几何解（Gao et al.），需第 4 点验证剔除 3 个非物理解 |
| **P4P** | 4 | ≤4（共面时唯一） | |
| **P5P** | 5 | ≤2 | 再用 1 点验证 |
| EPnP | 4 | 唯一 | 高效实用 |
| DLT | ≥6 | 1（线性直接解） | 过冗余时不如 RANSAC 经济 |

**工程实践**：P3P、P4P、P5P **同时计算、投票决策**（多数一致即采纳）。每个都是白盒解析解、毫秒级，计算总量可忽略，但组合后稳定性大增。

**剔除假解的物理准则**：三角化后三维点必须落在**相机前方**（深度为正）——代数上光线可无限传播，物理上相机不可能"看到背后"的点。

### 2.3 相机标定（Camera Calibration）

**定义**：已知场景三维结构 $X$（标定物），拍摄图像建立 2D-3D 对应，求解相机内参 $K$。

**关键认知**：内参与位姿**耦合**，必须一起解——相机位姿无法用别的方式直接获取，所以"只想求内参"也必须把 $R,t$ 一并解出来，再从结果中分解出 $K$。数学上等价于"不知道内参的姿态估计"。

**标定物两类**：
- **3D 标定物**（三维标定块）：角点精度可达**亚像素**，三维坐标精度可达**亚毫米**，输入非常干净；
- **2D 平面标定物**（棋盘格，多个视角）：最常用。

**标定流程与验证**（解析法）：
1. 检测图像角点（亚像素精度）；
2. 建立 2D-3D 对应，DLT 线性解出投影矩阵 $P$（再分解出 $K, R, t$）；
3. **验证**：把三维点**重投影**回图像，与检测角点比对像素距离——各视角下普遍在 **0.5 像素以内**即认为标定正确；
4. （重要）解析解是**代数误差**最小，非几何误差最小 → 应把结果当初值，再做**投影误差最小化**的非线性优化（如 Bundle Adjustment），得到几何意义下的最优 $K,R,t$。

### 2.4 稀疏重建 / SfM / SLAM——最难的完整问题

只有图像（严格说只有**图像间的特征匹配关系**），求解 $K, R, t, X$ **全部未知量**。详见第三部分两视图重建。

## 第三部分 两视图稀疏重建完整流程

"从纯图像到全部成像参数"的经典解析 pipeline：

```
两幅图像 + 特征匹配
        │
        ▼
   粗略内参 K（从 EXIF 估算，允许不准）
        │
        ▼
  5点法求解 本质矩阵 E
        │
        ▼
  SVD 分解 E → 4 组候选 (R, t)
        │
        ▼
  三角化验证（深度为正）→ 唯一物理解 (R, t)
        │
        ▼
  三角化 → 三维点云 X
        │
        ▼
  K, R, t, X 全部获得（代数解）
        │
        ▼
  Bundle Adjustment 优化（投影误差最小）→ 最终结果
```

### 3.1 对极几何：基本矩阵 F 与本质矩阵 E

两视图匹配点的约束关系（**对极几何**）：

$$
x_1^\top F\, x_2 = 0
$$

- **基本矩阵 $F$**（3×3，秩 2）：把内外参全部打包：
  $$F = K_2^{-\top} E\, K_1^{-1}$$
- **本质矩阵 $E$**：只含两相机的相对运动（内参被吸收掉）：
  $$E = [t]_\times R$$
  其中 $[t]_\times$ 是平移向量的反对称矩阵。

### 3.2 求解与分解

1. **八点法**：8 组匹配点 → 构建线性方程组 → DLT 解出 $F$；
2. **五/七点法**：已知粗略 $K$ 后转求 $E$（非线性多项式，但稳健）；
3. **SVD 分解 $E$**：$E$ 做奇异值分解后可构造出 **4 组** $(R,t)$，都满足代数约束；
4. **物理准则筛选**：对 4 组解分别把所有匹配点三角化，**只有一组**使三维点绝大多数落在两相机前方（深度为正）——其余三组会出现"点在相机后方"的物理悖论。

### 3.3 内参从哪来：EXIF 小技巧（未标定场景的工程实践）

- 数码照片的文件头（EXIF）自带元数据：拍摄时间、相机/镜头型号、分辨率、**物理焦距**、光圈、ISO，甚至 GPS 坐标——可直接用工具读取；
- 例：读到物理焦距 6 mm、传感器 1/2.5 英寸、分辨率 2500×1900 → 传感器宽度 ÷ 像素数 = 单个感光单元宽度（mm/px）→ 6 mm ÷ 单元宽度 = **像素焦距**（约 626 px）；
- 由此构造 $K$：假设 $f_x = f_y$、主点在图像中心、倾斜系数 $s=0$；
- 该值**不必精准**——后面还要做优化，粗值足以启动 pipeline。

> 多视图时同理扩展：增量式/全局式 SfM、Bundle Adjustment。

## 第四部分 从解析到数据驱动：方法论演进

### 4.1 代数误差 vs 几何误差（本课程最重要的一对概念）

| | 代数误差（解析解） | 几何误差（优化解） |
|---|---|---|
| 做法 | DLT、SVD、矩阵分解，让**代数式**在最小二乘下最优 | 最小化**重投影误差**（3D→2D 投影差） |
| 优点 | 线性、白盒、可解释、快 | 几何意义正确、精度高 |
| 缺点 | 代数式没有几何含义，不是真最优 | 非线性、需初值、慢 |
| 关系 | 作为优化的**初值** | 在初值上迭代求精 |

**实践准则**：解析解开路，优化收官。所有子问题（标定、PnP、SfM）都遵循此模式。

### 4.2 鲁棒性工具箱

- **RANSAC**：输入匹配含大量外点（误匹配）时，用随机采样 + 共识投票迭代估计，容忍高比例离群值；
- **投票融合**：多个最小配置解算器（P3P/P4P/P5P）并联投票，兼顾速度与可靠性；
- **物理约束剔除**：深度为正、共面性等先验直接砍掉非物理解。

### 4.3 数据驱动派：吴恩达计算机视觉课程框架（深度学习路线）

与几何派平行，吴恩达 deeplearning.ai《卷积神经网络》专项课程构建了数据驱动路线：

**模块一：CNN 基础与图像分类**
- 计算机视觉经典任务：图像分类、目标检测、人脸验证、神经风格迁移；
- 卷积运算的动机：边缘检测 → 参数共享 → 平移不变；
- Padding、Stride、卷积层、池化层；
- 经典网络演进：LeNet-5 → AlexNet → VGG → **ResNet**（残差连接，解决深层网络退化）→ Inception（1×1 卷积降维）；
- 数据增强、迁移学习（实战主力技巧）。

**模块二：深度卷积模型细节**
- 1×1 卷积的"瓶颈"作用；Inception 网络；移动端高效网络思路；
- 训练技巧：数据增强扩样、用开源权重做迁移学习。

**模块三：目标检测与分割**
- 目标定位、关键点（Landmark）检测；
- 滑动窗口 → 基于卷积的高效实现；
- **YOLO**（单阶段，快）与 **R-CNN → Fast R-CNN → Faster R-CNN**（两阶段，准）；
- Anchor 框、IoU、**非极大值抑制 NMS**；
- 语义分割与 U-Net（编解码结构）。

**模块四：人脸验证与神经风格迁移**
- One-shot 问题、**Siamese 网络**、Triplet Loss（人脸验证/识别）；
- 神经风格迁移 = 内容代价 + 风格代价（用中间层特征的相关性刻画"风格"）。

### 4.4 两条路线的对比与交汇

| 维度 | 几何 / 解析派 | 数据驱动派 |
|---|---|---|
| 输入 | 少量精心匹配的特征点 | 大量原始图像数据 |
| 可解释性 | 白盒，每步有几何意义 | 黑盒，端到端 |
| 精度控制 | 显式误差模型 + 优化 | 依赖数据分布与泛化 |
| 计算 | 轻量，可实时（毫秒级） | 依赖 GPU |
| 数据需求 | 极少（甚至可零训练） | 海量标注 |

**交汇融合（当代主流）**：
- 用 CNN 做传统模块的替换：**学习型特征匹配**（SuperPoint / LoFTR）替代 SIFT；
- **深度估计**：单目/双目深度学习直接回归深度图（接棒稠密重建）；
- **SLAM 前端深度学习化** + 后端仍用几何（BA / 位姿图优化）；
- **NeRF / 3D 高斯泼溅**：可微渲染把重建变成数据驱动的优化问题——"解析"与"学习"在可微渲染框架下真正合流。

## 第五部分 公式与概念速查

### 5.1 核心公式

| 名称 | 公式 | 用途 |
|---|---|---|
| 小孔成像 | $x = K[R|t]X$ | 一切几何的起点 |
| 齐次坐标 | $(X,Y,Z)\!\to\!(X,Y,Z,1)$，无穷远点末位为 0 | 统一表达无穷远元素 |
| 基本矩阵约束 | $x_1^\top F x_2 = 0$ | 两视图对极约束 |
| F 与 E 关系 | $F = K_2^{-\top} E K_1^{-1}$ | 剥离/恢复内参 |
| 本质矩阵 | $E = [t]_\times R$ | 编码两视图相对运动 |
| 重投影误差 | $\sum\|x_i - \pi(K,R,t,X_i)\|^2$ | BA 优化的目标函数 |
| 三角化 | 两射线求交（实际取公垂线中点） | 已知位姿求 3D 点 |
| 八点法 | $x_1^\top F x_2=0$ 线性解 $F$ | 求基本矩阵 |
| 自由度账 | $P$: 11 = $K$: 5 + $R$: 3 + $t$: 3 | 最小配置估算 |
