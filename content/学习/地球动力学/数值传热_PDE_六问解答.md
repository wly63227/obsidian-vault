## 1. 向前、向后、中心差分

它们都是用网格点上的函数值**近似导数**的公式，来源都是 Taylor 展开。设步长 $h$：

$$f(x+h)=f(x)+hf'(x)+\frac{h^{2}}{2}f''(x)+\frac{h^{3}}{6}f'''(x)+\cdots$$

| 名称 | 一阶导数公式 | 截断误差 | 精度 |
|---|---|---|---|
| 向前差分 | $f'(x)\approx\dfrac{f(x+h)-f(x)}{h}$ | $-\dfrac{h}{2}f''(\xi)$ | 一阶 $O(h)$ |
| 向后差分 | $f'(x)\approx\dfrac{f(x)-f(x-h)}{h}$ | $+\dfrac{h}{2}f''(\xi)$ | 一阶 $O(h)$ |
| 中心差分 | $f'(x)\approx\dfrac{f(x+h)-f(x-h)}{2h}$ | $-\dfrac{h^{2}}{6}f'''(\xi)$ | 二阶 $O(h^{2})$ |

### 要点

- **中心差分精度更高**，因为它把 $h$ 的奇次项消掉了；代价是要用左右两侧的信息。
- 一阶导数的误差符号有物理意义：当 $f''>0$（曲线向上凸）时，向前差分**高估**导数，向后差分**低估**导数。
- 二阶导数中心差分：

  $$f''(x)\approx\frac{f(x+h)-2f(x)+f(x-h)}{h^{2}},\qquad \text{误差 } O(h^{2})$$

  热传导方程的空间项 $\partial^{2}T/\partial x^{2}$ 就是用它离散的。
- **边界上**只能用单侧差分（左端向前、右端向后），或用虚拟节点（ghost point）保持二阶精度。
- **选择哪种差分取决于物理**：对流项 $\partial T/\partial x$ 若用中心差分，网格 Peclet 数 $Pe=\rho u\Delta x/\Gamma>2$ 时会出现非物理振荡，此时要用**迎风格式**（$u>0$ 时用向后差分取上游信息）。
- **时间方向同理**：
  - 前向欧拉：显式，需满足稳定条件（一维显式 $\alpha\Delta t/\Delta x^{2}\le 1/2$）；
  - 后向欧拉：隐式，无条件稳定；
  - Crank–Nicolson：$O(\Delta t^{2})$，无条件稳定。

## 2. 边界条件是什么

PDE 描述的是"内部规律"，对任意满足方程的场都成立；要得到**唯一解**，还必须给出定解条件。稳态问题只需要边界条件，非稳态问题需要**初始条件 + 边界条件**。

### 四类常见边界条件

| 类型  | 名称         | 数学形式                                                                                                | 物理含义             |                                                    |
| --- | ---------- | --------------------------------------------------------------------------------------------------- | ---------------- | -------------------------------------------------- |
| 第一类 | Dirichlet  | $T(0,t)=T_{w}$                                                                                      | 给定边界上的温度值        |                                                    |
| 第二类 | Neumann    | $-k\dfrac{\partial T}{\partial n}\Big                                                               | _{\Gamma}=q_{w}$ | 给定边界上的热流；绝热时 $q_{w}=0$，即 $\partial T/\partial n=0$ |
| 第三类 | Robin / 混合 | $-k\dfrac{\partial T}{\partial n}=h\,(T_{s}-T_{\infty})$                                            | 对流换热边界           |                                                    |
| 第四类 | 界面条件       | $T_{1}=T_{2},\quad k_{1}\dfrac{\partial T_{1}}{\partial n}=k_{2}\dfrac{\partial T_{2}}{\partial n}$ | 两区域交界处温度与热流连续    |                                                    |

### 为什么必须有边界条件

- **数学上**：PDE 积分后出现的任意常数、任意函数必须靠定解条件确定，否则解不唯一。
- **物理上**：边界条件就是**环境对系统的作用**——壁面温度、外部热流、对流散热。同一方程配不同边界条件结果可以完全不同（同一根杆，两端恒温得到线性分布，一端绝热得到均匀分布）。
- **数值上**：$N$ 个未知节点需要 $N$ 个方程。内部节点给出 $N-2$ 个方程，剩下的**边界方程由边界条件补上**，线性方程组才封闭可解。边界条件还决定矩阵的右端项（非零边界值 → 非齐次项）和矩阵结构。

### 数值实现方式

- 直接使用**单侧差分**：最简单，但只有一阶精度；
- 引入**虚拟节点**并做镜像处理：可保持二阶精度；
- **有限体积法的能量平衡法**（半网格）：最守恒、最稳健，适合不规则边界。

## 3. 方阵的快速解法

核心思想：**不要显式求逆矩阵**，而是利用矩阵结构选择算法。设未知量个数为 $N$。

| 方法 | 适用结构 | 运算量 | 说明 |
|---|---|---|---|
| 高斯消元 / LU 分解 | 通用 | $O(N^{3})$，约 $\frac{2}{3}N^{3}$ | 分解一次后，多个右端项只需 $O(N^{2})$ 前代回代 |
| Cholesky 分解 | 对称正定 | 约 $O(N^{3}/3)$ | 运算量减半，无需选主元 |
| **Thomas 算法（追赶法）** | 三对角 | $O(N)$ | 一维稳态导热、一维隐式格式的标准解法 |
| Sherman–Morrison | 循环三对角 | $O(N)$ | 周期边界条件，化归为两个三对角求解 |
| 块 Thomas / ADI | 块三对角 | 低于 $O(N^{3})$ | 二维隐式格式的行方向求解 |
| Jacobi / Gauss–Seidel / SOR | 稀疏、对角占优 | 每步 $O(N^{2})$（二维网格） | SOR 取最优 $\omega$ 时收敛最快 |
| 共轭梯度法 CG | 对称正定 | 依赖条件数 | 常配预条件（PCG） |
| **多重网格法** | 椭圆型方程 | $O(N)$ | 各频率误差分量都被高效消除，实用上最快 |
| FFT 快速 Poisson 求解 | 矩形、周期 | $O(N^{2}\log N)$ | 周期或矩形区域 |
| GMRES / BiCGSTAB | 通用大型稀疏 | —— | Krylov 子空间方法 |

### 关键认识

- **结构决定算法**。一维问题离散后是三对角矩阵，Thomas 算法 $O(N)$；若用通用高斯消元 $O(N^{3})$，$N=10^{4}$ 时是 $10^{12}$ 量级对比 $10^{4}$ 量级，差距直接决定问题能不能算。
- **分解复用**。同一系数矩阵、多个右端项（不同时间步、不同边界条件）时，先做 LU 分解最划算。
- **选法顺序**：先看结构（对称？正定？三对角？带状？稀疏？）→ 选直接法还是迭代法 → 再考虑并行与精度。
- **条件数**同样重要：病态矩阵即使算法很快，数值结果也可能不可靠。

## 4. 齐次和非齐次怎么区分

用线性算子 $L$ 写最清楚：

- **齐次**：$L[u]=0$，方程中**每一项都含有未知函数或其导数**，没有独立的外加项（源项）。
- **非齐次**：$L[u]=f$，$f\ne 0$，$f$ 是与 $u$ 无关的"外源 / 外驱动"。

### 三层含义要分清

| 层次 | 齐次 | 非齐次 |
|---|---|---|
| 方程 | $\dfrac{\partial^{2}T}{\partial x^{2}}=0$ 或 $\dfrac{\partial^{2}T}{\partial x^{2}}+\dfrac{S}{k}=0$ 中 $S=0$ | $S\ne 0$（有内热源） |
| 边界条件 | $T(0)=0$，$\partial T/\partial n=0$ | $T(0)=T_{w}\ne 0$，$-k\partial T/\partial n=q_{w}\ne 0$ |
| 整个定解问题 | 方程与所有定解条件都齐次 | 任一条非齐次即非齐次 |

**最容易出错的地方**：一维稳态无内热源导热 $\dfrac{d^{2}T}{dx^{2}}=0$，方程本身**是齐次的**；但如果两端给定非零温度 $T(0)=T_{0},\ T(L)=T_{L}$，整个问题**是非齐次的**——非零边界就是驱动。所以"方程齐次"$\ne$"问题齐次"。

### 性质与用途

- **叠加原理**：齐次问题满足，两个解相加仍是解；非齐次问题不满足。
- **解的结构**：非齐次通解 = 一个特解 + 对应齐次方程的通解。
- **齐次化技巧**：令 $T=\theta+T_{p}$，其中 $T_{p}$ 吸收非齐次边界或源项，$\theta$ 满足齐次问题，再用分离变量 / 特征函数展开求解。
- **数值表现**：齐次对应 $Ax=0$（零解或特征值问题，用于稳定性分析）；非齐次对应 $Ax=b$，源项和非零边界值全部进入右端项 $b$。

## 5. 理解 PDE 如何描述物理过程

PDE 不是凭空写出来的公式，而是**"守恒律 + 本构关系"的微分形式**。理解它分三步。

### 第一步：找守恒量

对任意控制体写"储存量的变化率 = 净流入 + 内部生成"：

- 质量守恒 → 连续性方程；
- 动量守恒 → Navier–Stokes 方程；
- 能量守恒 → 能量方程；
- 组分守恒 → 扩散方程。

### 第二步：用本构关系把通量和未知量连起来

热流用 **Fourier 定律** $\mathbf{q}=-k\nabla T$；剪应力用 **Newton 粘性定律**；质量扩散用 **Fick 定律**。这一步把"通量"换成"场变量的梯度"。

### 第三步：把积分形式局部化

控制体任意取都成立，把体积收缩到一点，就得到微分方程。

### 以热传导方程为例，每一项都有明确物理含义

$$\underbrace{\rho c\frac{\partial T}{\partial t}}_{\text{储热速率}}=\underbrace{\nabla\cdot(k\nabla T)}_{\text{净导入热量}}+\underbrace{S}_{\text{内热源}}$$

- 非稳态项为 0 → 稳态问题，得到 **Poisson / Laplace 方程**；
- 加上对流项 $u\cdot\nabla T$ → **对流扩散方程**，用 $Pe$ 数判断对流与扩散谁主导；
- 有内热源 → 非齐次；无源无驱动 → 齐次。

### 方程类型对应物理行为（最值得记住的一张表）

| 类型 | 代表方程 | 物理过程 | 数学性质 |
|---|---|---|---|
| 椭圆型 | Laplace / Poisson | 稳态平衡、不可压流动 | 边值问题；任一点变化全场立即响应 |
| 抛物型 | 热传导 / 扩散 | 时间不可逆、光滑化 | 初值 + 边值问题；"扰动瞬时传遍全场"是扩散近似的结果 |
| 双曲型 | 波动 / 无粘对流 | 有限速度传播、守恒 | 特征线方法；初值问题 |

### 分析工具

- **无量纲数与尺度分析**：$Re$、$Pe$、$Nu$、$Bi$、$Fo$，判断哪一项主导、哪一项可忽略；
- **定解条件**：初始条件 + 边界条件，说明过程从何处开始、受何种环境影响；
- **数值求解**：把 PDE 离散成网格点上的代数方程组，用**相容性、稳定性、收敛性**衡量，并考察离散格式是否**守恒**（守恒型格式正是把高斯定理直接作用在控制体上得到的）。

## 6. 用高斯定理 + 微分思想推导热力学公式

这里的"高斯方程"指**高斯散度定理**：

$$\oint_{S}\mathbf{F}\cdot\mathbf{n}\,dA=\int_{V}\nabla\cdot\mathbf{F}\,dV$$

它把"边界面上的通量"换成"体积内的源 / 汇"，是**把积分形式的守恒律变成微分形式 PDE 的关键一步**。

### 以热传导方程为例的完整推导

**第 1 步：对控制体写能量守恒。** 在物体内任取控制体 $V$，表面为 $S$：

$$\frac{d}{dt}\int_{V}\rho c\,T\,dV=-\oint_{S}\mathbf{q}\cdot\mathbf{n}\,dA+\int_{V}S\,dV$$

**第 2 步：代入 Fourier 定律** $\mathbf{q}=-k\nabla T$：

$$-\oint_{S}(-k\nabla T)\cdot\mathbf{n}\,dA=\oint_{S}k\nabla T\cdot\mathbf{n}\,dA$$

**第 3 步：应用高斯定理**，把面积分换成体积分：

$$\oint_{S}k\nabla T\cdot\mathbf{n}\,dA=\int_{V}\nabla\cdot(k\nabla T)\,dV$$

**第 4 步：合并为同一个体积分**：

$$\int_{V}\left[\rho c\frac{\partial T}{\partial t}-\nabla\cdot(k\nabla T)-S\right]dV=0$$

**第 5 步：微分思想最关键的一步——局部化。** 控制体 $V$ 是任意取的，被积函数连续；若一个连续函数在任意区域上的积分都为零，则该被积函数必须处处为零。让 $V$ 收缩到一点（微元），即得微分形式：

$$\boxed{\ \rho c\frac{\partial T}{\partial t}=\nabla\cdot(k\nabla T)+S\ }$$

**第 6 步：化简为常用形式。** 若 $k$ 为常数，除以 $k$：

$$\nabla^{2}T+\frac{S}{k}=\frac{1}{\alpha}\frac{\partial T}{\partial t},\qquad \alpha=\frac{k}{\rho c}$$

- 稳态：$\nabla^{2}T=-\dfrac{S}{k}$（Poisson 方程）；
- 稳态无内热源：$\nabla^{2}T=0$（Laplace 方程）。

### 推广到其他守恒型方程

推导逻辑完全一样：

- **质量守恒**：

  $$\frac{d}{dt}\int_{V}\rho\,dV=-\oint_{S}\rho\mathbf{u}\cdot\mathbf{n}\,dA\ \Longrightarrow\ \frac{\partial\rho}{\partial t}+\nabla\cdot(\rho\mathbf{u})=0$$

- **动量守恒**：通量项用高斯定理转成 $\nabla\cdot(\rho\mathbf{u}\mathbf{u})$ 与 $\nabla\cdot\boldsymbol{\tau}$，再代入本构关系 → Navier–Stokes 方程；
- **组分守恒** → 对流扩散方程；**内能 / 焓守恒** → 能量方程。

最后配合热力学状态关系（如 $dh=c_{p}\,dT$）使方程组闭合，即得到完整的热流体控制方程组。

### 与数值方法的联系

- **有限体积法**：反向使用这一推导——不做微分，而是**保留每个控制体上的积分形式**，用高斯定理把扩散项写成面通量，直接对网格单元做守恒。天然守恒，适合复杂边界。
- **有限差分法**：先把 PDE 写出来（第 5、6 题的结果），再用第 1 题的差分公式离散。

## 总结：六问之间的关系

1. **高斯定理把"边界上的通量"变成"内部的微分算子"**，得到 PDE（第 5、6 题）；
2. **PDE 需要定解条件才能唯一求解**，即初始条件与边界条件（第 2 题）；
3. **齐次 / 非齐次决定解的叠加性质与离散方程的右端项**（第 4 题）；
4. **离散时使用差分公式**，并根据物理选择格式（第 1 题）；
5. **离散后的大代数方程组按矩阵结构选择快速算法**（第 3 题）。

PDE（第 5、6 题）→ 定解条件（第 2 题）→ 齐次性（第 4 题）→ 离散（第 1 题）→ 快速求解（第 3 题）。
