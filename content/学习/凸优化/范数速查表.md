# 范数速查表（一页打印版）

> 配套：`凸优化从零到精通.md` 第 14–22 章、第 35 章
> 用法：打印后放在手边，做题/写代码/读论文时随时对照。

---

## 1. 三条公理

$$
\|x\|\ge0,\ \|x\|=0\iff x=0;\qquad \|\alpha x\|=|\alpha|\|x\|;\qquad \|x+y\|\le\|x\|+\|y\|
$$

**关键推论**：正齐次 + 三角不等式 $\Longrightarrow$ 单位球是**凸**且**对称**的。
**反向**（Minkowski 泛函）：任意凸、对称、有界、含原点为内点的集合 $\mathcal{C}$ 定义范数 $\|x\|_\mathcal{C}=\inf\{t>0\mid x/t\in\mathcal{C}\}$。

---

## 2. 常用范数

| 名称 | 定义 | 单位球 | 光滑 | 用途 |
| --- | --- | --- | --- | --- |
| $\ell_1$ | $\sum_i\|x_i\|$ | 菱形 | ✗ | 稀疏 |
| $\ell_2$ | $\sqrt{\sum_ix_i^2}$ | 圆 | ✓（除 0）| 最小二乘 |
| $\ell_\infty$ | $\max_i\|x_i\|$ | 正方形 | ✗ | 最坏情况 |
| $\ell_p$ | $(\sum_i\|x_i\|^p)^{1/p}$，$p\ge1$ | 中间形 | ✓（除 0）| 一般度量 |
| 加权 $\ell_1$ | $\sum_iw_i\|x_i\|$ | 变形菱形 | ✗ | 自适应稀疏 |
| 加权 $\ell_2$ | $\sqrt{x^\top Wx}$ | 椭圆 | ✓ | 相关结构 |
| Frobenius | $\sqrt{\sum_{ij}x_{ij}^2}$ | 矩阵球 | ✓ | 矩阵误差 |
| 谱范数 | $\sigma_{\max}$ | — | ✗ | 鲁棒性 |
| 核范数 | $\sum_i\sigma_i$ | — | ✗ | 低秩 |
| $\ell_{2,1}$ | $\sum_i\|x_{i\cdot}\|_2$ | — | ✗ | 行稀疏 |
| 诱导 $\|A\|_1$ | 最大**列**和 | — | ✗ | 逐列质量 |
| 诱导 $\|A\|_\infty$ | 最大**行**和 | — | ✗ | 逐行质量 |
| 诱导 $\|A\|_2$ | $\sigma_{\max}$ | — | ✗ | 最大放大倍数 |

**不是范数**：$\ell_0$（计数）、$\ell_p\ (0<p<1)$、$\|x\|_2^2$、TV、Huber、$\|Ax\|$（$A$ 奇异）、$\sqrt{\|x\|_1}$。

## 3. 对偶范数

$$
\|y\|_*=\sup_{\|x\|\le1}y^\top x=\sigma_{\mathcal{B}}(y),\qquad
\boxed{y^\top x\le\|x\|\,\|y\|_*}
$$

| 原范数 | 对偶范数 |
| --- | --- |
| $\ell_1$ | $\ell_\infty$ |
| $\ell_2$ | $\ell_2$（自对偶）|
| $\ell_\infty$ | $\ell_1$ |
| $\ell_p$ | $\ell_q$，$\frac1p+\frac1q=1$ |
| 加权 $\ell_1$（$w$）| $\max_i|y_i|/w_i$ |
| 加权 $\ell_2$（$w$）| $\sqrt{\sum_iy_i^2/w_i}$ |
| 马氏 $\|\cdot\|_W$ | $\|\cdot\|_{W^{-1}}$ |
| 核范数 | 谱范数 |
| 谱范数 | 核范数 |
| Frobenius | Frobenius |
| $\ell_{2,1}$ | $\max_i\|y_{i\cdot}\|_2$ |

## 4. 次微分

$$
g\in\partial f(x)\iff f(y)\ge f(x)+g^\top(y-x)\ \forall y;\qquad
\boxed{x^\star\ \text{最优}\iff0\in\partial f(x^\star)}
$$

| 函数 | 位置 | 次微分 |
| --- | --- | --- |
| $\|x\|_1$ | $x_i=0$ | $[-1,1]$ |
| $\|x\|_1$ | $x_i\ne0$ | $\text{sign}(x_i)$ |
| $\|x\|_2$ | $x=0$ | $\{g:\|g\|_2\le1\}$ |
| $\|x\|_2$ | $x\ne0$ | $x/\|x\|_2$ |
| $\|x\|_\infty$ | 唯一最大分量 $j$ | $\text{sign}(x_j)e_j$ |
| 加权 $\ell_1$ | $x_i=0$ | $[-w_i,w_i]$ |
| $\|X\|_*$ | 任意 | $UV^\top+W$，$\|W\|_2\le1$，$U^\top W=WV=0$ |
| $\|X\|_2$ | 最大奇异值唯一 | $u_1v_1^\top$ |
| $\|X\|_{2,1}$ | 零行 | $\{w:\|w\|_2\le1\}$ |

## 5. 近端算子

$$
\text{prox}_{tg}(v)=\arg\min_x\Big\{g(x)+\frac1{2t}\|x-v\|_2^2\Big\}
$$

| $g(x)$ | $\text{prox}_{tg}(v)$ | 名称 |
| --- | --- | --- |
| $\lambda\|x\|_1$ | $\text{sign}(v)\max\{|v|-\lambda t,0\}$ | 软阈值 |
| $\lambda\|x\|_2$ | $\big(1-\lambda t/\|v\|_2\big)_+v$ | 块软阈值 |
| $\lambda\|X\|_*$ | $U\text{diag}\big((\sigma-\lambda t)_+\big)V^\top$ | SVT |
| $I_\mathcal{C}$ | $\Pi_\mathcal{C}(v)$ | 投影 |

---

## 6. 共轭函数

| $f(x)$ | $f^*(y)$ |
| --- | --- |
| $\frac12x^\top Qx$（$Q\succ0$）| $\frac12y^\top Q^{-1}y$ |
| $\|x\|$ | $I_{\{\|y\|_*\le1\}}$ |
| $I_\mathcal{C}(x)$ | $\sigma_\mathcal{C}(y)$ |
| $e^x$ | $y\log y-y$（$y\ge0$）|
| $-\log x$ | $-1-\log(-y)$（$y<0$）|
| $x\log x$ | $e^{y-1}$ |

**Fenchel**：$f(x)+f^*(y)\ge x^\top y$，取等 $\iff y\in\partial f(x)$。

## 7. 不等式

| 名称 | 形式 |
| --- | --- |
| Cauchy–Schwarz | $\|x^\top y\|\le\|x\|_2\|y\|_2$ |
| Hölder ($1/p+1/q=1$) | $\sum_i\|x_iy_i\|\le\|x\|_p\|y\|_q$ |
| Young | $ab\le\frac{a^p}{p}+\frac{b^q}{q}$ |
| AM–GM | $\frac{a+b}{2}\ge\sqrt{ab}$ |
| 三角 | $\|x+y\|\le\|x\|+\|y\|$ |
| 反向三角 | $\big\|\|x\|-\|y\|\big\|\le\|x-y\|$ |
| Jensen | $f(\sum\theta_ix_i)\le\sum\theta_if(x_i)$ |
| 对偶配对 | $y^\top x\le\|x\|\,\|y\|_*$ |
| 等价常数 | $\|x\|_\infty\le\|x\|_2\le\sqrt n\|x\|_\infty$；$\|x\|_2\le\|x\|_1\le\sqrt n\|x\|_2$ |
| 矩阵版 | $\|A\|_2\le\|A\|_F\le\sqrt{\text{rank}(A)}\|A\|_2$ |

## 8. 模型化归

| 形式 | 家族 | 写法要点 |
| --- | --- | --- |
| $\|Ax-b\|_1$ | LP | 引入 $u\ge\pm(Ax-b)$ |
| $\|Ax-b\|_\infty$ | LP | 引入 $t$，$|Ax-b|\le t$ |
| $\|x\|_1\le t$ | LP | $-u\le x\le u$、$\mathbf{1}^\top u\le t$ |
| $\|Ax-b\|_2$ | SOCP | 二阶锥约束 |
| $\sum_g\|x_g\|_2\le t$ | SOCP | 每组一个二阶锥 |
| $\|x\|_2^2$ | QP | 二次目标 |
| $\|X\|_*$、$\|X\|_2$、$\lambda_{\max}$ | SDP | LMI 表述 |
| 正项式（正变量）| GP | 取对数变凸 |

## 9. 五个必背错误（考试与工程高频）

1. 把 $\sum_ix_i^2$ 当 $\ell_2$ 范数（需要开方）；
2. 用 $\ell_2$ 正则期望稀疏（不会稀疏，只会收缩）；
3. 写 $\|x\|_1=1$ 当凸约束（非凸，应写 $\le$）；
4. 记错对偶范数（$\ell_1\leftrightarrow\ell_\infty$、核范数 $\leftrightarrow$ 谱范数）；
5. 不标准化、还惩罚截距就做 $\ell_1$ 正则。

## 11. 一行公式集

$$
\begin{aligned}
&\|x\|_2^2=\textstyle\sum_ix_i^2,\qquad \|x\|_1=\textstyle\sum_i|x_i|,\qquad\|x\|_\infty=\max_i|x_i|\\
&\nabla\|x\|_2^2=2x,\qquad \nabla\|x\|_2=\frac{x}{\|x\|_2}\ (x\ne0),\qquad \partial\|x\|_1=\text{sign}(x)\ \text{或}\ [-1,1]\\
&\|A\|_2=\sigma_{\max},\qquad \|A\|_*=\textstyle\sum_i\sigma_i,\qquad \|A\|_F=\sqrt{\textstyle\sum_{ij}a_{ij}^2}\\
&\text{prox}_{\lambda\|\cdot\|_1}(v)=S_\lambda(v),\qquad \text{prox}_{\lambda\|\cdot\|_*}(V)=U\,\text{diag}(S_\lambda(\sigma))\,V^\top\\
&\lambda_{\max}=\|A^\top b\|_\infty\ \text{（Lasso 的全零阈值）}
\end{aligned}
$$
