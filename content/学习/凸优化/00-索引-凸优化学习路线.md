## 五、一句话记住这门课

$$
\text{凸集}+\text{凸函数}\ \Longrightarrow\ \text{局部最优}=\text{全局最优}\ \Longrightarrow\ \text{可求解、可验证}
$$

而**范数**是这套结构里最通用的度量工具，承担四重角色：

1. **度量大小**（误差项）；
2. **诱导结构**（稀疏、低秩、分组）；
3. **定义对偶**（对偶范数、最优性条件）；
4. **刻画几何**（范数球 ⟷ 凸集）。

## 六、环境准备（动手部分）

```bash
pip install numpy scipy cvxpy matplotlib scikit-learn
```

| 库 | 用途 |
| --- | --- |
| `numpy` | 矩阵与数值线性代数 |
| `cvxpy` | 凸优化建模（DCP 规则）|
| `scipy` | 稀疏矩阵、线性代数 |
| `scikit-learn` | Lasso/Ridge/ElasticNet 的工业实现、交叉验证 |
| `matplotlib` | 画单位球、正则化路径、TV 去噪结果 |

**自带求解器**：CVXPY 默认安装 `ECOS`（SOCP/LP）与 `SCS`（SDP、一阶）；更高精度可另装 MOSEK / Gurobi。
