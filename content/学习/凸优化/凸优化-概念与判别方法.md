## 1. 标准形式与定义

一个优化问题写成如下标准形式：

$$
\begin{aligned}
\min_{x}\quad & f_0(x) \\
\text{s.t.}\quad & f_i(x)\le 0,\quad i=1,\dots,m \\
& h_j(x)=0,\quad j=1,\dots,p
\end{aligned}
$$

其中 $x\in\mathbb{R}^n$ 是决策变量，$f_0$ 是目标函数，$f_i$ 是不等式约束，$h_j$ 是等式约束。

**定义**：该问题是凸优化问题，当且仅当

1. 目标函数 $f_0$ 是凸函数；
2. 每个不等式约束函数 $f_i$ 是凸函数；
3. 每个等式约束函数 $h_j$ 是仿射函数，即 $h_j(x)=a_j^\top x+b_j$。

此时可行域 $\mathcal{D}=\{x\mid f_i(x)\le0,\ h_j(x)=0\}$ 是凸集，问题等价于「凸集上最小化凸函数」。

> 直观理解：目标函数的等高线像「碗」，可行域是「一块没有凹陷的空间」。两者叠加后，不会出现「两个局部最低点之间隔着一道山」的情况。

---

## 2. 为什么凸优化重要

| 性质 | 含义 |
|---|---|
| 局部最优 = 全局最优 | 任何满足最优性条件的点都是全局最优解，梯度类算法停下即可放心 |
| 最优解集是凸集 | 多解时解集凸；若目标严格凸，则最优解唯一 |
| 有成熟算法 | 内点法、梯度/次梯度法、近端算法、ADMM，且有收敛性保证 |
| 有强对偶理论 | Slater 条件成立时强对偶成立，可通过对偶问题求最优值并给出最优性证书 |
| 可判定、可建模 | 有 DCP 等规则集，可以对表达式自动判定凸性 |

## 3. 五个组成部分的凸性要求

| 组成部分 | 要求 | 原因 |
|---|---|---|
| 目标 $f_0$ | 凸函数 | 保证局部最优即全局最优 |
| 不等式约束 $f_i(x)\le 0$ | $f_i$ 是凸函数 | 凸函数的下水平集是凸集 |
| 等式约束 $h_j(x)=0$ | $h_j$ 是**仿射**函数 | 只有仿射等式的解集一定是凸集 |
| 隐含定义域 | 是凸集 | 定义域本身不凸，问题就不可能凸 |
| 变量类型 | 连续变量 | 整数、二元变量破坏凸性 |

### 关于等式约束的说明

等式约束**必须**是仿射的，不能是任意凸函数：

- $h(x)=ax+b=0$：解集是超平面，凸 ✓
- $h(x)=x^2=0$：解集是单点 $\{0\}$，恰好凸，但这不是一般规律
- $h(x)=x^2-1=0$：解集是 $\{-1,1\}$，不是凸集 ✗

一般来说，凸函数的等式约束对应非凸可行域，因此标准形式中只允许仿射等式。

如果原问题写成 $g(x)\ge 0$ 的不等式，先改写成 $-g(x)\le 0$，再要求 $-g$ 凸，即 $g$ 是**凹**函数。

## 4. 判断流程：五步检查法

### 第一步：明确变量、目标与约束

把问题整理成「$\min$ … s.t. …」的形式，写清楚：

- 决策变量 $x$ 是什么、维度多少；
- 目标函数要最小化（还是最大化 → 取负号转成最小化）；
- 每一条约束想表达什么。

### 第二步：找出隐含定义域

函数自带的定义域也是约束，这一步最容易翻车：

| 表达式 | 隐含约束 |
|---|---|
| $\log x$、$\log\det X$ | $x>0$、$X\succ 0$ |
| $1/x$、$x/y$ | $x\ne0$、$y\ne0$（通常写成 $y>0$） |
| $\sqrt{x}$ | $x\ge 0$ |
| $\|x\|_p$ | $p\ge 1$ 才是范数 |
| $\mathrm{tr}(X^{-1})$ | $X\succ 0$ |

隐含定义域必须是凸集，否则直接判非凸。

### 第三步：检查约束

- 所有不等式整理成 $f_i(x)\le0$ 的统一形式；
- 检查每个 $f_i$ 是否凸（或 $g\ge0$ 形式下 $g$ 是否凹）；
- 检查等式是否仿射（$Ax=b$）；
- 出现下面这些，基本可以直接判非凸：
  - $\|x\|=1$、$x^2=1$ 等非仿射等式；
  - $x_i\in\{0,1\}$、$x_i\in\mathbb{Z}$ 等整数/二元约束；
  - $\|x\|_0\le k$（稀疏度约束）；
  - $\mathrm{rank}(X)\le k$（低秩约束）；
  - 形如 $x^\top P x\le 1$ 且 $P$ 不定的二次约束。

### 第四步：验证目标函数（及每个 $f_i$）是凸的

按手头信息选择一种方法（详见第 5 节）：定义、一阶条件、二阶条件、保凸运算组合、限制在直线上。

### 第五步：确认「凸性」是问题层面的

同一个问题可以有非凸写法和凸写法，判断要针对**等价规范形式**：

- $\min\ x^2/y$（$y>0$）：看似分式，其实是凸的；
- $\min\ x^2-y^2$：看似二次型，其实非凸；
- 几何规划、稀疏正则、协方差矩阵估计等，原始写法非凸，经变量代换后可转成凸问题。

## 5. 验证函数凸性的方法

### 方法一：定义

对任意 $x,y\in\mathrm{dom}\,f$ 和任意 $\theta\in[0,1]$：

$$
f(\theta x+(1-\theta)y)\le \theta f(x)+(1-\theta)f(y)
$$

几何意义：函数图像上任意两点连线，位于函数图像上方（「弦在图像上方」）。

### 方法二：一阶条件（$f$ 可微）

$$
f(y)\ge f(x)+\nabla f(x)^\top(y-x),\quad \forall x,y\in\mathrm{dom}\,f
$$

几何意义：函数始终在其任意一点的切平面**上方**——这是凸函数最常用的判别直觉。

### 方法三：二阶条件（$f$ 二阶可微）

$$
\nabla^2 f(x)\succeq 0,\quad \forall x\in\mathrm{dom}\,f
$$

即 Hessian 矩阵处处半正定。一元情形退化为 $f''(x)\ge 0$。

例子：

- $f(x)=x^2$，$f''=2>0$ → 凸；
- $f(x)=-\log x$，$f''=1/x^2>0$（$x>0$）→ 凸；
- $f(x)=x^2-y^2$，Hessian $=\mathrm{diag}(2,-2)$ 不定 → 非凸。

### 方法四：限制在直线上

$f$ 凸 $\iff$ 对任意 $x$ 和方向 $v$，一元函数

$$
t\mapsto f(x+tv)
$$

都是凸的。这条既能手算，也便于写代码数值抽查。

### 方法五：保凸运算组合（最实用）

不需要算 Hessian，按第 6 节的规则逐层搭建即可。

## 6. 保凸运算清单

如果 $f,g$ 是凸函数，$\alpha,\beta\ge0$，那么：

| 运算 | 结果 | 说明 |
|---|---|---|
| 非负加权和 | $\alpha f+\beta g$ 凸 | 凸性对非负线性组合封闭 |
| 仿射复合 | $f(Ax+b)$ 凸 | 最常见的一类 |
| 逐点最大值 | $\max\{f(x),g(x)\}$ 凸 | 可推广到任意多个函数 |
| 逐点上确界 | $\sup_{\alpha} f_\alpha(x)$ 凸 | 最大值的一般形式 |
| 部分变量最小化 | $g(x)=\inf_{y} f(x,y)$ 凸 | 很强，很多问题靠它化凸 |
| 透视函数 | $g(x,t)=t\,f(x/t)$ 凸 | 定义域 $t>0$ |
| 复合（保序） | $f$ 凸非减、$g$ 凸 ⇒ $f(g(x))$ 凸 | 单调方向必须对 |
| 复合（反序） | $f$ 凸非增、$g$ 凹 ⇒ $f(g(x))$ 凸 | 注意 $g$ 是凹的 |
| 与仿射映射复合 | $f(Ax+b)$ 凸 | 与第二行同义 |

### 复合规则的三种情形

设 $h(x)=f(g(x))$：

1. $f$ 凸且**非减**，$g$ 凸 → $h$ 凸 ✓
2. $f$ 凸且**非增**，$g$ 凹 → $h$ 凸 ✓
3. $f$ 凸但**不单调**，$g$ 凸 → $h$ **一般非凸** ✗

例：$f(u)=u^2$ 凸，$g(x)=\cos x$ 非凸，$h=\cos^2 x$ 非凸；$f(u)=\log u$ 凹且非减，$g$ 凹时 $f(g)$ 也是凹的。

### 常用构造

- 范数的非负组合：$\|Ax+b\|_1+\lambda\|x\|_2$ 凸；
- 分段最大值：$\max_i(a_i^\top x+b_i)$ 凸（可转成 LP）；
- log-sum-exp：$\log\sum_i e^{x_i}$ 凸（平滑的 max 近似）；
- 最小二乘：$\|Ax-b\|_2^2$ 凸；
- 透视形式：$x^2/y$、$t\log(x/t)$ 等凸。

## 7. 常见函数凸性速查表

| 表达式 | 凸性 | 备注 |
|---|---|---|
| $a^\top x+b$ | 既凸又凹 | 仿射函数是唯一同时凸凹的函数 |
| $x^\top P x+c^\top x+d$，$P\succeq0$ | 凸 | $P$ 不定则非凸 |
| $\|Ax+b\|$（任意范数） | 凸 | 含 $\ell_1,\ell_2,\ell_\infty$ |
| $\|x\|_0$ | 非凸 | 常用 $\ell_1$ 松弛 |
| $\max_i f_i(x)$，$f_i$ 凸 | 凸 | 逐点最大值 |
| $\min_i f_i(x)$，$f_i$ 凸 | 一般非凸 | 最小值不保凸 |
| $-\log x$（$x>0$） | 凸 | 对数障碍 |
| $x\log x$（$x>0$） | 凸 | 负熵 |
| $1/x$（$x>0$） | 凸 | 反比 |
| $x^2/y$（$y>0$） | 凸 | 透视函数，常用二次锥表示 |
| $\sqrt{x_1x_2}$（$x\ge0$） | **凹** | 几何平均，注意方向 |
| $\left(\prod_{i=1}^n x_i\right)^{1/n}$（$x\ge0$） | 凹 | 几何平均，几何规划的核心 |
| $\log(\sum_i e^{x_i})$ | 凸 | log-sum-exp |
| $\log\det X$（$X\succ0$） | **凹** | 常用作障碍函数 |
| $\lambda_{\max}(X)$ 半正定锥上 | 凸 | 最大特征值 |
| $x_1x_2$、$xy$ 型乘积 | 非凸 | 双线性项 |
| $\sin x$、$\cos x$、$\tan x$ | 非凸 | 周期函数 |
| $x^2-y^2$ | 非凸 | Hessian 不定 |
| $\|x\|_1^2$ | 非凸（一般） | $\ell_1$ 范数平方破坏凸性 |
| $\|x\|_2^2$ | 凸 | 欧氏范数平方 |
| $\|x\|=1$、$x^2=1$ | 非凸 | 非仿射等式 |
| $\mathrm{rank}(X)\le k$ | 非凸 | 常用核范数松弛 |

## 8. 常见误判与陷阱

1. **忽略隐含定义域**：只看表达式，忘了 $\log$、$1/x$ 自带的正性约束。
2. **约束方向搞反**：$g(x)\ge0$ 需要 $g$ 是凹函数，不是凸函数。
3. **把非仿射等式当凸约束**：等式只有仿射才允许。
4. **复合规则单调性用错**：$f$ 凸、$g$ 凸并不能推出 $f\circ g$ 凸，必须看 $f$ 的单调性。
5. **看到分式就判非凸**：$x^2/y$、几何平均等分式形式其实是凸/凹的。
6. **看到二次型就判凸**：$\min x^\top P x$ 只有在 $P\succeq0$ 时才凸。
7. **把「最大化凸函数」当凸**：最大化凸函数一般非凸，除非它是凹函数。
8. **忽略变量类型**：整数约束、二元约束、离散选择都会破坏凸性。
9. **只看原始写法**：很多非凸问题经变量代换、增加辅助变量后可转成凸问题。

## 9. 凸问题家族

判断时可以先尝试把问题往这些标准家族上归类，归得进去即为凸问题：

| 家族 | 标准形式特征 | 典型场景 |
|---|---|---|
| LP 线性规划 | 目标与约束均仿射 | 资源分配、网络流 |
| QP 二次规划 | 凸二次目标 + 仿射约束 | 最小二乘、投资组合 |
| QCQP 二次约束二次规划 | 凸二次目标 + 凸二次约束 | 稳健估计 |
| SOCP 二阶锥规划 | 二阶锥约束 | 鲁棒优化、范数问题 |
| SDP 半定规划 | 半定锥约束 | 松弛、控制、矩阵估计 |
| GP 几何规划 | 正项式目标与约束，可对偶成凸 | 工程设计、幂律建模 |
| CP 锥规划 | 一般凸锥约束 | 上述家族的统一框架 |

## 10. 工具校验：CVXPY / DCP

CVXPY 基于 **DCP（Disciplined Convex Programming）** 规则集自动判断表达式凸性：

- 报告 `convex` / `concave` / `unknown`；
- 报 `unknown` 不一定真非凸，可能只是写法没整理好（例如该用透视形式、换变量代换）；
- 报 `convex` 就一定是凸的（规则集只放行能证明凸的构造）。

```python
import cvxpy as cp

x = cp.Variable(2)

# 凸：二次目标 + 仿射约束
prob = cp.Problem(cp.Minimize(cp.sum_squares(x)), [cp.sum(x) == 1, x >= 0])
print(prob.is_dcp())          # True

# 非凸：等式约束非仿射
prob2 = cp.Problem(cp.Minimize(cp.sum_squares(x)), [cp.sum_squares(x) == 1])
print(prob2.is_dcp())         # False
```

手算与工具结合的使用建议：

1. 先按五步检查法手算一遍，形成判断；
2. 再用 CVXPY 校验，两者不一致时说明有细节被忽略（通常是隐含定义域或复合规则方向）。

## 11. 判别练习

判断下列问题是否为凸优化问题，并说明理由（答案见折叠思路）。

**练习 1**
$$
\min_x\ x_1^2+3x_2^2-2x_1x_2+4\quad \text{s.t.}\ x_1+x_2\ge1
$$

**练习 2**
$$
\min_x\ \|Ax-b\|_2^2+\lambda\|x\|_1
$$

**练习 3**
$$
\min_x\ \frac{x^\top P x}{c^\top x}\quad \text{s.t.}\ c^\top x>0,\ P\succeq0
$$

**练习 4**
$$
\max_x\ x^\top P x\quad \text{s.t.}\ \|x\|_2=1
$$

**练习 5**
$$
\min_x\ \sum_{i=1}^m \log(1+e^{a_i^\top x})\quad \text{s.t.}\ \|x\|_2\le 1
$$

**练习 6**
$$
\min_x\ x_1x_2\quad \text{s.t.}\ x_1,x_2\ge0
$$

> 思路提示：
> 1. 写成 $x^\top Qx$ 形式检查 $Q\succeq0$，约束化成 $-x_1-x_2\le-1$，凸。
> 2. 凸二次 + 凸范数的非负和，凸（Lasso）。
> 3. 分子凸、分母正仿射，属二次-线性分式，可化为锥规划，凸（需保持 $c^\top x>0$）。
> 4. 最大化凸函数 + 非仿射等式，非凸（实为最大特征值问题，需转为 SDP 松弛）。
> 5. log-sum-exp 的仿射复合凸，加范数约束，凸。
> 6. 双线性项非凸（可固定 $x_1$ 看关于 $x_2$ 是仿射，但整体不凸）。

**一句话总结**

判断标准：**等式约束必须仿射，不等式约束和目标必须凸，隐含定义域必须是凸集，变量必须是连续的——全部满足才是凸优化问题。**
